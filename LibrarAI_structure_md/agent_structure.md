## 주요 설계 원칙

**범용 설계 (기관 독립성)**
- 모든 에이전트는 특정 기관에 종속되지 않는다
- 기관별 고유 정보(기관명·예산·일정·강의실 등)는 배포 시 Config로 주입
- PRD 본문에 창녕도서관 등 특정 기관 정보를 하드코딩하지 않는다

**Human-in-the-loop**
- 모든 에이전트는 최종 결정·발송·결재 단계에서 사서 개입 필수
- 에이전트는 초안·분석·제안을 제공하며 실행은 사서가 담당

**공통 도구 에이전트**
- A01 공문서: 전 도메인 에이전트가 hwpx 초안 필요 시 호출
- A03 예산: 도메인 에이전트가 예산 잔액 조회·집행 기록 시 호출
- D04 홍보물: F01 SNS 에이전트가 이미지 생성 위임 시 호출

**출력 방식**
- hwpx: hwpx-autofill-conversion 스킬 (Filesystem MCP로 템플릿 로드 → section0.xml `<hp:t>` 치환 → rezip)
- 최종 파일: USB로 업무 PC 이전 후 한글 프로그램에서 검토·결재

**기술 용어 원칙**
- AI 에이전트 등 기술 용어는 Anthropic·OpenAI·Google 등 공신력 있는 기관의 공식 문서 기준으로만 사용
- 마이너하거나 비유적 표현 사용 금지. 비공식 용어 사용 시 반드시 명시

LibrarAI 리프 에이전트별 LLM 모델 티어 분류 (초안)
작성일: 2026-07-09
상태: 초안 — 사용자 검토 대기 (아직 코드에 반영 안 됨)

배경
----
LibrarAI.html의 모든 에이전트 탭은 api/chat.js(OpenRouter 프록시)를 공유하며,
지금은 사이드바의 selectedModel 전역 상태 하나를 전체 탭이 공유해서 쓰고 있음.
api/chat.js는 req.body를 그대로 OpenRouter에 전달하는 순수 프록시라
요청마다 다른 model 값을 보내는 것 자체는 이미 가능함.
리프별로 다른 모델을 쓰려면:
  1) 각 에이전트 설정 객체(B_AGENTS_CONFIG 등)에 model 필드 추가
  2) 요청 시 전역 selectedModel 대신 activeAgent.model을 참조하도록 변경
현재 LibrarAI.html에는 A/B/C/F 도메인 21개 리프만 탭으로 연결돼 있고,
D/E 도메인(10개)·DM 5개는 PRD·서브에이전트는 완료됐지만 아직 채팅 탭 미연결.
(이 문서는 향후 전부 연결된다는 전제로 30여 개 전체 기준 초안임)

분류 기준 (3단계)
------------------
T1 경량/고속
  정의: 단순 조회·집계·정형 응답. 호출 빈도 높고 오류 비용 낮음
  판단 축: 규칙이 명확 + 실수해도 되돌리기 쉬움 + 키오스크처럼 응답속도가 중요
  추천 모델(예시): Claude Haiku 4.5

T2 표준 (현재 기본값)
  정의: 규칙 적용형 판정, 정형 문서 초안, 여러 소스 편집·종합
  판단 축: 판단은 필요하지만 열려있는 창의적 사고는 아님
  추천 모델(예시): Claude Sonnet 5

T3 고정밀 추론
  정의: 다중 제약 하의 점수화·우선순위·예산배분, 창의적 기획/카피, 분류 판단, 상위 종합
  판단 축: 틀리면 후속 전체 워크플로우가 틀어지거나(B-04-W 분류 오류 등),
           외부에 노출되는 결과물(공문·보도자료)이거나, 열린 창의성이 필요
  추천 모델(예시): Claude Opus 4.8

주의: 현재 MODEL_OPTIONS에는 Claude Sonnet 5 / GPT-5.3-chat 2개뿐이라
T1·T3을 실제로 쓰려면 옵션 목록을 확장해야 함.

도메인별 초안
=============

[D0 행정]
A-01 공문서       T2  정형 템플릿 채우기 위주지만 표기 규칙이 엄격해 실수 비용 있음
A-02 최상위이관    T1  단순 취합·검증 브로커
A-03 예산관리      T2  원장 기록·잔액 조회, 금액이라 최소한의 신중함 필요
A-04 성과관리      T2  증감률·달성률 계산 및 구조화

[D1 장서]
B-01 수서         T3  점수화+예산배분 다중 제약 최적화
B-02 희망도서      T2  반려기준 10개 순차 적용, 애매한 건 사서에게 넘김
B-03 복본         T2  유사도 계산+대출데이터 분석
B-04-H 하네스     T1  순차 디스패치·QA 재검증 위주, 판단은 워커가 함
B-04-W 워커       T3  KDC 분류 판단 오류 시 후속 전체(청구기호 등)에 영향
B-05 균형         T1  비율·결핍지수 계산, B-01 실시간 조회용
B-06 점검         T2  대조 로직+결과보고 초안

[D2 이용자] (키오스크, 응답속도 중요)
C-01 FAQ          T1  RAG 단순 조회
C-02 추천         T2  개인화 로직·유사도 분석
C-03 프로그램안내  T1  실시간 취합·merge만
C-04 상호대차      T1  기록·마감 알림
C-05 외부도서서비스 T1  기록·확인메시지 정형
C-06 만족도조사    T1  집계·경고 로직

[D3 독서문화]
D-01 동아리       T2  공고문·운영일지 정형 생성
D-02 행사기획      T3  열린 창의적 브레인스토밍(주제 후보 등)
D-03 강사공모      T2  DB+웹검색 랭킹, 섭외문 초안
D-06 순회문고      T2  비율 기준 도서선정

[D4 평생학습]
E-01 강좌기획      T3  데이터 기반 판단+세부계획서, 복잡도 높음
E-02 강사공모      T2  공고·심사결과 정형
E-03 모집         T2  채널별 홍보문안(창의성은 있으나 정형 반복)
E-04 운영일지      T2  출결 기록은 단순하나 강사비 계산 포함

[D5 홍보협력]
F-01 홍보물 작성   T3  외부 노출 카피, 톤·품질이 중요
F-02 협력기관      T2  대외(의원·위원회) 소통 기록, 민감도 있으나 정형
F-03 공모사업      T2  자격검토·마감추적
F-04 소식지        T2  여러 소스 편집 종합

[DM 도메인 에이전트]
DM-01~DM-05        T2 (전부)  하향 분배는 단순 라우팅, 월간 실적 취합·보고서는 편집 위주라
                            열린 추론까지는 불필요

[최상위 오케스트레이터]
chief-coordinator  T3  5개 DM 응답을 통합한 최종 보고서·이상징후 판단

요약
----
T1 약 12개 / T2 약 13개 / T3 약 6개

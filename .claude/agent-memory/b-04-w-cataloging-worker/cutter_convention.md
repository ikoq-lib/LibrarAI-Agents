한국인 저자의 저자기호는 에이전트 정의(b-04-w-cataloging-worker.md)에 제시된 표준 커터표를 기준으로 한다: 김→19, 이→65, 박→45, 최→98, 정→74 등. 새로운 성씨가 등장하면 해당 표준 커터표(한국문헌자동화목록기구표 등)를 참고해 유추하고, 이 메모리에 추가한다.

**문학류(810 등)**: 커터번호 뒤에 작품 표제 초성을 딴 작품기호를 부기한다 (예: 파친코 → 김19ㅍ).

**비문학류(문학 이외 전 분야)**: 동일 저자·동일 분류번호로 여러 도서가 있을 경우를 대비해, 커터번호 뒤에 표제 첫 음절의 초성을 도서기호로 부기하는 관행을 적용한다 (예: 『현대 조직관리론 입문』, 저자 박테스트, KDC 325.1 → 박45ㅎ, "ㅎ"은 "현대"의 초성).

**Why:** 문학류의 작품기호 부여 규칙은 에이전트 정의에 명시되어 있으나 비문학류의 도서기호 부여 방식은 명시되어 있지 않아, 2026-07-11 테스트 케이스(TEST-B04H-현대 조직관리론 입문) 처리 시 일관된 규칙을 임의로 정해 적용했다. 향후 실제 도서 카탈로징에서도 동일한 방식을 재사용하기 위해 기록한다.

**How to apply:** 비문학류 도서의 저자기호 뒤에 도서기호가 필요한 경우(동일 저자·동일 분류번호 중복 방지 목적) 표제 첫 글자의 한글 초성 1자를 부기한다. 다만 이는 정식 저자기호표(예: 이재철식 저자기호표)를 관장 도서관이 채택하기 전까지의 잠정 관행이므로, 사서의 확인/승인을 받아야 한다.

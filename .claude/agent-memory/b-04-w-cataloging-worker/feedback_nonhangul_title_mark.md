작품기호(저자기호 셋째 자리)는 본표제 첫 글자를 음절 그대로 쓰는데, 표제가 영문·숫자로
시작하면 한글 음절이 없다. 이때 **소리 내어 읽은 첫 음절**을 쓴다.

- **영문은 한글 발음으로** — `AI 알아보기` → 에이 → **에** / `I` → 아이 → **아**
- **숫자는 한자음으로** — `64` → 육십사 → **육** / `10년 후` → 십 → **십**
  (일·이·삼·사·오·육·칠·팔·구·십)

**Why:** 2026-09-12 사서 확정. 제4차 정기도서 배치에서 『64』(요코야마 히데오)와 『I』가
"본표제에 한글 음절이 없다"며 저자기호 없이 qa_failed로 나갔다. 저자기호가 비면 청구기호가
완성되지 않아 배가할 수 없다.

**How to apply:** `b04w/leejaechul.py`의 `title_first_syllable()`이 처리한다(회귀 테스트 3건).
단건으로 직접 계산할 때도 같은 규칙을 쓰고, 산출 과정에 읽은 방식을 남긴다
(예: "숫자 '64'을 한자음 '육십사'으로 읽어 첫 글자"). 관련: [[feedback-one-syllable-surname]]

2026-07-11: 사서 요청으로 B-01의 표준 업무흐름 3단계(복본 확인 위임) 단독 테스트를 실행함. SEOJI/네이버 수집(FN-01)과 B-05 균형 확인은 생략하고, Agent 도구로 `b-03-duplicate-check`만 직접 호출.

**테스트 후보 3건과 결과:**
- c-001 (ISBN 8949110091, 『치과의사 드소토 선생님』): `duplicate` — ISBN 완전일치(FN-01), 기존 소장 1부. 대출이력 테이블(loan_history/reservations) 미적재로 추가구입 의견은 "판단 보류"로 옴 — 부수 부족 자체만으로 자동 추가구입 권고를 만들지 않음.
- c-002 (ISBN 9999999999999, 『치과의사 드소토 선생님(개정판)』, "윌리엄 스타이그 지음"): `needs_review` — ISBN이 형식상 비정상(전부 9로 된 더미값)이라 완전일치 없음. 제목+저자 유사도 74.3%(title_sim 0.765×0.7 + author_sim 0.692×0.3)로 70~85% 안전마진 구간에 걸려 자동 미확정, 사서 확인 대상으로 넘어옴.
- c-003 (ISBN 9791100000000, 가상 신간): `new` — ISBN·trgm 유사도 모두 매치 없음(0건), 정상 신규 확정.

**확인된 사실 (Why 이것이 유의미한가):** B-03이 실제로 SQL(ISBN exact match + pg_trgm 유사도)을 실행해 판정하며, 목업이나 눈대중 응답이 아님. 또한 B-03은 자체 메모리에 "치과의사 드소토 선생님" 개정판 케이스를 이미 과거에 겪은 엣지케이스로 기억하고 있어(재현 수치 0.743 동일), 같은 유사도 계산 로직이 세션 간 일관되게 재현됨.

**How to apply:** 향후 B-01이 실제 배치 복본 확인을 수행할 때, (1) `duplicate` 판정이라도 대출이력 데이터가 없으면 B-03이 추가구입 의견을 "판단 보류"로 반환할 수 있음 — 이 경우 B-01은 사서에게 이력 데이터 부족을 알리고 원칙대로 후보 제외해야 함(B-03이 추가구입 의견을 명시적으로 제시하지 않는 한 유지 사유 없음). (2) ISBN이 형식상 비정상(자릿수는 맞지만 반복 숫자 등)인 후보는 B-03이 알아서 "완전일치 없음 + fuzzy 유사도"로 처리하므로 B-01이 사전에 별도로 ISBN 유효성 검증을 할 필요는 없음, 다만 이런 값은 원본 SEOJI/네이버 응답 자체의 이상치일 수 있어 FN-01 수집 단계에서 로그로 남겨두는 편이 좋음. (3) needs_review 후보는 B-03이 비교표(기존 소장 vs 신규 후보)를 함께 반환하므로 그대로 사서에게 전달 가능.

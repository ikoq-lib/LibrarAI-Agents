[6] 2026-08-26 처리 결과 — [1]의 결함이 어떻게 해결됐는지
--------------------------------------------------------------------
(1) 저자기호  -> 해결. 리재철 구조 확정:
      [저자명 첫 글자] + [둘째 글자의 숫자기호(초성+중성)] + [표제 첫 글자]
      요코제키 다이 『루팡의 딸』 -> 요875루 (코 = ㅋ87 + ㅗ5)
      김중미 『괭이부리말 아이들』 -> 김77괭 (중 = ㅈ7 + ㅜ7)
      외국인 저자도 한글 음역 기준. 작품기호는 음절 그대로.
(2) 056/049/090 -> 해결. 우리 관 정책 확정:
      청구기호는 090 $a[KDC] $b[저자기호]
      056은 KDC만 ($a분류기호 $26)
      052(국중 수입순 청구기호)는 생성 금지
      049 $l등록번호 $c복본수 $f별치기호(J/유)
(3) 기본표목  -> 해결. 100/110/111 생성 금지, 700/710만 사용,
      주 책임자에게만 $4 aut. (샘플 52건 전체에 100/110 0건으로 확인)
(4) 245 $c    -> 해결. KORMARC은 $d(첫 책임표시)/$e(그 외).
(5) LDR 22자리 -> 24자리로 정정. 008 40자리 유지.
(6) 041 0_    -> 번역서는 041 1_ + 546 언어주기로 정정.
(7) 300 구두점 -> ISBD 구두점 실물 기준으로 명시.
(8) QA 공백   -> B-04-H FN-03 체크리스트에 100/110 부재·052 부재·
      090 $a=056 $a·저자기호 구조·245 $d/$e·$4aut 검사 추가.
(9) 별치기호  -> B-04-H FN-03.5 INSERT에 loc_mark·vol 컬럼 추가.

추가로 확인된 것:
  - 우리 관 목록작성기관 부호: 040 $a 148024 $c 148024
    (자관 MARC 5건 전부 동일. 맞는지 한 번 확인해 주면 좋음)
  - 650 주제명은 ind2=8 + $0 KSH번호(국중 주제명표목표).
    KSH 번호를 모르면 $0 생략하도록 규정 — 지어내지 않게.
  - 008/22 대상독자(a 유아 / b 어린이 / 성인 공백)와
    049 $f 별치기호(유 / J / 없음)가 서로 일치해야 함.

## 1. 전체본 샘플 구성

`산출물/[양식샘플]2026년_10월_도서관_월간업무계획.docx` — A4 4쪽, 표 11개

| 절 | 표현 방식 |
|---|---|
| 표지 | 제목 + 하단 강조선, 문서정보 2단 라벨/값 표(대상기간·작성부서·작성자·작성일·문서상태·총 소요예산) |
| 1. 총괄 요약 | 개조식 3줄 + 도메인별 요약표(도메인 / 핵심업무 / 소요예산 / 확인필요) |
| 2. 주차별 추진 일정 | 1~5주차 × 기간 · 주요일정 · 담당 |
| 3. 도메인별 상세 | 도메인마다 「구분/내용」 개요 표 → 세부 업무 표. 행사·강좌 표는 합계 행에 음영 |
| 4. 예산 소요 개요 | 단위과제카드 / 사업항목 / 예산목 / 예산액 / 기집행 / 이달 소요 / 잔액 (7열) |
| 5. 확인·승인 필요 항목 | 연번 / 출처 / 항목 / 내용 / 회신기한 |

### 가독성 장치 (hwpx 양식에 반영 요청 대상)

- 표 머리행: 음영 `#E8EFEC` + 굵게 + 가운데 정렬
- 금액·수량 열: **우측 정렬** / 분류·설명 열: 좌측 정렬 / 일자·구분 열: 가운데 정렬
- 합계 행: 음영 `#F4F6F5` + 굵게
- 열 너비 고정(autofit 해제), 셀 상하 여백 확보, 세로 가운데 정렬
- 절 제목에 좌측 세로 강조선(`#1E6E5C`), 문서 제목에 하단 강조선
- 표마다 `[표 n] 캡션` 부여
- 표가 페이지를 넘어가면 머리행 반복(`w:tblHeader`)
- 표 아래 단서는 `※` 소형 회색 문단으로 분리

## 3. 현재 구현 상태와 실제 원인

### hwpx 변환기는 이미 표를 지원한다

`LibrarAI.html`의 `buildHwpxSection0`(3622행)이 본문을 줄 단위로 훑으면서
`| ... |` 행 + `|---|---|` 구분선을 만나면 `buildHwpxTable`(3594행)로 실제 hwpx 표(`hp:tbl`)를 만든다.

- 첫 행 = 표 헤더 → `paraPr 55`(가운데정렬) + `charPr 46`(굵게)
- 나머지 행 = 본문 셀 → `paraPr 56`(좌측정렬) + `charPr 5`
- 테두리 `borderFillIDRef 33`(가는 실선 4방향), 셀 여백 141, `repeatHeader="1"`
- 단독 행 `---`는 페이지 나눔으로 처리

즉 **변환기가 못해서 밋밋한 게 아니다.** 에이전트가 마크다운 표를 내보내지 않고
`항목  내용  비고` 처럼 공백으로 구분한 평문 문단을 출력하고 있는 것이 원인이다.
(참고: `gen_6월업무계획서.py`도 같은 방식으로 표를 평문 문단으로 넣고 있다.)

### 변환기에 없는 것 (양식 확정 후 보강 대상)

| 기능 | 현재 | 필요 |
|---|---|---|
| 열별 정렬 | 헤더 가운데 / 본문 전부 좌측 고정 | 금액 열 우측 정렬 |
| 열 너비 | 전 열 균등 분할 | 열별 너비 지정 |
| 합계 행 강조 | 없음 | 마지막 행 음영 + 굵게 |
| 표 머리 음영 | 없음(테두리만) | 머리행 배경색 |
| 표 캡션 | 없음 | `[표 n]` 소제목 스타일 |

## 1. 에이전트 정의

공공도서관의 자료 선정·주문·수령·등록 업무를 지원하는 단일 목적(single-purpose) leaf agent.
도서관 외부 데이터(국립중앙도서관 서지정보유통지원시스템, 네이버 책 검색 API)와 내부 데이터(기존 장서 DB, 이용자 대출 통계)를 조합해 선정 초안을 자동 생성하고, 사서의 최종 검토·결재를 지원한다.

| 항목 | 내용 |
|---|---|
| 상위 에이전트 | 자료개발 도메인 에이전트 (Domain Agent) |
| 호출 방식 | 도메인 에이전트로부터 태스크 수신 / 사서 직접 호출 |
| 출력 소비자 | 도서관 장서 관리 시스템, 도메인 에이전트, 담당 사서 |
| 개발 방법론 | 바이브 코딩 + 하네스 엔지니어링 |

## 2. 배경 및 문제 정의

### 현재 문제
신간 목록 수기 검토, 중복 확인, 예산 배분 계산이 분절·수작업으로 처리됨. 선정 근거 문서화 미흡.

### 목표 상태
정형화된 선정 기준과 외부 API를 활용해 초안을 자동 생성, 사서는 검토·승인에만 집중.

## 3. 업무 범위 (Scope)

### 포함 (In Scope)
1. 신간 후보 목록 수집 및 필터링 (SEOJI 서지정보 1차 수집 + 네이버 책 검색 API로 정가·베스트셀러 근접 신호 보완)
2. B-03 복본 에이전트 호출을 통한 중복(복본) 판정 결과 수신 및 후보 목록 반영 (ISBN 완전일치·제목저자 유사도 판정, 추가구입 의견)
3. 선정 기준 점수화 및 우선순위 정렬 (이용자 요청, 대출 통계, 출판 연도, KDC 균형)
4. 예산 범위 내 자동 배분 초안 산출
5. 선정 도서 목록 엑셀/보고서 초안 자동 생성 및 결재 패키지 구성
6. **(2026-07-09 신규) 정기구입 트랙의 자료심의위원회 연동** — 위원회 구성(연 1회)·개최·회의결과 문서 생성 지원 및 심의 결과(삭제 도서 등)의 최종 구입 목록 반영 (FN-06)
7. **(2026-07-09 신규) 3개 구입 트랙(정기구입/희망도서/웹툰도서) 구분 처리** — 트랙별 결재선·문서 템플릿·심의 필요 여부가 다름
8. **(2026-07-27 신규) 지역 이용 데이터 후보 보강** — 업로드된 대출·예약·상호대차 수령 데이터에서 최대 5종을 선정해 후보 풀에 병합

### 제외 (Out of Scope)
- 최종 선정 결정 (사서 고유 권한)
- 복본(중복) 판정 로직 자체 — ISBN 대조, 제목저자 유사도 계산, 추가구입 필요성 분석은 B-03 담당
- 발주 송신
- 납품 검수
- KORMARC 레코드 생성 (목록 에이전트 담당)
- 폐기 처분 판단 (B-06 담당 — 단, 폐기 대상도 자료심의위원회를 거쳐야 함은 동일)
- 자료심의위원회 위원 임명 자체(인사 발령) — B-01은 위원회 구성·개최·회의결과 문서 생성만 지원, 위원 임명은 도서관장 고유 권한

## 4. 업무 흐름 (Workflow)

```
트리거 수신 (도메인 에이전트 / 사서)
  → 구입 트랙 결정: 정기구입 / 희망도서 / 웹툰도서 (2026-07-09 신규 분기)
  → 신간 후보 수집 (SEOJI 1차 + 네이버 책 검색 API 보완)
  → B-03 복본 판정 요청 → 판정 결과 수신 (복본/상세조사필요/신규 + 추가구입 의견)
  → 점수화·정렬 (선정 기준 적용, 복본 판정 결과 반영)
  → 예산 배분 초안 (KDC별 균형)
  → [정기구입 트랙만] 자료심의위원회 연동 (FN-06)
      구성(연 1회, 최초/인사이동 시) → 개최 기안 → 회의결과 수신 → 심의결과(삭제 등) 목록 반영
  → 보고서 생성 (Excel / 공문 초안 — 트랙별 템플릿: 정기구입=TPL-019, 희망도서=TPL-014, 웹툰도서=TPL-020)
  → 사서 검토·승인 [Human-in-the-loop]
```

**트랙별 결재선·심의 요건 요약:**

| 트랙 | 심의위원회 | 결재선 | 공문 템플릿 |
|------|-----------|--------|------------|
| 정기구입 | **필수** | 주무관·도서관장 | TPL-019 (심의결과 반영본) |
| 희망도서 | 생략 | 주무관·도서관장 | TPL-014 |
| 웹툰도서 | 생략 | **사서팀장·도서관장** (주무관 없음, 예외) | TPL-020 |
| 500만원 이상 자료 / 정기간행물 구독 / 자료 폐기(B-06 소관) | 필수 | (해당 도메인 규칙 따름) | — |

## 5. 기능 요구사항

### FN-01 · 신간 후보 자동 수집 (2026-08-27 SEOJI 일일 전량 수집으로 전환)

**1차 발굴원은 SEOJI 종이책 신간 전량이다.** GitHub Actions `harvest-seoji-catalog.yml`이 매일 KST 06:00에 `public.book_catalog`로 워터마크 증분 수집한다.

| 항목 | 내용 |
|---|---|
| 엔드포인트 | `https://www.nl.go.kr/seoji/SearchApi.do` (`form=종이책`, `sort=INPUT_DATE&order_by=DESC`) |
| 증분 방식 | `max(book_catalog.input_date) − 3일`을 워터마크로 삼아 그보다 오래된 등록일이 나오면 중단 |
| 호출량 | 하루 1~2회(1페이지 1,000건). 이전 롤링 윈도우 방식의 20회/일을 대체 |
| 수집 단계 배제 | 부가기호 1자리 `5`·`6`(학습참고서)·`9`(전문서), 2자리 `8`(전자자료) |
| 실측 규모 | 2026-07-26~08-25 한 달치 9,873종 |

`start_input_date`/`end_input_date` 파라미터는 SEOJI가 무시하지만 `sort=INPUT_DATE`는 정상 동작한다. 이 성질이 워터마크 방식의 전제다.

**주간 8개 출처 취합은 폐기하지 않았다.** `acquisition_candidates`는 후보 목록이 아니라 인기도 축의 재료로 남는다(FN-03 참조, 현재 축 비활성). 아래는 그 수집 사양이며 `harvest-acquisition-candidates.yml`이 매주 월요일에 수행한다.

| 분야 | 고정 출처 | 원시 할당량 |
|---|---|---:|
| 출판 유통·판매 | 출판유통통합전산망 「화제의 책 200선」 | 20 |
| 서점 | 교보문고 | 15 |
| 서점 | YES24 | 15 |
| 언론 | 한겨레 「책과 생각」 | 5 |
| 언론 | 동아일보 「금주의 신간」 | 5 |
| 공공도서관 | 국립중앙도서관 사서추천도서 | 5 |
| 공공도서관 | 국립어린이청소년도서관 사서추천도서 | 5 |
| 공공데이터 | 도서관 정보나루 인기대출도서 | 5 |

직접 HTML/PDF 파싱을 우선하고, 직접 수집이 불가능하거나 할당량에 못 미친 출처만 해당 도메인으로 제한한 AI 웹 검색을 최대 3회 재시도한다. 인플루언서·북튜버는 수집 대상에서 제외한다. 1차 출처 병합 후 40종 미만이면 알라딘·영풍문고를 예비 출처로 필요한 수만큼만 사용한다.

원시 후보는 65~75종, 중복·부적합 자료 제거 후 저장 후보는 40~50종을 목표로 한다. 한겨레와 동아일보는 각각 5종으로 동일 상한을 유지한다. 결과가 40종 이상이면 정상 성공, 30~39종이면 부분 성공 경고, 30종 미만이면 실패 처리한다.

주간 취합분에 대한 SEOJI 검증은 그대로 유지한다(ISBN·서명·저자·출판사·정가·발행일·종이책 포맷). 미등록·무응답 후보는 `verified=false`로 보존하고 발주 전 사서 재확인을 요구한다. 단 **2026-08-27부터 SEOJI는 검증원인 동시에 1차 발굴원이므로**, "SEOJI는 후보를 발굴하지 않는다"는 이전 서술은 더 이상 유효하지 않다.

동일한 SEOJI 응답에서 `EA_ADD_CODE`를 읽는다. 유효한 5자리만 `isbn_add_code`에 저장하며 데이터베이스가 `add_code_audience`(1자리), `add_code_form`(1자리), `add_code_subject`(3자리)를 자동 생성한다. 독자대상 `7`/`4`는 각각 어린이·청소년 일반도서의 보조 신호로 사용하고 `6`/`5`는 학습참고서로 분리한다. `add_code_subject`는 임시 내용분류이며 KDC 확정값으로 출력하지 않는다.

### FN-02 · 복본 확인(B-03 위임)·장서 균형 확인(B-05 위임)
- **복본 판정은 B-01이 직접 수행하지 않는다.** 신간 후보 목록(ISBN·제목·저자)을 B-03 복본 에이전트에 전달하고 판정 결과를 수신한다 (요청/응답 구조는 B-03 PRD FN-05 참조).
- B-03 응답에 따른 처리:
  - `duplicate`(복본 확정): 원칙적으로 후보에서 제외하되, B-03이 제시한 추가구입 의견(수요 대비 소장 부수 부족 등)이 있으면 예외적으로 후보에 유지하고 사서에게 사유를 명시
  - `needs_review`(상세조사 필요): 사서 확인이 완료될 때까지 점수화·예산 배분 대상에서 보류
  - `new`(신규): 정상적으로 점수화 단계 진행
- **1차 걸러내기는 뷰가 한다(2026-08-27).** `v_candidate_scores.already_owned`가 ISBN 완전일치 소장분을 표시하므로 B-03에는 나머지만 보낸다. 서명+저자 유사도 판정은 뷰가 못 하므로 **`already_owned`가 0건이어도 B-03 호출을 생략하지 않는다.** (실측: 카탈로그 9,873종 중 ISBN 교집합 0건 — 8월 발행 신간인데 우리 최종 입수일이 7월 8일이기 때문. 신간 수서에서는 정상이나 희망도서 트랙은 사정이 다르다.)
- **KDC 균형은 별도 호출 없이 점수에 이미 반영된다(2026-08-27 변경).** `mv_kdc_deficit`이 결핍을 계산하고 `score_kdc`가 점수로 바꾼다. 후보 한 건씩 B-05에 결핍 지수를 묻지 않는다. 다만 **목표비율(`kdc_target_ratios`)의 소유자는 여전히 B-05**이며 등록·변경은 B-05를 통한다. 정기 균형 리포트나 목표비율 변경이 필요할 때만 호출한다.
- 이용자 희망도서 요청 목록과 교차 확인 → 해당 자료 우선순위 상향 (B-01 자체 수행)
- 도구: B-03 호출(복본 판정), `v_candidate_scores` 조회(균형 점수·복본 1차 표시), 희망도서 매핑

### FN-01A · 지역 이용 데이터 기반 후보 보강 (2026-07-27 신규)

- 입력: 사서가 업로드한 대출·예약·상호대차 수령 데이터. 개인별 원시 이력 대신 도서별 집계값을 사용하고 이용자 식별정보는 저장하지 않는다.
- 후보 의미:
  - 대출·예약 상위 자료: 이미 소장한 자료의 `additional_copy` 후보
  - 우리 관에 없어 다른 도서관에서 수령한 상호대차 자료: `new_title` 후보
- ISBN 우선, ISBN이 없으면 정규화한 제목+저자로 세 데이터의 동일 도서를 병합한다.
- 대출·예약·상호대차 원시 건수는 단위가 다르므로 직접 합산하지 않는다. 각 지표의 업로드 배치 내 백분위 순위를 사용하며, 여러 지표에 동시에 나타난 도서는 복수 근거를 보존하고 동점 시 우선한다.
- 부적격 자료 필터와 중복 병합 후 한 번의 업로드 배치당 최대 5종만 `public.acquisition_candidates`에 upsert한다.
- 기존 후보와 ISBN 또는 제목+저자가 같으면 새 행 대신 기존 행에 `우리도서관 이용 데이터` 출처와 이용 근거를 병합한다.
- 저장 근거: 후보 유형, 업로드 배치 ID, 집계 기간, 대출 횟수, 예약 건수, 상호대차 수령 횟수, 순위·백분위, 선정 사유. 이용자 번호·이름은 저장하지 않는다.
- B-03에서 실제 소장 여부와 기존 소장 부수를 확인한다. `additional_copy` 후보는 복본이라는 이유만으로 자동 탈락시키지 않고 추가구입 의견과 함께 사서에게 제시한다.
- 파일의 실제 열 구조와 분포를 최초 샘플로 확인한 뒤 열 매핑과 최소 인정 기준을 확정한다. 확인 전 임의 임계값을 만들지 않는다.
- 처리 결과는 분석 행 수, 유효 후보 수, 신규 삽입 수, 기존 후보 병합 수, 제외 사유, 최종 후보 최대 5종으로 보고한다.

### FN-03 · 선정 기준 점수화 (2026-08-27 v0.5 전면 교체)

점수는 **`public.v_candidate_scores` 뷰가 계산한다.** LLM은 점수를 만들지 않고 읽어서 설명만 한다. 점수를 저장하지 않고 조회 시점에 계산하므로 대출이 쌓이거나 달이 바뀌면 UPDATE 없이 점수가 따라 움직인다. 가중치는 `public.scoring_weights` 테이블에 있어 코드 수정 없이 조정 가능하다.

| 축 | 만점 | 측정 방법 | 근거 없을 때 |
|---|---|---|---|
| 출판사 | 24 | 그 출판사 소장분의 조정 회전율 백분위(베이지안 축소 적용) | 중앙값 12 |
| 저자 | 24 | 그 저자 소장분의 조정 회전율 백분위(축소 강도 더 높음) | 중앙값 12 |
| 발행일 | 24 | `pubdate_score_bands` 구간표 | 최저 구간 4.8 |
| KDC결핍 | 17 | `mv_kdc_deficit`의 `목표비율 − 현재 소장비율` | 중앙값 8.5 |
| 가격 | 11 | `price_score_bands` 구간표 | 중앙값 5.5 |
| ~~인기도~~ | ~~0~~ | ~~`acquisition_candidates.recommend_count`~~ (비활성) | — |

**설계 원칙 세 가지**

1. **회전율은 노출기간 보정(book-months)을 거친다.** 2026년 입수분과 2019년 입수분을 같은 분모로 나누지 않는다(`books.acquired_date` 사용, 반월 단위 추정).
2. **미상값은 0이 아니라 중립값**을 준다. 0을 주면 "모르는 것"이 "나쁜 것"이 되어 신인 저자·소형 출판사가 구조적으로 배제된다.
3. **베이지안 축소**로 소장 권수가 적은 출판사·저자를 전체 평균 쪽으로 당긴다. 소장 1권 저자의 회전율을 그대로 믿지 않기 위해서다.
4. **(2026-08-27 추가) 출판사 축은 이름이 붙어야 계산된다.** SEOJI는 법인명으로 등록하고(`(주식회사)창비`) 우리 장서는 임프린트명으로 들어와 있어(`창비`, `아울북`) 두 이름이 안 붙으면 실적이 있는데도 중립값을 받는다. 두 단계로 막는다 — `norm_publisher()`가 표기 흔들림을(정확일치 26.5% → 56.1%), `public.publisher_aliases`가 이름 자체가 다른 이형을 처리한다. 별칭 등재 근거와 점검 절차는 `db/publisher_aliases.sql`에 있고, **짐작으로 등재하지 않는다** — ISBN 발행자기호로 동일 등록 주체임을 확인한 것만 넣는다.

**폐기한 4축과 그 이유**

| 구 항목 | 폐기 사유 |
|---|---|
| ① 이용자 수요 40% | "유사 도서 대출 실적"을 LLM 판단에 의존했다. 실제 대출 데이터가 들어오면서 출판사·저자 회전율로 정량화됐다 |
| ② 사회적 관심도 25% | 알라딘 차단 후 대체 신호를 찾지 못했다. 주간 harvest로 되살렸으나 SEOJI 수집분과 교집합이 4종(0.7%)뿐이라 2026-08-27 비활성화 |
| ③ 장서 균형 25% | KDC결핍 17점으로 승계. 다만 **점수 가점만으로는 비율이 지켜지지 않아** 권수 쿼터(FN-04)로 이중화했다 |
| ④ 출판 시의성 10% | 발행일 24점으로 승계·증량. 실측 결과 회전율을 가장 잘 설명하는 단일 변수였다(2014년 발행 0.53 vs 2024년 4.39 = 8.3배) |

**가중치 변경 시 주의:** `pubdate`·`price`는 구간표에 절대 점수가 들어 있어 `max_points`만 바꾸면 실제 점수가 따라오지 않는다. 구간표도 같은 배율로 환산해야 한다.

FN-01A의 최대 5종 추출은 후보 풀 진입 규칙이며 최종 구입 점수가 아니다. 업로드 데이터의 열 구조·집계 기간·분포를 확인하기 전에는 대출·예약·상호대차 건수의 최종 가중치를 확정하지 않으며, 데이터가 없는 값을 추정하지 않는다.

### FN-03A · 후보 배제 규칙 (2026-08-27 신규)

점수 축은 "우리 관에서 잘 나갈 책"은 잘 고르지만 "도서관이 사면 안 되는 책"을 거르지 못한다. 배제는 `public.acquisition_block_reason(출판사, 서명, 정가)`가 판정하며 **LLM이 판단하지 않는다.**

| 유형 | 규칙 위치 | 예 |
|---|---|---|
| POD·자가출판 | `acquisition_excluded_publishers` | 부크크, 퍼플, 좋은땅 |
| 수험서·학습교재 전문 | 〃 | 세진북스, 해커스, 박문각, 제이원에듀 |
| 웹소설 권당 분책 | 〃 | 미스터블루, 더블플러스 |
| 비매품(정가 0원) | `scoring_params.min_purchase_price` | 외국어 선교 설교집 |
| 수험서 서명 패턴 | `acquisition_excluded_title_patterns` | 한국사능력검정, 기출문제집, SMAT |
| 시리즈 과다 | `scoring_params.series_max_per_batch`(3) | 「무직전생」 10권 → 3권 |

- 오탐 방지를 위해 단독 단어(`합격`·`수험생`·`이기적`)는 패턴에 넣지 않는다.
- 배제 결과는 `public.v_blocked_candidates`로 사서에게 제시한다. 사서가 이의를 제기하면 **규칙을 고치지 목록을 손으로 되돌리지 않는다.**
- 우리 관 소장 이력이 있는 출판사(북랩 62권, 하움 16권)는 배제 목록에 넣지 않았다 — 과거 구입 전례가 있기 때문이다.

### FN-04 · 예산 배분 초안 (2026-08-27 KDC 권수 쿼터 도입)
- 분기별 자료구입비 예산을 입력값으로 수신
- **선정은 `public.acquisition_shortlist_kdc(총권수, 발행일상한개월, 시리즈상한)` 한 번으로 끝난다.** 배제 규칙·시리즈 상한·KDC 권수 쿼터·점수순 선정이 모두 이 함수 안에 있다
- 류별 권수는 ATT-006 산식 그대로 `E = 총권수 × D / 100`(최대잔여법으로 합계 보정)
- 단일 출판사 편중(30% 초과) 자동 감지 및 경고 출력

**점수 가점만으로는 KDC 비율이 지켜지지 않는다 (2026-08-27 실측).** 쿼터 없이 점수순으로만 583종을 뽑으면 상위 100종의 78%가 문학이 된다(목표 50%). 문학이 결핍 축에서도 가점을 받고 후보 풀 자체도 문학 편중이기 때문이다. 쿼터를 걸면 10개 류가 목표비율과 정확히 일치했고, 성인:어린이는 59:41로 기존 60:40 쿼터와 충돌하지 않았다.

**KDC 목표비율(`kdc_target_ratios`)은 B-05가 소유한다.** 등록·변경은 B-05를 통하며 B-01은 조회만 한다. 현재 값은 ATT-006 산식 `D = (A 전년 대출비율 + B 전년 확충비율 + C 전체 장서비율) / 3`을 우리 DB 실측으로 재계산한 것이다(문학 50.00 / 사회과학 12.35 / 자연과학 7.38 / 기술과학 6.99 / 역사 6.42 / 철학 6.21 / 예술 3.88 / 총류 2.63 / 언어 2.21 / 종교 1.93). 산식 원값은 문학 50.06이며 사서가 정한 상한 50.0을 적용했다.

**수서 계획 산정 기준 (2026-07-31 사서 확정)** — 월간·분기 계획의 권수·예산을 산출할 때 아래 기준값을 사용하며, 이 항목들에 대해 임의 가정값을 생성하지 않는다.

| 기준 | 확정값 | 근거 |
|---|---|---|
| 트랙별 예산 비중 | 정기수서 : 희망수서 = **50 : 50** | 사서 결정 (2026-07-31) |
| 권당 단가 | **20,000원** | 2024~2026년 출판분 실측 평균 18,162원(2026년분 18,781원)의 상승 추세 반영. 소장 장서 전체 평균 14,614원은 구간 장서가 끌어내린 값이라 신간 수서에 부적합 |
| 이용대상별 배분 | 일반성인 50 / 청소년 10 / 어린이 25 / 유아 15 (%) | 사서 결정 (2026-07-31) |

- 배정 산식: 정기수서는 **정기 배정액 ÷ 잔여 회차**(연 4회, 2·5·8·11월), 희망도서는 **희망 배정액 ÷ 잔여 주수**. 기준액은 A-03 조회 **잔액**을 우선 사용하고 연간 편성액 기준값을 교차검증으로 병기한다.
- 연간 목표를 1/12로 분할하는 방식은 사용하지 않는다 — 정기수서는 매월이 아니라 분기 1회다.
- 반올림 잔여분은 청소년 분야에서 조정한다.
- **축 구분:** 이용대상별 배분은 이용대상 분류이고 B-05의 목표비율은 KDC 주제 분류다. 매핑 규칙 확정 전까지 두 기준을 같은 표에 혼합 제시하지 않는다 (9장 미결 10번).
- **집행 라인 순차 소진(2026-07-31 확정):** 도서취득비 두 라인은 용도 구분이 없다. `1)공공도서관자료구입(기초)|가)도서취득`(30,000,000원)을 먼저 소진하고 부족분만 `2)공공도서관자료구입|가)도서취득`(28,000,000원)에서 집행하며, 한 건이 1순위 잔액을 넘으면 결의를 2건으로 분할하고 사서에게 통지한다(승인 아님). 트랙 비중 50:50은 예산 배분 기준, 순차 소진은 집행 순서 규칙으로 서로 독립이다 — 두 라인을 트랙별로 나누어 쓰지 않는다. 상세는 `a-03-budget-management.md` FN-07.

### FN-06 · 자료심의위원회 연동 (정기구입 트랙 전용, 2026-07-09 신규)

「경상남도교육청 창녕도서관 운영규정」 제2장 제2절 제16조에 근거해, **정기구입 도서 및 500만원 이상 자료는 자료심의위원회 심의를 거친 후에만 구입 가능**하다. 희망도서 등 수시구입은 심의를 생략할 수 있다(운영규정 문언 기준). 정기간행물 구독·자료 폐기(B-06 소관)도 동일 위원회를 거친다.

**위원회 구성 (연 1회, A-01 `TPL-016` 호출):**
- 위원 5명: 위원장(도서관장) + 위원 4명(사서6급 학교도서관지원 담당, 사서7급 종합자료실 담당, 사서7급 어린이자료실 담당, 위원(간사) 사서6급 문헌정보담당)
- 최초 구성 후 매년 갱신하지 않아도 되며, 인사이동 시 후임자가 자동으로 위원 자격을 승계한다(실물 문서상 특약 확인)
- B-01은 구성 여부만 확인하고, 미구성 상태에서 정기구입을 진행하려 하면 사서에게 구성 선행을 안내(임의 진행 금지)

**개최 (회차별, A-01 `TPL-017` 호출):**
- FN-04에서 산출한 예산 배분 초안을 "심의대상 목록"으로 변환 (A-01 `ATT-009` 서식: 총괄표/일반/어린이 3시트, 순번·주제·서명·저자·출판사·출판년·ISBN·책수·가격·비고)
- 개최 기안문에 붙임으로 심의대상 목록 + 위원 명단을 첨부하고 사서가 일시·장소·심의방법(대면회의 등)을 확정

**회의 결과 반영 (사서가 회의 후 결과를 입력하면, A-01 `TPL-018` 호출):**
- 사서가 입력하는 결과: 삭제 결정 도서 목록(도서명·저자·출판사·사유) — 회의록 자체 작성은 B-01 범위 밖(사서가 직접 작성하거나 회의 중 기록)
- B-01은 삭제 결정된 도서를 FN-04 배분 초안에서 제외하고, 심의 전/후 책수·금액 비교표(예: "심의 전 583권/10,011,100원 → 심의 후 581권/9,980,300원")를 자동 산출
- 붙임 4종 생성 지원: 심의결과(비교표+삭제내역) / 회의록(사서 작성 원문 삽입) / 심의결과 목록(A-01 `ATT-010`, 심의 후 확정본) / 참석자 명단

**정기도서구입건의 최종 문서 (A-01 `TPL-019` 호출):**
- 심의 결과가 반영된 최종 목록으로 구입 건의 기안문 생성, "관련"에 자료확충계획(TPL-013 문서번호)과 회의결과(TPL-018 문서번호)를 모두 인용

**심의 생략 트랙(희망도서·웹툰도서) 처리:** FN-06을 호출하지 않고 FN-04 완료 후 바로 FN-05로 진행, 각각 `TPL-014`/`TPL-020` 사용.

## 8. 수용 기준 (Acceptance Criteria)

- **AC1**: 8개 고정 출처에서 원시 후보 65~75종을 취합하고 중복·부적합 자료 제거 후 주간 40~50종을 후보 풀에 저장한다. 30종 미만이면 자동 실행을 실패 처리한다.
- **AC2**: 희망도서 요청 목록에 포함된 자료가 최종 선정 초안 상위 20%에 반드시 포함된다.
- **AC3**: 예산 초과 자료가 최종 목록에 포함되지 않는다.
- **AC4**: 사서 승인 없이 외부 시스템(발주 시스템 등)으로 데이터가 전송되지 않는다.
- **AC5** (2026-07-09 신규): 정기구입 트랙은 자료심의위원회 구성 확인 → 개최 → 회의결과 반영의 3단계를 모두 거치지 않으면 최종 구입 건의 문서(TPL-019)를 생성하지 않는다. 위원회 미구성 상태에서는 개최 요청 자체를 차단하고 사서에게 안내한다.
- **AC6** (2026-07-27 신규): 이용 데이터 업로드 1회당 후보 풀에 신규 삽입 또는 병합하는 도서는 최대 5종이며, 각 후보에 집계 기간·실측 근거·후보 유형이 기록된다. 이용자 식별정보는 저장하지 않는다.
- **AC7** (2026-07-31 신규): 월간·분기 수서 계획 산출 시 트랙 비중(50:50)·권당 단가(20,000원)·이용대상별 배분(50/10/25/15)을 그대로 적용하고, 계산 근거로 A-03 조회 잔액과 잔여 회차·주수를 명시한다. 이 세 기준값을 임의로 바꾸거나 근거 없는 대체값(예: 1/12 분할, 소장 전체 평균 정가)을 사용하면 실패로 처리한다.

9. **(2026-07-09 신규) 500만원 이상 자료·정기간행물 구독 심의 트리거 판단 로직 미설계** — 현재 FN-06은 "정기구입"이라는 트랙 단위로만 심의를 트리거하므로, 희망도서 중 500만원 이상 단일 자료(전집 등)가 발생하는 예외 케이스의 자동 감지 로직 추가 설계 필요

11. **(2026-07-31 해결) 도서취득비 집행 라인 선택 규칙 — 순차 소진으로 확정.** 두 라인(`1)공공도서관자료구입(기초)|가)도서취득` 30,000,000원, `2)공공도서관자료구입|가)도서취득` 28,000,000원)은 **용도 구분이 없다.** 1순위 라인을 먼저 소진하고 부족분만 2순위에서 집행하며, 한 건이 1순위 잔액을 넘으면 결의를 2건으로 분할한다. 라인 선택·분할에 사서 승인은 불필요하고 A-03이 자동 처리한다(`a-03-budget-management.md` FN-07). 트랙 비중 50:50은 예산 배분 기준이고 순차 소진은 집행 순서 규칙이므로, 두 라인을 트랙별로 나누어 쓰지 않는다.

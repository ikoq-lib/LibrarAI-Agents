**문서 버전:** 1.0  
**작성일:** 2026-05-11  
**소속 도메인:** D0 행정  
**에이전트 ID:** A-01  
**에이전트 유형:** Leaf Agent (공통 도구 에이전트)  
**참조 아키텍처:** 창녕도서관 사서 AI 에이전트 시스템 v3

## 1. 개요

### 1.1 목적

A-01 공문서 초안 작성 에이전트는 창녕도서관 전 업무 도메인에서 발생하는 공문서(기안문) 초안을 hwpx 형식으로 생성하는 공통 도구 에이전트다. 각 도메인 에이전트가 공문 작성이 필요한 시점에 A-01을 호출하여 초안을 받아가는 구조로, 경상남도교육청 공문서 양식 규정과 공공기관 기안문 작성 기준을 일원화하여 관리한다.

### 1.2 배경

창녕도서관은 수서, 프로그램 운영, 독서동아리, 순회문고, 강사 섭외 등 거의 모든 업무에서 기안문 작성이 필요하다. 기안문은 경상남도교육청 표준 양식을 준수해야 하며, 형식 오류 시 반려 처리된다. 현재는 사서가 직접 한글(HWP) 프로그램에서 기존 문서를 복사·수정하는 방식으로 처리하나, 반복 작업이 많고 양식 일관성 유지가 어렵다.

A-01은 이 반복 과정을 자동화하고, 공문 양식 지식을 단일 에이전트에 집중시켜 향후 양식 변경 시 A-01만 수정하면 전 도메인에 일괄 반영되도록 한다.

### 1.3 운영 방식

A-01은 독립적으로 사서 요청을 직접 받을 수도 있고, 타 도메인 에이전트(D-02 행사기획, E-01 강좌기획 등)가 내부적으로 호출하는 방식으로도 작동한다. 생성된 hwpx 파일은 MCP Filesystem을 통해 지정 경로에 저장되며, 사서가 USB로 복사하여 업무 PC의 한글 프로그램에서 검토·결재 처리한다.

### 1.4 범위

- **포함:** 기안문 hwpx 초안 생성, 공문 양식 템플릿 관리, 도메인 에이전트 호출 대응
- **제외:** 결재 처리, 공문 발송, 접수·처리 이력 관리 (별도 행정 시스템 담당), 첨부 문서 본문 작성 (각 도메인 에이전트 담당)

## 4. 기능 요구사항

### F-01 공문 유형별 템플릿 관리

경상남도교육청 공문서 양식을 hwpx 템플릿 파일로 관리한다. 템플릿은 MCP Filesystem의 지정 경로(`/templates/official_docs/`)에 저장하며, 에이전트 실행 시 동적으로 로드한다. 시스템 프롬프트에 템플릿 내용을 직접 삽입하지 않아 컨텍스트 과부하를 방지한다.

**관리 템플릿 목록:**

| 템플릿 ID | 공문 유형 | 주요 사용 도메인 |
|-----------|----------|----------------|
| `TPL-001` | 내부결재 기안문 (기본형) | 전 도메인 |
| `TPL-002` | 계획 수립 보고 | D-02, E-01 |
| `TPL-003` | 강사 모집 공고 | D-03, E-02 |
| `TPL-004` | 모집 결과 보고 | D-03, E-02, E-03 |
| `TPL-005` | 강사 선정 결과 보고 | D-03, E-02 |
| `TPL-006` | 수강생 모집 공고 | E-03 |
| `TPL-007` | 수강생 모집 결과 보고 | E-03 |
| `TPL-008` | 강사비 지급 내역 보고 | E-04 |
| `TPL-009` | 최종 결과 보고 | D-05, E-05 |
| `TPL-010` | 자료 구입 건의 | B-01 |
| `TPL-011` | 순회문고 운영 보고 | D-06 |

> 템플릿이 없는 유형 요청 시, `TPL-001` 기본형을 기반으로 생성하고 사서에게 양식 추가 등록을 권고한다.

### F-02 기안문 구조 생성

경상남도교육청 기안문 표준 구조에 따라 본문을 구성한다.

**기안문 표준 구조:**

```
수신: 내부결재
(경유)
제목: ○○○

1. 관련: [관련 공문 번호 및 날짜]
2. [추진 배경 또는 목적] (개조식)
3. [세부 내용 또는 결과] (개조식, 표 포함 가능)
   가. 항목1: ...
   나. 항목2: ...
4. 향후 계획 (해당 시)

붙임: ○○○ 1부. 끝.
```

**개조식 작성 원칙:**
- 명사형 또는 동사 명사화로 종결 ("~임", "~함", "~예정임")
- 불필요한 수식어 제거, 사실 위주 기술
- 수치는 아라비아 숫자 사용, 단위 명시

### F-03 hwpx 파일 생성 (hwpx-autofill-conversion 스킬 기반)

**처리 흐름:**

1. MCP Filesystem에서 해당 공문 유형의 hwpx 템플릿 로드
2. hwpx 압축 해제 → `Contents/section0.xml` 파싱
3. `<hp:t>` 태그 내 플레이스홀더 식별 (예: `{{제목}}`, `{{본문1}}`, `{{붙임}}`)
4. 사서 또는 호출 에이전트가 전달한 내용으로 플레이스홀더 치환
5. `Preview/PrvText.txt` 미리보기 텍스트 업데이트
6. hwpx 재패키징 (`mimetype` 파일을 zip 루트에 포함)
7. 완성 파일을 `/outputs/` 경로에 저장

**파일명 규칙:**
```
[날짜]_[공문유형]_[대상또는제목요약].hwpx
예: 20260511_강사선정결과보고_2026상반기평생학습.hwpx
```

**Human-in-the-loop 필수:** 생성된 hwpx 초안은 사서가 한글 프로그램에서 반드시 검토·수정 후 결재 상신한다. 에이전트는 초안만 제공하며 결재 처리를 대행하지 않는다.

---

### F-04 기안문 불필요 공문 식별 및 안내

일부 공문은 기안문 없이 별도 문서만 작성하거나 구두 처리가 적절한 경우가 있다. 에이전트는 요청 내용을 분석하여 기안문이 불필요한 경우 사서에게 안내한다.

**기안문 불필요 유형 (확정 사례):**

| 유형 | 처리 방식 |
|------|----------|
| 강사 섭외 문자 | 문자·이메일 초안 직접 생성 (기안문 없음) |
| 범죄경력조회 요청 | 관련 기관 지정 양식 사용 (기안문 없음) |
| 이용자 안내 문자 | 문자 초안 직접 생성 (기안문 없음) |

## 8. 제약 및 예외 처리

| 상황 | 처리 방식 |
|------|----------|
| 요청 유형에 맞는 템플릿 없음 | TPL-001 기본형 사용 후 사서에게 신규 템플릿 등록 권고 |
| hwpx 재패키징 실패 | .txt 또는 .docx 대안 제공 후 사서에게 상황 안내 |
| 플레이스홀더 불일치 | 미치환 항목 목록화 후 사서에게 수동 입력 요청 |
| 기안문 불필요 유형 요청 | 기안문 대신 적합한 문서 형식으로 안내 후 처리 |
| 개조식 종결 형태 오류 | 생성 후 검토 항목으로 사서에게 명시 |

## 9. 비기능 요구사항

- hwpx 파일은 한글 2020 이상에서 정상 열람 가능해야 한다.
- 파일명에 날짜·유형·요약을 포함하여 사서가 파일 목록에서 즉시 식별할 수 있어야 한다.
- 생성 파일은 `/outputs/official_docs/YYYY/MM/` 경로 구조로 연월별 정리 저장한다.
- 에이전트 응답 언어: 한국어

---

## 10. 템플릿 추가·수정 절차

공문 양식이 변경되거나 신규 유형이 필요한 경우:

1. 사서가 신규 hwpx 템플릿 파일을 `/templates/official_docs/`에 배치
2. 템플릿 내 플레이스홀더를 `{{항목명}}` 형식으로 표시
3. F-01 템플릿 목록에 새 항목 등록 (에이전트 설정 파일 수정)
4. 이후 해당 유형 요청 시 자동 적용

## 11. 향후 확장 고려사항

- 경상남도교육청 표준 공문서 양식 업데이트 시 템플릿 일괄 갱신 자동화 검토

- 결재 완료 공문 이력 관리 기능 추가 검토 (A-02 최상위이관 에이전트와 연계)

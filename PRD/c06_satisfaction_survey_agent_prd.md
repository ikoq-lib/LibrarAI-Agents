# PRD — C-06 만족도 에이전트 (Satisfaction Survey Agent)

**문서 버전:** 1.0
**작성일:** 2026-07-07
**소속 도메인:** D2 이용자
**에이전트 ID:** C-06
**에이전트 유형:** Leaf Agent

---

> **표기 안내:** 이 문서의 `FN-01`, `FN-02`... 는 C-06 에이전트 내부 기능(Function) 번호다. 본문에 등장하는 `DM-03`·`DM-04`·`A-02`는 실제 에이전트 참조다. (구 `D-05`·`E-05`는 2026-07-07 각각 DM-03·DM-04로 흡수되어 결번 처리됨)

---

## 1. 개요

### 1.1 목적

C-06 만족도 에이전트는 도서관 이용자의 만족도를 조사·집계하는 에이전트다. 키오스크(음성+터치)에서 도서관 서비스 전반에 대한 상시 만족도를 수집하고, 평생학습 강좌·독서동아리·행사 등 개별 프로그램이 종료되면 DM-03·DM-04의 요청에 따라 프로그램 전용 설문을 생성·수집해 결과를 되돌려준다.

### 1.2 배경

프로그램별 만족도는 그동안 각 운영 에이전트(D-01, E-04 등)가 개별적으로 처리하거나 아예 수집하지 않았다. C-06은 설문 설계·배포·집계 로직을 단일 에이전트로 일원화하여, 어떤 프로그램이든 동일한 기준으로 만족도를 비교할 수 있게 한다.

> **C-06 vs C-01 FAQ 역할 구분**
> C-01은 이용자의 질문에 답하는 에이전트이고, C-06은 이용자에게 반대로 질문(설문)해 의견을 수집하는 에이전트다. 두 에이전트 모두 키오스크 음성+터치 인터페이스를 사용하지만 상호작용 방향이 다르다.

### 1.3 범위

- **포함:** 도서관 서비스 전반 상시 만족도 설문 제공·수집, 프로그램 종료 후 전용 설문 생성·수집(DM-03·DM-04 요청), 응답 집계(평균 점수·응답률·주관식 의견 요약), 정기/프로그램별 만족도 리포트 생성, A-02·DM-03·DM-04에 표준 만족도 데이터 제공
- **제외:** 설문 결과에 따른 정책·프로그램 개선 결정(사서·관장 고유 권한), 개별 이용자 응대(C-01 담당), 설문 대상자 개별 독려·리마인드 발송(사서 담당)

---

## 2. 업무 흐름 (Workflow)

```
[상시 운영]
이용자 → 키오스크: 이용 후 상시 만족도 설문 응답 (선택)
C-06: survey_responses 저장 (FN-02)

[프로그램 종료 시]
DM-03 또는 DM-04 → C-06: 프로그램 만족도 조사 요청 (프로그램명, 대상, 수집 기간)
C-06: 전용 설문 템플릿 생성 (FN-03) → 수집 기간 동안 응답 수집
C-06: 집계 (FN-04) → DM-03/DM-04에 결과 반환

[사서 요청 시]
사서 → C-06: "이번 분기 만족도 리포트 만들어줘"
C-06: 대상 기간·프로그램 집계 → 리포트 제시 (FN-05)

[A-02 정기 수집]
A-02 → C-06: 표준 데이터 수집 요청
C-06 → A-02: 만족도 지표 응답 (FN-06, 자동)
```

---

## 3. 기능 요구사항

### FN-01 설문 문항 제공

**기본 템플릿(도서관 서비스 전반, 상시):** 종합 만족도(5점 척도), 직원 응대, 자료 다양성, 시설 환경, 자유 의견(선택 입력)

**프로그램 전용 템플릿(요청 시 생성):** 종합 만족도(5점 척도), 강사/진행자 만족도(해당 시), 프로그램 구성·난이도 적합성, 재참여 의향, 자유 의견

신규 템플릿 문항 구성은 사서 확인을 거쳐 확정한다.

---

### FN-02 키오스크 상시 설문 수집

이용자가 키오스크 이용 종료 시점에 선택적으로 응답할 수 있도록 짧은 상시 설문(문항 3~4개, 1분 이내 응답 가능)을 제공한다. 음성·터치 입력 모두 지원하며, 응답은 익명으로 `survey_responses`에 저장한다.

---

### FN-03 프로그램 전용 설문 생성 (DM-03·DM-04 연계)

DM-03(독서문화 도메인) 또는 DM-04(평생학습 도메인)가 프로그램 종료를 알리며 만족도 조사를 요청하면 전용 설문을 생성한다.

**요청 형식:**
```json
{
  "requester_agent": "DM-04",
  "program_id": "[프로그램 식별자]",
  "program_name": "[프로그램명]",
  "target_audience": "[대상]",
  "collection_period_days": 14
}
```

수집 기간 동안 대상 프로그램 참여자에게 안내(사서가 문자·안내문 등으로 별도 배포)된 설문 링크 또는 키오스크 코드로 응답을 수집한다. C-06은 배포 자체를 수행하지 않으며, 설문 생성과 응답 집계만 담당한다.

---

### FN-04 응답 집계

수집 기간 종료 후(또는 사서 요청 시) 다음을 산출한다:
- 문항별 평균 점수(5점 척도)
- 응답률(대상자 수 대비, 대상자 수가 제공된 경우)
- 자유 의견 주요 키워드 요약(빈도 상위 표현)

**최소 표본 기준:** 응답 수가 5건 미만이면 "표본 부족 — 참고용" 문구를 결과에 함께 표기한다.

---

### FN-05 만족도 리포트 생성

사서 요청 시 기간·프로그램 범위를 지정해 리포트를 제시한다.

**출력 형식:**
```
[만족도 조사 결과 — 대상: (프로그램명 또는 "도서관 서비스 전반"), 기간: YYYY-MM-DD ~ YYYY-MM-DD]

응답 수: N건 (응답률: X%, 표본 5건 미만 시 "참고용" 표기)
종합 만족도 평균: X.X / 5.0
문항별 평균: [문항1] X.X, [문항2] X.X, ...
주요 의견 요약: [키워드1], [키워드2], ...
```

공식 문서(공문) 형태가 필요하면 사서 요청 시에만 A-01을 호출한다.

---

### FN-06 표준 데이터 제공 (DM-03·DM-04·A-02 연계)

요청 에이전트에 다음 형식으로 응답한다:

```json
{
  "agent_id": "C-06",
  "program_id": "[해당 시]",
  "period": "[기간]",
  "response_count": 0,
  "avg_score": 0.0,
  "response_rate": null,
  "low_sample_warning": false,
  "top_comments_keywords": ["...", "..."]
}
```

사서 개입 없이 자동으로 응답한다.

## 4. 비기능 요구사항

| 항목 | 기준 |
|------|------|
| 익명성 | 개별 응답자 식별 정보를 수집·저장하지 않는다(익명 집계 원칙) |
| 자동 처리 범위 | 상시 설문 수집(FN-02), 표준 데이터 응답(FN-06)은 사서 개입 없이 자동 처리 |
| Human-in-the-loop | 신규 프로그램 전용 문항 확정, 공식 문서화(A-01 호출) 여부는 사서 확인 필요 |
| 표본 신뢰도 표기 | 응답 수 5건 미만인 결과는 반드시 "참고용" 경고를 함께 제시 |

| `survey_responses` | 응답(템플릿 참조, 프로그램 참조, 점수, 자유 의견, 제출 일시) — 익명 |

## 6. 도구 및 MCP 연동

| 도구 / 에이전트 | 사용 시점 |
|----------------|---------|
| MCP SQLite | `survey_templates`·`survey_responses` 저장·조회 |
| DM-03 독서문화 도메인 에이전트 | 독서문화 프로그램 만족도 조사 요청·결과 제공 (FN-03, FN-06) |
| DM-04 평생학습 도메인 에이전트 | 평생학습 프로그램 만족도 조사 요청·결과 제공 (FN-03, FN-06) |
| A-02 최상위이관 에이전트 | 정기 만족도 통계 제공처 (FN-06) |
| A-01 공문서 에이전트 | 리포트를 공문 형태로 별도 필요 시에만 호출 |

외부 API 연동 없음.

## 7. 수용 기준 (Acceptance Criteria)

- **AC1**: 키오스크 상시 설문은 3~4개 문항, 1분 이내 응답 가능한 형태로 제공된다.
- **AC2**: DM-03·DM-04의 프로그램 전용 설문 요청 시 전용 템플릿이 생성되고, 지정된 수집 기간 동안 응답이 집계된다.
- **AC3**: 응답 수가 5건 미만인 결과에는 반드시 "참고용" 경고가 포함된다.
- **AC4**: 응답 데이터에 개별 식별 정보가 저장되지 않는다.
- **AC5**: A-02·DM-03·DM-04 요청에 사서 개입 없이 표준 형식으로 자동 응답한다.

---

## 8. 미결 사항 (Open Questions)

1. **프로그램 전용 설문 배포 경로**: 참여자에게 설문 링크·코드를 실제로 전달하는 채널(문자, 이메일, 키오스크 코드 등)을 어느 에이전트가 담당할지 확정 필요 — 현재는 사서가 직접 배포하는 것으로 가정.
2. **키오스크 상시 설문 노출 빈도**: 매 이용 종료 시 노출할지, 일정 주기(예: 이용자당 월 1회)로 제한할지 결정 필요 — 과도한 노출로 인한 응답 피로 방지.
3. **정성 의견(자유 응답) 분석 고도화**: 현재는 키워드 빈도 기반 요약이며, 향후 감성 분석 등으로 고도화할지는 운영 데이터 축적 후 검토.

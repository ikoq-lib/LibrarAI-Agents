# PRD — C-03 프로그램안내 에이전트 (Program Information Agent)

**문서 버전:** 1.0
**작성일:** 2026-07-04
**소속 도메인:** D2 이용자
**에이전트 ID:** C-03
**에이전트 유형:** Leaf Agent
**참조 아키텍처:** 도서관 사서 AI 에이전트 시스템 v3

---

> **표기 안내:** 이 문서의 `FN-01`, `FN-02`... 는 C-03 에이전트 내부 기능(Function) 번호다. 본문에 등장하는 `F-04 소식지`(1.2 배경·1.3 비교표)는 F-04 소식지 에이전트를 가리키는 실제 에이전트 참조이며, 다른 에이전트의 기능을 인용할 때(예: D-01 FN-08)는 해당 에이전트 PRD의 기능 번호를 가리킨다.

---

## 1. 개요

### 1.1 목적

C-03 프로그램안내 에이전트는 이용자가 키오스크(음성+터치 입력)에서 도서관이 운영 중이거나 예정인 프로그램 — 독서동아리(D-01), 독서문화 행사(D-02), 순회문고(D-06), 평생학습 강좌(E-01·E-03) — 에 대해 실시간으로 질문하면, 해당 운영 에이전트로부터 최신 정보를 조회하여 안내하는 리프 에이전트다.

### 1.2 배경

F-04 소식지 에이전트는 월간·계간 정기 발행물로 이미 지나간 활동의 하이라이트와 다음 호 예고를 다룬다. 반면 이용자는 "이번 주 무슨 행사 있어요?", "캘리그라피 강좌 아직 신청할 수 있어요?"처럼 **그 순간의 실시간 정보**를 궁금해한다. 이런 질문에 정확히 답하려면 정적 문서가 아니라 각 프로그램 운영 에이전트에 매번 최신 상태를 조회해야 한다. C-03은 이 실시간 조회·안내 창구 역할을 한다.

### 1.3 다른 에이전트와의 구분

| 구분 | 정보 성격 | 갱신 시점 | 상호작용 방식 |
|------|---------|---------|-------------|
| **C-03 (이 문서)** | 프로그램 일정·신청 현황 등 동적 정보 | 질의 시점에 실시간 조회 | 이용자 즉석 질의응답 |
| F-04 소식지 | 지난 활동 하이라이트 + 예고 | 월간/계간 정기 발행 | 발행물 열람 |
| C-01 FAQ | 대출·회원가입 등 정적 정책·시설 정보 | 사서가 지식베이스 갱신 시 | 이용자 즉석 질의응답 |

C-01과 C-03은 둘 다 키오스크 질의응답이지만, C-01은 **바뀌지 않는 규정성 정보**(지식베이스 문서 기반)를, C-03은 **매번 바뀌는 운영 현황**(각 도메인 에이전트 실시간 조회)을 다룬다는 점에서 지식 소스와 갱신 방식이 다르다.

### 1.4 범위

- **포함:** 진행 중·예정 프로그램 통합 조회·안내, 프로그램 상세 정보(대상·기간·장소·비용·신청방법) 안내, 신청 가능 여부·마감일 안내, 대상 연령별 필터링, 실제 신청 경로(홈페이지·담당 창구) 안내
- **제외:** 실제 신청·접수 처리(각 도메인 에이전트 및 사서 담당), 결제 처리, 개인별 신청 이력 조회, 프로그램 기획·구성 변경(D-01·D-02·E-01 담당)

## 4. 기능 요구사항

### FN-01 진행 중·예정 프로그램 통합 조회

이용자가 "요즘 무슨 프로그램 있어요?" 같은 포괄적 질문을 하면, D-01·D-02·D-06·E-01에 표준 조회 요청을 보내 응답을 통합하여 안내한다.

**조회 요청 구조 (C-03 → 각 소스 에이전트):**
```json
{
  "requester_agent": "C-03",
  "request_type": "current_program_status"
}
```

**소스별 기대 응답 항목:**

| 소스 | 응답 항목 |
|------|---------|
| D-01 동아리 | 동아리명, 대상, 모집 중 여부, 다음 회차 일정 (D-01 PRD FN-08 인터페이스 재사용) |
| D-02 행사기획 | 이번 달 행사명, 대상, 일정, 신청 방법 |
| D-06 순회문고 | 서비스 개요, 신청 방법 (기관 대상 서비스이므로 개인 이용자에게는 간략 안내만) |
| E-01 강좌기획 | 이번/차기 시즌 강좌명, 대상, 일정 |
| E-03 모집 | 강좌별 잔여 정원, 모집 마감일 |

**출력 형식 예시:**
```
[이번 달 도서관 프로그램]

📖 독서동아리
 · 목요 성인 독서모임 — 모집 중 (매주 목 14:00)

🎉 행사
 · 여름밤 그림책 낭독회 — 7/18(금) 19:00, 신청: 홈페이지

🎓 평생학습 강좌
 · 캘리그라피 — 신청 가능 (잔여 3자리, 마감 7/20)
 · 쿠킹클래스 — 마감 임박 (잔여 1자리, 마감 7/12)
```

---

### FN-02 프로그램 상세 안내

이용자가 특정 프로그램명을 언급하면 해당 프로그램의 상세 정보를 안내한다.

**안내 항목:** 대상, 운영 기간·시간, 장소, 비용(무료/유료), 신청 방법, 문의처

---

### FN-03 신청 가능 여부·마감 안내

평생학습 강좌의 경우 E-03 모집 에이전트로부터 잔여 정원과 마감일을 조회하여 안내한다.

**마감 임박 강조:** 마감 3일 이내인 경우 "마감 임박"으로 강조 표시한다.

**정원 마감 시:** "현재 정원이 마감되었습니다. 대기 신청이 가능한지 담당자에게 문의해주세요."로 안내한다.

---

### FN-04 대상 연령별 필터링

이용자가 특정 대상(어린이·청소년·성인)을 명시하거나 자료실 맥락(예: 어린이자료실 키오스크)에 따라 해당 대상에 맞는 프로그램만 필터링하여 안내한다.

---

### FN-05 신청 경로 안내

프로그램 신청은 C-03이 직접 처리하지 않고, 올바른 신청 경로(홈페이지 신청 페이지, 담당 자료실 방문·전화)로 안내한다.

> ⚠️ C-03은 정보 제공까지만 담당하며, 실제 신청·접수는 각 도메인 에이전트 또는 사서가 처리한다.

---

### FN-06 소스 미응답 처리

조회 요청에 응답이 없는 소스가 있으면 해당 항목을 생략하고 안내에 "일부 프로그램 정보는 확인 중"이라는 문구를 포함한다.

---

## 5. 데이터 흐름

```
[이용자 질문]
이용자 → C-03: "요즘 무슨 프로그램 있어요?" / "○○ 강좌 신청 가능해요?"

C-03 → D-01·D-02·D-06·E-01: 현재 프로그램 현황 조회 요청
D-01·D-02·D-06·E-01 → C-03: 응답 (또는 미응답)

특정 강좌 신청 여부 질문 시:
C-03 → E-03: 강좌별 신청 현황 조회
E-03 → C-03: 잔여 정원·마감일 응답

C-03: 대상 연령 필터링 → 통합 안내 생성 → 이용자에게 응답
필요 시 → 신청 경로 안내 (FN-05)
```

## 8. 제약 및 예외 처리

| 상황 | 처리 방식 |
|------|----------|
| 소스 에이전트 응답 지연·미응답 | 해당 항목 생략, "확인 중" 안내 |
| 이용자가 언급한 프로그램명이 여러 개와 유사 | 후보 목록 제시 후 재확인 요청 |
| 정원 마감된 강좌 문의 | 마감 안내 + 대기 신청 가능 여부는 담당자 문의로 안내 |
| 순회문고 등 기관 대상 서비스에 개인 이용자가 문의 | 서비스 성격(기관 대상)을 안내하고, 개인 이용은 대상이 아님을 명확히 함 |
| 라우팅 대상 에이전트가 아직 미구현 상태 | 해당 정보는 현재 사서에게 직접 문의하도록 안내 |

## 9. 비기능 요구사항

- 키오스크 상호작용 특성상 응답은 지연 없이 즉시 제공되어야 한다.
- 동일 질의에 대한 반복 조회 부담을 줄이기 위해 짧은 주기(예: 수 분 단위)로 캐시를 활용할 수 있다.
- 에이전트 응답 언어: 한국어

## 11. 향후 확장 고려사항

- 이용자가 특정 프로그램에 대해 알림(리마인더)을 받고 싶어 할 경우 알림 신청 기능 검토 (실행은 별도 알림 채널 필요)
- 프로그램 인기도(FN-01 조회 빈도) 데이터를 D-02·E-01 기획에 참고 자료로 제공하는 방안 검토
- 키오스크 위치(자료실)에 따라 첫 화면에 관련 프로그램을 자동 노출하는 기능 검토

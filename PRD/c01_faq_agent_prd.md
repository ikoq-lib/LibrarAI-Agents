# PRD — C-01 FAQ 에이전트 (Library FAQ & Wayfinding Agent)

**문서 버전:** 1.0
**작성일:** 2026-07-04
**소속 도메인:** D2 이용자
**에이전트 ID:** C-01
**에이전트 유형:** Leaf Agent
**참조 아키텍처:** 도서관 사서 AI 에이전트 시스템 v3

---

## 1. 개요

### 1.1 목적

C-01 FAQ 에이전트는 이용자가 키오스크(음성+터치 입력) 또는 유사 인터페이스를 통해 묻는 도서관 이용안내 질문 — 대출·반납 규정, 회원가입, 운영시간·휴관일, 연체, 시설 이용규칙 등 — 에 RAG(검색 증강 생성) 방식으로 답변하는 리프 에이전트다. 2026-07-04 구조 개편으로 자료실·시설 위치 안내(구 C-02 위치 에이전트)도 이 에이전트에 통합되었다.

### 1.2 배경

도서관 이용안내 질문은 정형화되어 있고 반복적이다. 창녕도서관의 경우 `References/library_info.md` 문서가 이미 이런 질문에 대응하도록 설계되어 있다 — 각 섹션에 RAG 청크 식별자(`chunk_id`)와 질의 의도 태그(`intent`, 예: `대출_권수_기간`·`회원가입_방법`·`시설_위치_문의`)가 붙어 있고, 44개 이상의 Q&A 쌍으로 구성된 전용 FAQ 섹션도 포함되어 있다. C-01은 이런 형태의 지식베이스 문서를 지식소스로 삼아 이용자 질문에 즉시 답변한다.

구 C-02(위치)를 별도 에이전트로 유지하지 않은 이유는, 위치 안내 질문(`시설_위치_문의`·`화장실_위치`·`자료실_위치` 등)이 이미 동일한 지식베이스 문서에 동일한 방식(RAG 질의응답)으로 포함되어 있어, 별도 에이전트로 분리할 기술적 근거가 부족했기 때문이다.

### 1.3 범용 설계 원칙

- 지식베이스 문서(`library_info.md` 등)는 기관마다 다르므로 **Config로 지식소스 파일 경로를 주입**한다. PRD 본문에 특정 도서관의 시설·규정을 하드코딩하지 않는다.
- 지식베이스 문서는 사서가 직접 작성·갱신하는 1차 자료이며, C-01은 이를 그대로 신뢰하고 답변을 생성한다. 지식베이스에 없는 내용을 임의로 추정하지 않는다.

### 1.4 범위

- **포함:** 이용안내 RAG 질의응답(대출·반납·연체·회원가입·운영시간·시설이용규칙 등), 자료실·시설 위치 안내(층별 배치, 오시는 길), 지식베이스 범위를 벗어난 질문의 타 에이전트 라우팅 안내, 미답변 질의 에스컬레이션
- **제외:** 실제 대출·반납·연장 처리(RFID/LMS 키오스크 하드웨어 담당, 현재 실시간 OPAC 연동 없음 — CLAUDE.md Pending Issues 참조), 개인화 도서 추천(C-02 담당), 프로그램 신청·모집 현황 처리(C-03·E 시리즈 담당), 상호대차·외부도서서비스 신청 처리(C-04·C-05 담당)

## 4. 기능 요구사항

### FN-01 지식베이스 기반 질의응답 (RAG)

Config로 지정된 지식베이스 문서(예: `library_info.md`)를 검색하여 이용자 질문에 답변한다.

**처리 흐름:**
1. 이용자 질문 수신 (음성 또는 터치 입력)
2. 질문의 의도(intent)를 지식베이스 문서의 `intent` 태그와 매칭하거나, 매칭되는 태그가 없으면 `chunk_id` 단위 유사도 검색 수행
3. 검색된 청크 내용을 기반으로 자연스러운 문장으로 답변 생성
4. 지식베이스에 이미 준비된 FAQ 섹션(Q&A 쌍)이 있는 경우 우선 활용

**답변 원칙:**
- 지식베이스에 명시된 내용만 답변하며, 없는 정보는 추정하지 않는다.
- 수치(대출 권수·기간·금액 등)는 지식베이스 원문 그대로 인용한다.
- 여러 청크에 걸친 정보(예: 대출 규정 + 연체 규정)는 통합하여 답변한다.

**응답 예시:**
```
Q. 책은 한 번에 몇 권까지 빌릴 수 있어요?
A. 도서는 1인 10권을 2주(14일) 동안 대출할 수 있어요. 1회 1주일 연기도 가능한데,
   예약된 자료는 연기가 안 되니 참고해주세요.
```

---

### FN-02 자료실·시설 위치 안내 (구 C-02 통합)

시설·자료실 위치, 층별 배치, 오시는 길 관련 질문에 답변한다. FN-01과 동일한 RAG 방식을 사용하되, 위치 정보 특성상 다음을 포함한다.

**응답 포함 요소:** 건물(본관/별관)·층·이용 대상·이용시간(해당 시)

**응답 예시:**
```
Q. 어린이자료실은 어디에 있어요?
A. 어린이자료실은 본관 1층에 있어요. 다문화자료실도 같은 층에 있고,
   유아와 초등학생이 이용할 수 있는 공간입니다.
```

> 향후 터치스크린 지도 하이라이트 등 시각적 안내로 확장할 수 있으나(11장 참고), 현재는 텍스트/음성 응답으로 처리한다.

---

### FN-03 범위 밖 질문 라우팅

C-01의 지식베이스 범위를 벗어나는 질문(개인화 추천, 프로그램 신청 처리, 상호대차·외부서비스 신청 처리 등)은 적절한 에이전트로 안내한다.

**라우팅 기준:**

| 질문 성격 | 안내 대상 |
|----------|---------|
| "나한테 맞는 책 추천해줘" 등 개인화 도서 추천 | C-02 추천 |
| 프로그램 신청 현황·모집 마감일 등 실시간 프로그램 문의 | C-03 프로그램안내 |
| 상호대차 신청·처리 현황 | C-04 상호대차 |
| 책나래·책바다·택배대출 신청 | C-05 외부도서서비스 |
| 실시간 특정 도서 대출 가능 여부 | 현재 미지원 — 자료실 방문 또는 홈페이지 검색 안내 (OPAC 미연동) |

라우팅 시 C-01이 직접 처리하지 않고, "○○ 관련 질문은 △△에서 안내해드릴게요" 형태로 안내만 수행한다.

---

### FN-04 미답변 질의 에스컬레이션

지식베이스에 없는 질문이나 의도가 불분명한 질문은 사서 문의 채널로 안내한다.

**처리 방식:** 지식베이스 문서에 이미 정의된 문의처(예: "사서에게 물어보세요" 홈페이지 게시판, 자료실 전화번호)를 안내한다.

**로그 기록:** 에스컬레이션된 질문은 `unanswered_queries` 테이블에 기록하여, 사서가 주기적으로 검토 후 신규 FAQ 항목으로 지식베이스에 추가할 수 있도록 한다.

> ⚠️ **Human-in-the-loop 필수:** 미답변 질문에 대한 신규 지식베이스 항목 추가는 사서가 직접 문서를 수정한다. 에이전트가 임의로 지식베이스를 수정하지 않는다.

---

### FN-05 지식베이스 갱신 반영

사서가 지식베이스 문서를 갱신(버전 상승, `last_updated` 갱신)하면 다음 질의응답부터 최신 내용을 반영한다. 별도의 재색인 절차가 필요한 경우 이를 사서에게 안내한다.

---

## 5. 데이터 흐름

```
[이용자 질문 발생]
이용자 → C-01: 질문 (음성/터치)
C-01: 지식베이스 검색 (intent 매칭 또는 유사도 검색)

  → 답변 가능 (FN-01/FN-02): 자연어 응답 생성 → 이용자에게 응답
  → 범위 밖 질문 (FN-03): 해당 에이전트 안내 → 이용자에게 라우팅 메시지
  → 답변 불가 (FN-04): 사서 문의처 안내 + unanswered_queries 기록

[정기]
사서: 지식베이스 문서 검토·갱신
사서 → C-01: unanswered_queries 검토 후 신규 FAQ 반영 여부 결정
```

## 6. MCP 도구 연동

| 도구 | 용도 |
|------|------|
| MCP Filesystem | 지식베이스 문서(`library_info.md` 등) 로드 |
| MCP SQLite | `unanswered_queries` 테이블 (미답변 질의 로그) |

외부 API 연동 없음. 실시간 OPAC(대출 가능 여부 등) 연동 없음 — 이용자에게는 미지원 안내로 처리한다.

## 7. Human-in-the-loop 정책

| 단계 | 사서 개입 여부 | 내용 |
|------|--------------|------|
| 지식베이스 기반 질의응답 | 불필요 | 자동 응답 |
| 위치 안내 | 불필요 | 자동 응답 |
| 범위 밖 질문 라우팅 | 불필요 | 자동 안내 |
| 미답변 질의 에스컬레이션 | 불필요 | 자동으로 문의처 안내, 로그만 기록 |
| 신규 FAQ 항목 추가 | **필수** | 사서가 지식베이스 문서 직접 수정 |
| 지식베이스 갱신 | **필수** | 사서 직접 관리 |

## 8. 제약 및 예외 처리

| 상황 | 처리 방식 |
|------|----------|
| 지식베이스에 없는 질문 | "사서에게 물어보세요" 문의처 안내 + 로그 기록 (FN-04) |
| 질문 의도가 여러 카테고리에 걸침 | 관련된 모든 청크 정보를 통합하여 답변 |
| 지식베이스 문서 로드 실패 | 사서에게 즉시 알림, 기본 문의처 안내로 대체 응답 |
| 실시간 대출 가능 여부·재고 질문 | 미지원 안내 후 자료실 방문 또는 홈페이지 검색 권고 |
| 라우팅 대상 에이전트가 아직 미구현(PRD 미작성) 상태 | 해당 업무는 현재 사서에게 직접 문의하도록 안내 |

## 9. 비기능 요구사항

- 키오스크 상호작용 특성상 응답은 지연 없이 즉시 제공되어야 한다.
- 음성 입력·출력을 지원하는 환경을 고려하여 응답 문장은 낭독하기 자연스러운 구어체로 구성한다.
- 지식베이스 문서의 `review_cycle`(예: 연 1회)에 맞춰 사서에게 정기 갱신 필요 여부를 상기시킨다.
- 에이전트 응답 언어: 한국어 (다국어 지원은 향후 확장 검토 항목)

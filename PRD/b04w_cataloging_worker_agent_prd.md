## 1. 개요

### 1.1 목적

B-04-W 자료조직 워커 에이전트는 도서 **1건 단위**로 KDC(한국십진분류법) 6판 주제 분류와 KORMARC 서지 레코드 기술을 수행하는 전문 에이전트다. 분류 정확도가 최우선이므로 한 번에 한 권씩 완결 처리하며, 여러 권을 한 번에 처리해야 하는 배치 오케스트레이션은 B-04-H가 전담한다.

### 1.2 배경

도서관 자료조직 업무는 신간 입고 시마다 주제를 분석해 청구기호를 부여하고 KORMARC 표준에 맞춰 서지 정보를 기술하는 반복 전문 작업이다. 분류 판단에는 도서의 제목·목차·요약 등 맥락 정보를 깊이 이해해야 하므로, 여러 권을 동시에 처리하기보다 한 권씩 신중하게 판단하는 구조가 정확도에 유리하다. B-04-W는 이 개별 처리를 전담하고, 대량 입고 시의 진행 관리·QA 재검증은 B-04-H가 감싸는 구조로 역할을 분리한다.

### 1.3 범위

- **포함:** 도서 1건 기준 KDC 분류번호 결정, 리재철 저자기호(도서기호) 생성, `090` 청구기호 구성, KORMARC 레코드 기술(주요 필드), 자체 QA 체크리스트 검증
- **제외:** 여러 권의 배치 접수·순차 위임·재시도(B-04-H 담당), 도서 선정·구입 결정(B-01 담당), 복본 판정(B-03 담당), 서가 실제 배치·라벨 부착(사서 담당)

### FN-02 KDC 주제 분류 결정

**절차:**
1. 제목·부제·목차·요약을 분석해 주제를 파악한다. **ISBN 부가기호의 내용분류를 KDC로 그대로 옮기지 않는다** — 출판사 신고값이라 실제 내용과 자주 어긋난다.
2. `References/KDC6_for_learning.txt`의 **본표**에서 강목·요목·세목을 직접 확인한다. 요목표에는 세목이 없어 요목표만 보면 오분류한다.
3. 표로 해결되지 않으면 학습된 KDC 6판 지식을 적용하되, 표에서 확인한 것과 기억으로 채운 것을 메모에서 구분한다.
4. 복수 주제가 동등하게 두드러지면 **주제 우선 원칙**에 따라 대표 주제의 분류를 선택한다.
5. 항상 가장 구체적인(세목 수준 이상) 분류번호를 우선한다 — 단 6-1의 자관 관행 확인을 거친 뒤에.
6. 한국문학(810)은 문학형식을 셋째 자리로 구분한다(시 811, 희곡 812, 소설 813, 수필 814). 그 아래 세목은 표를 직접 확인한다 — `813.8 동화(우화 포함)`는 시대구분이 아니라 형식 구분이다.
6-1. **자관 관행 교차검증(확정 전 필수)** — KDC6는 별법(선택 세분)을 다수 제공하고 우리 관은 일부만 채택했다. 확정 전 `public.books`에서 같은 강목의 세목 분포를 조회해 자관이 실제 쓰는 값을 따르고, 표와 어긋나면 근거 수치를 메모에 남긴다.
7. 전기(傳記)는 원칙적으로 피전기자의 주제 분야로 분류하며, 집단 전기집만 990에 분류한다.

**다주제 도서 처리:** 주제가 3개 이상 대등하면 상위 강목으로 분류하고 판단 근거를 설명한다.

### FN-03 저자기호(도서기호) 및 청구기호 구성

**저자기호는 리재철 한글순 도서기호법 제5표를 따른다.** 전거: `References/리재철 한글순도서 기호법제 제5표.xlsx`

```
[저자명 첫 글자(한글 그대로)] + [저자명 둘째 글자의 기호] + [본표제 첫 글자(한글 그대로)]
```

**둘째 글자의 기호 = 자음기호(초성) + 모음기호(중성)**. 받침(종성)은 반영하지 않는다.

**자음기호(초성):** ㄱ·ㄲ 1 / ㄴ 19 / ㄷ·ㄸ 2 / ㄹ 29 / ㅁ 3 / ㅂ·ㅃ 4 / ㅅ·ㅆ 5 / ㅇ 6 / ㅈ·ㅉ 7 / ㅊ 8 / ㅋ 87 / ㅌ 88 / ㅍ 89 / ㅎ 9

**모음기호(중성)** — 초성이 `ㅊ`이면 전용 열을 쓴다:

| 중성 | 일반 | 초성이 ㅊ |
|------|------|----------|
| ㅏ | 2 | 2 |
| ㅐ ㅑ ㅒ | 3 | 2 |
| ㅓ ㅔ ㅕ ㅖ | 4 | 3 |
| ㅗ ㅘ ㅙ ㅚ ㅛ | 5 | 4 |
| ㅜ ㅝ ㅞ ㅟ ㅠ | 6 | 5 |
| ㅡ ㅢ | 7 | 5 |
| ㅣ | 8 | 6 |

**자릿수:** 초성이 ㄴ·ㄹ·ㅋ·ㅌ·ㅍ이면 3자리, 나머지는 2자리.

**검증 예시**(우리 도서관 실제 장서 및 자관 MARC에서 확인):

| 저자 | 표제 | 저자기호 | 산출 |
|------|------|---------|------|
| 남경환 | 거북선 | `남14거` | 경 = ㄱ 1 + ㅕ 4 |
| 윤소영 | 박물관에서 놀자 | `윤55박` | 소 = ㅅ 5 + ㅗ 5 |
| 이혜란 | 우리 가족입니다 | `이94우` | 혜 = ㅎ 9 + ㅖ 4 |
| 김창옥 | 소통 잘하는 아이가… | `김82소` | 창 = ㅊ 8 + ㅏ **2 (ㅊ 전용 열)** |
| 예림당 | 어린이 음악백과 | `예298어` | 림 = **ㄹ 29** + ㅣ 8 |
| 요코제키 다이 | 루팡의 딸 | `요875루` | 코 = **ㅋ 87** + ㅗ 5 |
| 제프 키니 | 착해도 너무 착한 롤리의 일기 | `제897착` | 프 = **ㅍ 89** + ㅡ 7 |

> **검증 근거:** 이 규칙을 장서 DB 73,390행에 적용한 결과, 저자 기준으로 기호가 부여된 49,081건 중 **42,807건(87%)이 정확히 일치**한다. 불일치 6,188건 중 39%는 마지막 자리 `±1` 편차(아래 기호 조정), 나머지는 총서·전집·전기 등 저자가 아닌 기준으로 기호가 부여된 자료다.

**기호 조정(충돌 회피):** 같은 분류번호 안에서 동일한 저자기호가 이미 존재하면 숫자 마지막 자리를 `±1` 조정한다(예: `황53마`는 규칙값 `황54마`의 조정형). 확정 전 장서 DB에서 `call_no like '<KDC> <저자기호>%'`로 확인하고, 조정했으면 메모에 남긴다.

**원칙:**
- 외국인 저자도 **한글 음역 기준**이다. 로마자 이니셜을 쓰지 않는다.
- 세 번째 자리 작품기호는 본표제 **첫 글자를 음절 그대로** 쓴다(자모 `ㅍ`이 아니라 `파`).
- 전기 자료는 피전기자 기준으로 기호를 부여하고 세 번째 자리에 저자 첫 글자를 둔다.
- 총서·전집으로 서가를 묶는 자료(예: `808.9`)는 기존 소장본의 총서 기준 기호를 따른다.
- 청구기호 = `090 __ $a[KDC 분류기호] $b[저자기호]`. 사람이 읽는 표기는 `833.6 요875루`(장서 DB `call_no` 형식과 동일).
- 권차·복본은 `090 $b`에 넣지 않고 `049 $v`·장서 DB `vol`로 관리한다.

### FN-04 KORMARC 레코드 기술

**이 도서관의 목록 정책 3가지가 다른 모든 기술 규칙에 우선한다.**

1. **기본표목(Main Entry) 미사용** — `100`·`110`·`111`을 생성하지 않는다. 모든 개인명은 `700`, 단체명은 `710`에 부출하고, 저작의 주 책임자에게만 `$4 aut`를 부여한다.
2. **청구기호는 `090`** — `052`(국립중앙도서관 청구기호)는 생성하지 않는다. 국중 052 `$b`(예: `24-414`)는 국중 **수입순** 기호라 우리 관 서가 배열과 무관하다. `056`에는 KDC 분류기호만 기술한다(`$a`분류기호 `$2`6).
3. **책임표시는 `245 $d`/`$e`** — MARC21식 `245 $c`를 쓰지 않는다.

**필수 필드:** LDR(24자리), 001(로컬 제어번호), 005, 007, 008(40자리), 020(ISBN·부가기호·정가), 040(`$a 148024 $c 148024`), 049(소장사항 — 등록번호·복본수·별치기호), 056(KDC), 090(청구기호), 245(표제사항), 260(발행사항), 300(형태사항), 650/653(주제명표목), 700/710(부출표목), 950(정가)

**조건부 필드:** 041(번역서, 지시기호 `1_`), 240·246·500·546(번역서), 250(판사항), 490/830(총서), 504·505·520·521·536, 651, 740(다권본 각 권 표제), 900(외국 저자 이형 표기), 852(소장 레코드 분리 출력 시)

**생성하지 않는 필드:** 052(국중 수입순 청구기호), 023(CIP), 082(DDC), 880(로마자 병기) — 국중 레코드를 본보기로 참조할 때 함께 복사하지 않도록 주의한다.

**지시기호 원칙:** `245`=`00`(기본표목이 없으므로 제1지시기호는 항상 0, 한글 표제는 배열 제외 문자 없으므로 제2지시기호 0) · `041`=`1_`(번역물) · `049`=`0_` · `056`=`__` · `090`=`__` · `650`=`_8`(국중 주제명표목표) · `700`=`1_` · `490`=`10` / `830`=`_0`

**ISBD 구두점:** `245 00 $a본표제 : $b부표제 / $d첫 책임표시 ; $e다음 책임표시` · `260 __ $a발행지 : $b발행처, $c발행년` · `300 __ $a면수 : $b삽화 ; $c크기 cm` · `490 10 $a총서명 ; $v권호`. 구두점은 앞 서브필드 끝에 붙인다.

**008 주요 위치:** 00-05 입력일자 / 06 `s` / 07-10 발행년 / 15-17 발행국(`ulk` 서울, `ggk` 경기 등) / 18-21 삽화 / **22 대상독자(`a` 유아, `b` 어린이, 성인 공백)** / 29-31 색인 등 / 33 문학형식(`f` 소설, `p` 시, `m` 수필·기타) / 35-37 언어 `kor`. `008/22`와 `049 $f` 별치기호(`J`/`유`), 장서 DB `room` 값은 서로 모순되지 않아야 한다.

**출력 형식(도서 1건):**
```
========== [제목] 자료조직 결과 ==========
[1. KDC 분류] 분류번호 / 분류 근거(대강→강목→요목→세목 전개) / 대표 주제어
[2. 청구기호] 청구기호 / 저자기호 산출 과정 / 별치기호
[3. KORMARC 레코드] LDR, 001, 005, 007, 008, 020, 040, 049, 056, 090, 245, 260, 300, 650, 700, 950 (+ 조건부 필드)
[4. 메모/특이사항] 판단 근거, 애매한 점, 확인 필요 사항
```

여러 권이 한 번에 전달된 경우(사서 직접 요청 시) 구분선을 두고 순차 처리한다.

### FN-05 자체 품질(QA) 체크리스트 검증

레코드 확정 전 다음을 스스로 점검한다:

1. `100`·`110`·`111`이 하나도 없다 (기본표목 미사용)
2. `052`가 없다 (국중 수입순 청구기호를 복사하지 않았다)
3. `090 $a` = `056 $a` 이고, `090 $b` 저자기호가 리재철 규칙 구조를 따른다
4. 저자기호 숫자가 리재철 제5표대로 산출되었다 (초성이 `ㅊ`이면 ㅊ 전용 모음열, ㄴ·ㄹ·ㅋ·ㅌ·ㅍ이면 3자리). 같은 분류에 동일 기호가 있으면 `±1` 조정하고 메모에 남겼다
5. 책임표시가 `245 $d`/`$e`에 있고 `$c`를 쓰지 않았다
6. `245` 지시기호가 `00`이다
7. 주 책임자에게 `700 $4aut`가 정확히 한 번 부여되었다
8. LDR이 24자리, `008`이 40자리다
9. 번역서라면 `041`이 `1_`이고 `546` 언어주기가 있다
10. `008/22` 대상독자와 `049 $f` 별치기호가 일치한다
11. `020` ISBN이 실물 ISBN-13과 일치한다
12. `650`/`653`이 최소 1개 있고 `650 $0`에 지어낸 KSH 번호가 없다
13. KDC 분류번호가 세목(3자리) 이상 수준으로 구체적이다
14. 필수 필드가 모두 존재하고 ISBD 구두점이 앞 서브필드 끝에 붙어 있다

이 체크리스트는 B-04-H가 배치 처리 시 동일 기준으로 재검증(FN-03, `PRD/b04h_cataloging_harness_agent_prd.md`)하는 근거이기도 하다.

## 4. 예외 처리

| 상황 | 처리 방식 |
|------|----------|
| 주제 불명확 | 목차·책 소개 등 추가 정보를 요청한 뒤 분류 |
| 다주제 도서(3개 이상 대등) | 상위 강목으로 분류, 판단 근거 설명 |
| 번역서 | `041 1_ $akor $h원어` + `240` 통일표제 + `246 19` 원표제 + `500 $a원저자명:` + `546` 언어주기. 원저자는 `700 $4aut`, 역자·삽화가는 `$4` 없는 `700`, 원저자 이형 표기는 `900 10` |
| 공저 | 모두 `700`에 나열하고 주 책임자에게만 `$4aut`. 기본표목이 없으므로 "첫 저자를 100에" 처리는 하지 않는다 |
| 단체 저작 | `710 __ $a단체명 $4aut` |
| 총서·다권본 | `490 10` + `830 _0`, 권차는 `245 $n`/`$p`와 `049 $v`에, 각 권 표제는 `740 02` |
| 어린이·유아 자료 | `008/22`에 `b`(어린이)/`a`(유아), `049 $f`에 `J`/`유`. 대상독자 주기가 필요하면 `521` |
| 저자기호 충돌 | 같은 분류에 동일 저자기호가 이미 있으면 마지막 자리를 `±1` 조정하고 근거를 메모에 기록 |
| 저자기호 산출 불가 | 저자명이 한 글자여서 둘째 글자가 없으면 `needs_info`로 표시해 사서 확인 요청 |
| 전자책/멀티미디어 | 인쇄 단행본 우선 처리 대상이며, 비인쇄 자료는 별도 처리 필요함을 안내 |
| ISBN 없음 | ISBN 부재 명시, 지역 제어번호만 사용 |
| KDC 분류 불확실 | 후보 2~3개를 근거와 함께 제시한 뒤 가장 적절한 것을 선택 |

## 7. 수용 기준 (Acceptance Criteria)

- **AC1**: 목차·요약 등 주제 판단 정보가 충분한 경우, 세목(3자리) 이상 수준의 KDC 분류번호를 근거와 함께 제시한다.
- **AC2**: 모든 레코드는 FN-05 체크리스트 14개 항목을 통과한 뒤 최종본으로 제시된다. 특히 `100`/`110` 부재, `052` 부재, `090 $a`=`056 $a` 일치는 예외 없이 만족해야 한다.
- **AC3**: 정보가 부족해 분류가 불가능한 경우, 임의로 분류하지 않고 필요한 항목을 구체적으로 요청한다.
- **AC4**: 다주제·번역서·공저·총서·어린이자료 등 예외 케이스는 4절의 규칙에 따라 일관되게 처리된다.
- **AC5**: 여러 권이 한 번에 전달되어도(사서 직접 요청 시) 각 권을 구분선으로 나누어 순차적으로 완결 처리한다.

## 8. 미결 사항 (Open Questions)

1. **공공데이터포털 주제명 API 연동 여부**: 국립중앙도서관 주제명표목 검증 API 스펙이 미확정이며, 확정 전까지는 워커 자체 판단으로 운영한다.
2. **B-04-H와의 인터페이스 표준화**: 현재 B-04-H가 자연어 지시로 위임하는 방식이며, 정식 JSON 스키마(B-03 방식)로 표준화할지는 운영 안정화 이후 검토 대상이다(`PRD/b04h_cataloging_harness_agent_prd.md` 10절 TBD 참조).
3. **KORMARC 출력 형식**: 최종 출력이 MarcXML/ISO 2709 등 기계가독 형식으로 확정될 경우, 현재의 사람이 읽기 쉬운 텍스트 tag-order 출력을 변환하는 로직이 추가로 필요하다.
4. **저자기호 자동 조정**: 리재철 제5표는 확보·검증되었으나(2026-08-26), 동일 기호 충돌 시의 `±1` 조정은 장서 DB 조회가 필요하다. B-04-H 배치 처리에서 이 조회를 매 건 수행할지, 배치 시작 시 한 번에 처리할지는 운영 부하를 보고 결정한다.
5. **소장 레코드 분리 출력**: 자관 MARC(`루팡의 딸.mac`)는 서지 레코드 뒤에 `004`+`852` 소장 레코드를 별도로 붙이는 구조다. 배치 출력 파일에서 이 소장 레코드를 함께 생성할지는 B-04-H 출력 형식 확정(`PRD/b04h_cataloging_harness_agent_prd.md`)과 함께 결정한다.

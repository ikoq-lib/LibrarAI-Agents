## 1. 개요

### 1.1 목적

E-05 결과보고 에이전트는 E-04 운영일지 에이전트로부터 시즌 운영 실적 데이터를 수신하여 결과보고서 hwpx 초안을 생성하는 D4 평생학습 파이프라인의 마지막 리프 에이전트다. 보고서 생성 완료 후 수강 실적 데이터를 E-01 강좌기획 에이전트에 피드백하여 다음 시즌 프로그램 추천에 반영되도록 한다.

### 1.2 배경

시즌 종료 후 결과보고서는 도서관 내부 결재 및 상위기관 보고를 위해 반드시 작성해야 하는 문서다. 복수 프로그램의 실적을 취합하고 예산 집행 현황까지 통합하는 과정이 반복적이고 시간이 많이 소요된다. E-05는 E-04 수신 데이터와 A-03 예산 데이터를 자동 취합하여 보고서 초안을 생성함으로써 이 과정을 자동화한다.

또한 E-05는 단순 보고서 생성에 그치지 않고, 수강 실적 데이터를 E-01에 피드백하는 데이터 루프를 완성한다. 이 루프를 통해 시즌이 축적될수록 E-01의 프로그램 추천 정확도가 높아진다.

### 1.3 범위

- **포함:** 시즌 결과보고서 hwpx 초안 생성, 예산 집행 현황 A-03 조회 및 보고서 반영, E-01 수강 실적 데이터 피드백, A-02 월간·연간 통계 데이터 제공
- **제외:** 강좌 운영 중 기록 (E-04 담당), 결과보고서 실제 제출·발송 (사서 직접 처리), 차기 시즌 프로그램 기획 (E-01 담당)

## 4. 기능 요구사항

### FN-01 E-04 운영 실적 데이터 수신 및 검증

E-04로부터 시즌 운영 실적 데이터를 수신하고 필수 항목 누락 여부를 검증한다.

**필수 검증 항목:**

| 항목 | 검증 기준 |
|------|---------|
| 총 진행 회차 수 | 0보다 커야 함 |
| 수강생별 출석률 | 0~100% 범위 내 |
| 수료 인원 | 등록 인원 이하 |
| 강사비 집행 회차 수 | 진행 회차 수 이하 |

**검증 실패 시:** 누락·오류 항목을 목록화하여 사서에게 E-04 재확인 요청.

---

### FN-02 예산 집행 현황 조회 (A-03 호출)

A-03 예산 에이전트에서 해당 시즌 강사비·운영물품비 집행 현황을 조회하여 보고서에 자동 반영한다.

**조회 항목:**
- 시즌별 강사비 편성액·집행액·잔액·집행률
- 운영물품비 편성액·집행액·잔액·집행률
- 도메인간 유용 발생 건수 및 금액 (해당 시)

---

### FN-03 시즌 결과보고서 초안 생성 (A-01 호출)

E-04 실적 데이터와 A-03 예산 데이터를 통합하여 결과보고서 hwpx 초안을 생성한다. 복수 프로그램은 하나의 보고서에 통합한다.

**결과보고서 구성:**

| 항목 | 형식 | 내용 |
|------|------|------|
| 1. 운영 개요 | 개조식 | 시즌명, 운영 기간, 프로그램 수, 총 정원, 장소 |
| 2. 운영 실적 | 표 | 프로그램별 정원·접수·수료·출석률·진행 회차, 합계 행 포함 |
| 3. 수강생 현황 | 표 | 총 접수·수료·중도 포기 인원, 수료율, 대상별 분류 |
| 4. 예산 집행 현황 | 표 | 강사비·운영물품비 편성액·집행액·잔액, 합계 행 포함 |
| 5. 성과 및 개선사항 | 개조식 | 잘된 점 (성과), 개선이 필요한 점 (개선사항) |

**운영 실적 표 예시:**

| 프로그램명 | 대상 | 정원 | 접수 | 수료 | 수료율 | 진행 회차 | 평균 출석률 | 비고 |
|----------|------|------|------|------|------|---------|---------|------|
| 캘리그라피 | 성인 | 15 | 14 | 12 | 85.7% | 9/10 | 88.3% | 1회 휴강·보강 |
| 북아트 | 어린이 | 12 | 12 | 11 | 91.7% | 10/10 | 92.1% | — |
| **합계** | | **27** | **26** | **23** | **88.5%** | | | |

**성과 및 개선사항 자동 생성 기준:**

| 항목 | 자동 생성 조건 | 예시 문구 |
|------|-------------|---------|
| 성과 (잘된 점) | 수료율 85% 이상 | "○○ 프로그램의 높은 수료율(○%)로 이용자 만족도 우수" |
| 성과 | 모집충족률 100% 이상 | "○○ 프로그램 조기 마감으로 지역 주민의 높은 수요 확인" |
| 개선사항 | 수료율 70% 미만 | "○○ 프로그램 수료율 저조(○%) — 프로그램 구성·시간대 재검토 필요" |
| 개선사항 | 휴강 2회 이상 | "강사 일정 관리 강화 필요 — ○○ 프로그램 ○회 휴강 발생" |
| 개선사항 | 중도 포기 3인 이상 | "수강생 지속 참여 유도 방안 마련 필요" |

> 자동 생성 문구는 초안이며 사서가 반드시 검토·수정 후 사용한다.

**Human-in-the-loop 필수:** 결과보고서 초안 생성 후 사서 검토·수정·결재 후 사용.

### FN-04 E-01 수강 실적 데이터 피드백

결과보고서 사서 확정 후 E-01 강좌기획 에이전트의 `course_history` 테이블에 수강 실적 데이터를 전달한다.

**전달 항목:**
```json
{
  "requester_agent": "E-05",
  "season": "상반기",
  "year": 2026,
  "courses": [
    {
      "program_name": "캘리그라피",
      "subject_tag": "캘리그라피",
      "target_audience": "일반 성인",
      "capacity": 15,
      "applicants": 14,
      "avg_attendance": 12.4,
      "completions": 12,
      "recruitment_rate": 93.3,
      "attendance_rate": 88.3,
      "completion_rate": 85.7,
      "composite_score": 88.7
    }
  ]
}
```

**종합 점수 계산 (E-01 기준과 동일):**
- 모집충족률 × 0.4 + 출석률 × 0.4 + 수료율 × 0.2

**전달 시점:** 결과보고서 사서 확정 직후 자동 전달.

### FN-05 A-02 통계 데이터 제공

A-02 최상위이관 에이전트의 데이터 수집 요청에 응답하여 시즌 운영 실적을 전달한다.

**제공 항목:**
- 시즌별 총 프로그램 수, 총 수강생 수, 평균 수료율, 강사비 집행액
- 특이사항 건수 (휴강·중도 포기·민원 등)

---

### FN-06 연간 누계 보고 (연말 요청 시)

사서 요청 또는 12월 말 자동 트리거 시 연간 4개 시즌 실적을 취합하여 연간 결과 요약을 생성한다.

**연간 요약 포함 항목:**

| 항목 | 내용 |
|------|------|
| 시즌별 운영 현황 표 | 시즌·프로그램 수·총 수강생·평균 수료율 |
| 연간 최고 성과 프로그램 | 종합 점수 상위 3개 |
| 연간 개선 필요 프로그램 | 종합 점수 하위 3개 |
| 연간 예산 집행 요약 | 강사비·운영물품비 연간 편성·집행·잔액 |
| 차기 연도 기획 제언 | 데이터 기반 운영 방향 제언 (3~5개 개조식) |

```

E-04 → E-05: 시즌 운영 실적 데이터 수신

  → 검증 실패: 사서에게 재확인 요청

E-05 → A-03: 시즌 예산 집행 현황 조회

E-05 → A-01: 결과보고서 hwpx 초안 생성 요청
A-01 → E-05: hwpx 파일 경로 반환
E-05 → 사서: 초안 전달

사서: 결과보고서 검토·수정·결재 확정

[확정 후]
E-05 → E-01: 수강 실적 데이터 피드백 (course_history 갱신)

[월간·연간 통계 수집 시]

E-05 → A-02: 시즌·연간 실적 데이터 제공

[연말]
자동 트리거 또는 사서 요청 → E-05: 연간 누계 보고 생성
```

## 9. 비기능 요구사항

- 결과보고서는 시즌 종료 후 5영업일 이내 초안 생성을 목표로 한다.
- 성과·개선사항 자동 생성 기준값(수료율 85%·70%, 휴강 2회 등)은 Config에서 조정 가능하다.
- E-01 피드백 데이터 형식은 E-01 PRD의 `course_history` 테이블 구조와 완전히 일치해야 한다.
- SQLite 데이터는 연도 단위로 보존하며 삭제하지 않는다.
- 에이전트 응답 언어: 한국어

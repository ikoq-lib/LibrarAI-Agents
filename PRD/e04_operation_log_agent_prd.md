# PRD — E-04 운영일지 에이전트 (Program Operation Log Agent)

**문서 버전:** 1.0  
**작성일:** 2026-06-29  
**소속 도메인:** D4 평생학습  
**에이전트 ID:** E-04  
**에이전트 유형:** Leaf Agent  
**참조 아키텍처:** 도서관 사서 AI 에이전트 시스템 v3

---

## 1. 개요

### 1.1 목적

E-04 운영일지 에이전트는 E-03 모집 에이전트로부터 수강생 명단과 프로그램 일정을 인계받아, 강좌 운영 기간 동안 회차별 출결 관리, 월별 강사비 지급 내역서 작성, 특이사항 기록을 담당하는 리프 에이전트다. 시즌 종료 후 DM-04 평생학습 도메인 에이전트에 운영 실적 데이터를 전달한다.

### 1.2 배경

평생학습 강좌는 시즌당 8~12회 운영되며 매 회차마다 출결 기록이 필요하다. 강사비는 월별로 지급되므로 회차별 진행 기록과 금액 계산이 정확하게 연동되어야 한다. E-04는 이 반복적인 기록·계산 작업을 자동화하고 사서는 출결 입력과 공문 검토에 집중할 수 있도록 한다.

### 1.3 범위

- **포함:** 출결 관리 대장 서식 자동 생성, 매 회차 출결 입력·기록, 누적 출석률 자동 계산, 월별 강사비 지급 내역서 초안, 특이사항 기록, DM-04 운영 실적 데이터 전달
- **제외:** 수강생 모집 (E-03 담당), 결과보고서 작성 (DM-04 담당), 강사비 실제 지급 처리 (담당자 직접 처리), 예산 집행 결정 (A-03 담당)

## 4. 기능 요구사항

### FN-01 출결 관리 대장 서식 자동 생성

E-03 인계 수신 즉시 프로그램별 출결 관리 대장 Excel 서식을 자동 생성하여 MCP Filesystem에 저장한다.

**서식 구조:**

- 행: 수강생 명단 (E-03 인계 데이터 자동 적용)
- 열: 회차별 날짜 (예: 1회 3/7, 2회 3/14, ...)
- 자동 계산 셀: 수강생별 출석 횟수·출석률, 회차별 출석 인원

**출석 기호:**
- `○` 출석 / `×` 결석 / `△` 조퇴·지각 / `휴` 휴강

**서식 예시 (캘리그라피 10회차):**

| 번호 | 성명 | 연락처 | 1회 3/7 | 2회 3/14 | ... | 10회 5/9 | 출석 횟수 | 출석률 |
|------|------|--------|---------|---------|-----|---------|---------|------|
| 1 | 김○○ | | ○ | ○ | | ○ | 9 | 90% |
| 2 | 이○○ | | ○ | × | | ○ | 8 | 80% |
| | **회차 출석 인원** | | 14 | 13 | | 12 | | |

**수료 기준 표시:**
Config에 수료 기준 출석률을 설정하면 (예: 70% 이상) 기준 충족 수강생에 자동으로 수료 표시를 부여한다.

---

### FN-02 매 회차 출결 입력 및 기록

사서가 매 회차 종료 후 출결 현황을 입력하면 SQLite `attendance` 테이블에 저장하고 출결 관리 대장 Excel 파일을 자동 갱신한다.

**사서 입력 항목:**
- 회차 번호, 실제 진행일, 수강생별 출결 기호, 특이사항

**`attendance` 테이블 저장 항목:**

| 필드 | 설명 |
|------|------|
| `attendance_id` | 자동 부여 ID |
| `program_id` | 연결 프로그램 ID |
| `session_no` | 회차 번호 |
| `session_date` | 실제 진행일 |
| `student_id` | 수강생 ID |
| `status` | `present` / `absent` / `late` / `cancelled` |
| `note` | 개별 특이사항 |

**`sessions` 테이블 저장 항목:**

| 필드 | 설명 |
|------|------|
| `session_id` | 자동 부여 ID |
| `program_id` | 연결 프로그램 ID |
| `session_no` | 회차 번호 |
| `scheduled_date` | 예정일 |
| `actual_date` | 실제 진행일 |
| `status` | `completed` / `cancelled` / `rescheduled` |
| `instructor_substitute` | 대체 강사 여부 |
| `note` | 회차 특이사항 |

**자동 계산:**
- 수강생별 누적 출석 횟수·출석률
- 회차별 출석 인원·결석 인원
- 수료 기준 도달 수강생 자동 표시

**Human-in-the-loop 필수:** 출결 입력은 사서가 매 회차 직접 수행. 에이전트가 임의로 출결을 입력하지 않는다.

---

### FN-03 특이사항 기록

회차별 특이사항(휴강, 보강, 강사 변경, 수강생 민원 등)을 별도 `remarks` 테이블에 기록하고 DM-04 결과보고 시 함께 전달한다.

**특이사항 유형:**

| 코드 | 내용 |
|------|------|
| `suspension` | 휴강 (사유 기재) |
| `makeup` | 보강 (예정일 기재) |
| `instructor_change` | 강사 변경 (대체 강사명 기재) |
| `complaint` | 수강생 민원 (내용 요약) |
| `dropout` | 중도 포기 (수강생명·사유) |
| `other` | 기타 |

---

### FN-04 월별 강사비 지급 내역서 초안 (A-01 호출, A-03 연계)

매월 말 또는 사서 요청 시 해당 월에 진행된 회차 기준으로 강사비 지급 내역서 hwpx 초안을 생성하고, A-03 예산 에이전트에 집행 기록을 요청한다.

**월별 지급 계산:**
- 해당 월 실제 진행 회차 수 × 회당 강사비 (Config 기본값)
- 휴강 회차는 제외, 보강 회차는 진행 월 기준으로 포함
- 대체 강사 발생 시 해당 회차 강사비를 별도 행으로 분리

**지급 내역서 포함 항목:**

| 항목 | 내용 |
|------|------|
| 프로그램명 | |
| 강사명 | |
| 지급 대상 회차 | 회차 번호·진행일 목록 |
| 진행 회차 수 | |
| 회당 강사비 | Config 설정값 |
| 지급 합계 | 진행 회차 수 × 회당 강사비 |
| 비고 | 휴강·대체 강사 등 특이사항 |

**복수 프로그램 처리:**
동일 월에 복수 프로그램이 운영되는 경우 강사별로 행을 분리하여 하나의 내역서에 통합한다.

**A-03 집행 기록 요청:**
내역서 생성 후 A-03에 아래 항목을 전달한다.
```json
{
  "requester_agent": "E-04",
  "domain": "D4",
  "budget_item": "강사비",
  "amount": 500000,
  "description": "2026년 상반기 평생학습 강사비 — 3월분",
  "execution_date": "2026-03-31"
}
```

**Human-in-the-loop 필수:** 지급 내역서 사서 검토·결재 후 실제 지급 처리. 에이전트가 직접 지급하지 않는다.

### FN-05 운영 현황 조회

사서 요청 시 프로그램별 현재 운영 현황을 요약하여 출력한다.

**출력 예시:**
```
[평생학습 운영 현황 — 2026년 4월 기준]

캘리그라피 (성인)
 · 진행 회차: 5/10회 완료
 · 평균 출석률: 88%
 · 수료 예상 인원: 12/14명
 · 이번 달 강사비: 200,000원 (2회 진행)
 · 특이사항: 3회차 강사 변경 (대체 강사 홍○○)

북아트 (어린이)
 · 진행 회차: 5/10회 완료
 · 평균 출석률: 92%
 · 수료 예상 인원: 11/12명
 · 이번 달 강사비: 200,000원 (2회 진행)
 · 특이사항: 없음
```

## 8. 제약 및 예외 처리

| 상황 | 처리 방식 |
|------|----------|
| 휴강 발생 | `cancelled` 기록, 강사비 해당 회차 제외. 보강 일정 사서 입력 후 `makeup` 기록 |
| 보강 진행 | 실제 진행일 기준으로 해당 월 강사비에 포함 |
| 대체 강사 발생 | 해당 회차 `instructor_substitute: true` 기록, 강사비 내역서에 별도 행으로 분리 |
| 수강생 중도 포기 | `dropout` 특이사항 기록, 이후 회차 출결 입력 대상에서 제외 |
| 강사비 단가 변경 | Config 수정 후 적용. 이미 지급된 월은 소급 적용하지 않음 |
| Excel 파일 손상 | SQLite 데이터 기반으로 재생성 |

## 9. 비기능 요구사항

- 출결 관리 대장 Excel 서식은 openpyxl 기반으로 생성하며 구조화 테이블(Table) 형식을 유지한다.
- 강사비 지급 내역서는 매월 말일 기준으로 자동 생성 트리거를 지원한다 (사서 수동 요청도 가능).
- 수료 기준 출석률은 Config에서 조정 가능하다 (기본값: 70%).
- SQLite 데이터는 연도 단위로 보존하며 삭제하지 않는다.
- 기관별 고유 정보(강사비 단가, 수료 기준, 예산과목 등)는 Config로 주입한다.
- 에이전트 응답 언어: 한국어

## 11. 향후 확장 고려사항

- 수강생 출석률 저조 시 자동 알림 기능 추가 검토 (예: 3회 연속 결석 시 사서에게 안내)
- 강사비 지급 이력 누적 분석 기능 추가 검토 (연간 강사별 총 지급액)
- E-01 수강 데이터와 연동하여 출석률을 다음 시즌 프로그램 추천 점수에 반영 검토

# PRD: 월별 행사 기획 에이전트

## 1. 개요

### 배경
공공도서관은 평생학습 프로그램 외에도 독서의 달, 어린이날, 독서토론회, 북콘서트 등 단발성 행사를 연중 기획·운영한다. 현재 행사 기획은 담당자가 매번 처음부터 문서를 작성하는 방식으로, 반복적인 행정 업무 부담이 크다.

### 목적
월별 행사 기획의 전 단계(기획 → 홍보 → 운영 → 결과 보고)에 걸쳐 필요한 문서를 AI가 초안으로 생성하여, 담당자의 행정 업무를 줄이고 행사 품질을 높인다.

### 범위
- **포함**: 단발성 행사 (1일~수일 내 완결되는 이벤트성 행사)
- **제외**: 회차가 있는 정기 강좌 (→ 평생학습 에이전트 담당), 도서 구입 업무

## 4. 워크플로우 및 단계별 기능

### 전체 흐름

```
1단계: 행사 기획
  └─ 1-1. 행사 후보 제안
  └─ 1-2. 행사 세부계획서 (기안문 + 첨부)

2단계: 홍보물 제작
  └─ 2-1. 홍보 문안 (현수막 / SNS / 홈페이지 / 보도자료)
  └─ 2-2. 이미지 생성용 프롬프트 (포스터·배너용)

3단계: 참가자 모집 (선택)
  └─ 3-1. 참가 신청서 서식
  └─ 3-2. 참가자 모집 기안 (기안문 + 첨부)

4단계: 운영 준비
  └─ 4-1. 행사 진행 시나리오 (타임테이블)
  └─ 4-2. 준비물·체크리스트

5단계: 결과 보고
  └─ 5-1. 행사 결과 보고서 (기안문 + 첨부)
  └─ 5-2. 운영일지 서식
```

### 단계별 산출물 상세

#### 1-1. 행사 후보 제안
- 입력: 월(月), 대상(어린이/성인/전체), 예산 범위, 선호 유형 (선택)
- 출력: 후보 행사 3~5개 (행사명, 대상, 개최 이유, 예상 참가 인원, 예산 개요)
- 제안 기준: 해당 월의 기념일·절기, 최근 공공도서관 트렌드, 지역사회 수요

#### 1-2. 행사 세부계획서
- 기안문 + 첨부 분리 출력 (기존 구분자 형식 사용)
- 첨부 구성:
  1. 행사 개요 (목적, 일시, 장소, 대상, 인원, 예산)
  2. 세부 추진 일정 (준비 → 홍보 → 행사 당일 → 사후 처리)
  3. 소요 예산 표 (항목/단가/수량/금액/비고)
  4. 기대 효과

**A-03 예산 에이전트 연동 (예산 부족 처리):** 소요 예산 표를 확정하기 전에 항목별 금액을 A-03 예산 에이전트에 전달하여 실제 예산 항목 잔액을 확인한다. A-03이 특정 항목의 예산 부족으로 응답하면 A-03의 FN-07 절차(사업항목 간 예산 유용, Bottom-Up — 같은 단위과제카드 내 인접 사업항목의 잔액을 가까운 단계부터 찾아 대체 재원으로 쓸지 확인하는 절차)를 따른다:
- A-03이 "예산이 부족합니다. 다른 항목의 예산을 사용하시겠습니까?"라고 물으면 그대로 담당자에게 전달하고 회신을 A-03에 전달한다.
- A-03이 같은 단위과제카드 내 대체 사업항목(항목명 + 현재 잔액)을 제시하면 그대로 전달하고, 사용 여부·항목 선택 회신을 A-03에 전달한다.
- 담당자가 동의하면 확정된 대체 항목을 소요 예산 표의 예산과목으로 반영하여 세부계획서 작성을 계속 진행한다.
- 담당자가 거절하면 **해당 행사의 세부계획서 작성을 즉시 중단한다.** 임의로 예산을 줄이거나 다른 항목으로 대체하지 않는다.
- 같은 단위과제카드 내에 대체 재원이 전혀 없다고 A-03이 응답한 경우에만 예산 초과 사실을 담당자에게 알리고 조정 여부를 확인한다.

#### 2-1. 홍보 문안
- 현수막: 한 줄 슬로건 + 핵심 정보 (일시·장소·문의)
- SNS (인스타그램/블로그): 본문 + 해시태그
- 홈페이지 공지: 제목 + 본문 (정보 중심, 공식 어투)
- 보도자료: 도서관명·행사명·일시 등 기본 정보 포함한 표준 보도자료 형식

#### 2-2. 이미지 생성용 프롬프트
- 포스터 / SNS 카드뉴스 / 현수막 각각의 이미지 생성 프롬프트 작성
- 스타일 가이드 포함 (도서관 분위기, 색감, 구성 요소)

#### 4-1. 행사 진행 시나리오
- 타임테이블 (시간 / 내용 / 담당자 / 비고)
- 사회자 멘트 초안 포함 (선택)

#### 5-1. 결과 보고서
- 기안문 + 첨부 분리 출력
- 첨부 구성:
  1. 행사 개요
  2. 추진 경과
  3. 참가 현황 (목표 대비 실적)
  4. 예산 집행 현황
  5. 성과 및 향후 개선사항

## 6. UI 구성

기존 에이전트(평생학습, 수서)와 동일한 레이아웃을 따른다.

```
┌──────────────┬────────────────────────────────┐
│  사이드바     │  채팅 영역                       │
│              │                                │
│  [기관 설정]  │  에이전트 메시지                  │
│  - 기관명    │  사용자 입력                      │
│  - 담당자    │                                │
│  - 예산      │                                │
│              │  [문서 출력 영역]                 │
│  [단계 선택]  │  ===기안문시작=== ~ ===기안문끝=== │
│  1단계       │  ===첨부시작=== ~ ===첨부끝===   │
│  2단계       │                                │
│  3단계       │  [파일 다운로드 버튼]              │
│  4단계       │                                │
│  5단계       │  ────────────────────────────  │
│              │  [텍스트 입력창]  [전송]           │
└──────────────┴────────────────────────────────┘
```

### 파일 다운로드
- 기안문과 첨부 각각 `.hwpx` 형태로 다운로드 가능
- 평생학습 에이전트에 이미 구현된 파일 업로드/다운로드 패턴 재사용

## 7. 문서 출력 형식

기존 에이전트와 동일한 구분자 사용:

```
===기안문시작===
수신: 내부결재
(경유)
제목: OOO

1. 관련근거: ...
2. 추진 개요: ...
3. 세부 내용: 붙임 참고

붙임: OOO 1부. 끝.
===기안문끝===

===첨부시작===
(첨부 내용 - 마크다운 형식)
===첨부끝===
```

기안문이 불필요한 단계(홍보 문안, 섭외 문자 등)는 구분자 없이 본문만 출력한다.

## 8. 에이전트 응답 원칙

- 단계를 지정하면 해당 단계 업무만 수행
- 각 단계 완료 후 다음 단계 진행 여부 확인
- 숫자(예산, 인원)는 담당자 입력값 기준으로 계산
- 소요 예산 확정 시 A-03 예산 에이전트에 잔액을 확인하며, 예산 부족 시 위 "1-2. 행사 세부계획서"의 A-03 연동 절차(FN-07 Bottom-Up 대체 항목 확인)를 따른다 — 담당자가 대체 항목 사용을 거절하면 세부계획서 작성을 중단한다
- 기관명·담당자명이 미입력 상태면 산출 전 먼저 요청
- 공공기관 공문서 어투 준수
- 항상 한국어로 응답

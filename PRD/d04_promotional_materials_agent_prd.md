# PRD — D-04 홍보물 에이전트 (Promotional Materials Agent)

**문서 버전:** 1.0  
**작성일:** 2026-06-07  
**소속 도메인:** D3 독서문화  
**에이전트 ID:** D-04  
**에이전트 유형:** Leaf Agent (공통 도구 에이전트)  
**참조 아키텍처:** 창녕도서관 사서 AI 에이전트 시스템 v3

---

## 1. 개요

### 1.1 목적

D-04 홍보물 에이전트는 창녕도서관의 각종 행사·프로그램 홍보물 초안을 매체 유형에 맞게 생성하는 공통 도구 에이전트다. D-02 행사기획, D-03 강사섭외, E-01 강좌기획 등 행사를 발생시키는 에이전트들이 D-04를 호출하여 홍보물 초안을 요청하며, F-01 SNS 에이전트도 인스타그램용 이미지가 필요할 때 D-04에 생성을 위임한다.

### 1.2 배경

도서관 홍보물은 동일한 행사 정보를 보도자료, 홈페이지·인쇄물, SNS(인스타그램) 세 가지 매체에 맞춰 각각 다른 형식으로 제작해야 한다. 매체마다 분량·비율·포함 정보가 달라 사서가 행사 하나당 세 종류의 홍보물을 반복적으로 수작업 제작해왔다. D-04는 이 반복 과정을 자동화하되, 이미지 생성은 OpenRouter 이미지 생성 모델을 활용하고 최종 검토는 사서가 담당하는 human-in-the-loop 구조로 설계한다.

### 1.3 산출물 유형

| 유형 | 성격 | 형식 | 주요 내용 |
|------|------|------|----------|
| 보도자료 | 공식 | 텍스트 (.md / .txt) | 제목·부제, 행사 취지·기간·내용, 관계자 코멘트 |
| 홈페이지·인쇄물 | 공식·시각 | 이미지 (A4/A3 세로형) | 이미지 요소 + 운영기간·내용·장소·신청방법 텍스트 |
| SNS (인스타그램) | 소셜 | 이미지 (1:1) + 캡션 텍스트 | 인쇄물 축약·중요 정보 중심 이미지 + 인스타그래머블 캡션 |

### 1.4 범위

- **포함:** 매체별 홍보물 초안 생성 (보도자료·인쇄물·SNS 이미지+캡션), OpenRouter 이미지 생성 모델 연동, F-01 SNS 에이전트 이미지 생성 위임 처리
- **제외:** 홍보물 실제 게시·발송 (사서 직접 처리), SNS 텍스트 게시글 최종 작성 (F-01 담당), 소식지 제작 (F-04 담당), 영상 홍보물 제작

## 4. 입력 인터페이스 (호출 에이전트 → D-04)

호출 에이전트가 D-04를 호출할 때 전달하는 표준 입력 구조:

```json
{
  "requester_agent": "D-02",
  "event_name": "2026 창녕도서관 여름방학 독서캠프",
  "event_type": "어린이 독서행사",
  "target_audience": "초등학생",
  "period": "2026-07-21 ~ 2026-07-25",
  "venue": "창녕도서관 2층 프로그램실",
  "content_summary": "독서 활동, 북아트, 저자 강연 포함 5일 캠프",
  "application_method": "도서관 홈페이지 선착순 접수 (6.30~)",
  "contact": "055-532-9501",
  "output_types": ["press_release", "print_poster", "sns_instagram"],
  "tone": "친근하고 밝은",
  "spokesperson": "창녕도서관장 ○○○"
}
```

**`output_types` 값:**
- `press_release` — 보도자료
- `print_poster` — 홈페이지·인쇄물 이미지
- `sns_instagram` — 인스타그램 이미지 + 캡션
- 복수 선택 가능, 생략 시 3종 모두 생성

## 5. 기능 요구사항

### F-01 보도자료 생성

공식 성격의 텍스트 홍보물로, 보도자료 표준 구조에 따라 작성한다.

**보도자료 구성 요소:**

| 항목 | 내용 |
|------|------|
| 제목 | 행사 핵심을 담은 명확한 제목 (15자 내외) |
| 부제 | 제목 보완, 기간·대상 등 구체 정보 포함 |
| 행사 취지 | 개최 배경 및 목적 (2~3문장, 개조식) |
| 행사 개요 | 기간·장소·대상·내용 (표 형식) |
| 세부 내용 | 프로그램별 세부 설명 |
| 관계자 코멘트 | 담당자 또는 도서관장 명의 1~2문장 인용구 |
| 문의 | 담당자·연락처 |

**작성 원칙:**
- 육하원칙(누가·언제·어디서·무엇을·어떻게·왜) 기반
- 객관적 사실 위주, 과장 표현 지양
- 지역 신문·교육청 보도자료 기준 준수

**출력 형식:** 마크다운 텍스트 → 사서가 `.hwpx` 또는 `.docx`로 변환 후 배포

---

### F-02 홈페이지·인쇄물 이미지 생성

도서관 홈페이지 게시 및 오프라인 인쇄(A4/A3)용 세로형 홍보 포스터를 생성한다.

**처리 흐름:**

1. 입력 정보 기반으로 이미지 생성 프롬프트 자동 구성
2. OpenRouter 이미지 생성 모델 `[모델명 — 확정 시 기재]` 호출
3. 생성 이미지에 포함할 텍스트 요소 목록 제시 (에이전트가 텍스트 레이어는 별도 안내)
4. 사서 검토 후 필요 시 프롬프트 수정 재생성

**이미지 프롬프트 구성 원칙:**
- 행사 성격에 맞는 분위기·색감·스타일 지정
- 텍스트 삽입 공간 확보 지시 포함 (`leave space for text overlay`)
- 비율: 세로형 (A4 기준 1:1.414 / A3 기준 동일)
- 공공기관 홍보물 기준: 과도한 장식 지양, 정보 전달 중심

**텍스트 요소 (이미지 생성 후 사서가 디자인 툴에서 삽입):**
- 행사명, 운영 기간, 장소, 대상, 신청 방법, 문의처
- 창녕도서관 로고·CI (사서 직접 배치)

**Human-in-the-loop 필수:** 생성된 이미지는 사서 검토 후 디자인 툴(Canva 등)에서 텍스트 요소를 삽입하여 완성한다. 에이전트가 최종 완성 이미지를 직접 게시하지 않는다.

---

### F-03 SNS (인스타그램) 이미지 + 캡션 생성

인스타그램 게시에 최적화된 1:1 정방형 이미지와 캡션 텍스트를 함께 생성한다.

#### F-03-A 인스타그램 이미지

- 홈페이지·인쇄물 이미지(F-02)와 디자인 방향은 동일하게 유지
- 비율: 1:1 정방형
- 정보 밀도 축소: 인쇄물 대비 중요도가 낮은 정보(세부 일정, 상세 신청 절차 등)는 생략 가능
- 핵심 정보만 강조: 행사명·기간·장소·신청 방법

#### F-03-B 인스타그램 캡션 (인스타그래머블 텍스트)

이미지 내용을 바탕으로 인스타그램에 어울리는 감성적·참여 유도형 캡션을 작성한다.

**캡션 구성:**

| 항목 | 내용 |
|------|------|
| 첫 줄 (훅) | 이목을 끄는 1~2문장 (의문형, 감탄형, 공감형 등) |
| 본문 | 행사 핵심 정보 (간결하게, 이모지 활용 가능) |
| CTA | 신청 방법 안내 (링크, 전화, 홈페이지 등) |
| 해시태그 | 창녕도서관 고정 태그 + 행사 관련 태그 5~10개 |

**캡션 예시 (독서캠프):**
```
📚 이번 여름방학, 책 속으로 떠나는 5일 여행!

창녕도서관 여름방학 독서캠프에서 독서, 북아트, 작가와의 만남까지
알차게 보내세요 :)

📅 7월 21일(월) ~ 25일(금)
📍 창녕도서관 2층 프로그램실
👦 초등학생 누구나
📝 홈페이지 선착순 접수 (6.30~)

자세한 내용은 프로필 링크를 확인해주세요!
☎ 055-532-9501

#창녕도서관 #독서캠프 #여름방학 #어린이독서 #창녕 #도서관행사 #북아트
```

### F-04 F-01 SNS 에이전트 이미지 위임 처리

F-01 SNS 에이전트가 이미지 생성을 D-04에 위임하는 경우, F-01의 요청을 F-03과 동일한 방식으로 처리하여 결과를 반환한다.

**입력:** F-01으로부터 행사 정보 + SNS 플랫폼 유형 수신  
**출력:** 해당 플랫폼에 맞는 이미지 초안 + 프롬프트 내역 반환

---

### F-05 프롬프트 템플릿 관리

반복 사용되는 행사 유형별 이미지 프롬프트 템플릿을 SQLite에 저장하고 관리한다.

**템플릿 분류:**

| 행사 유형 | 프롬프트 키워드 방향 |
|----------|-------------------|
| 어린이 독서행사 | 밝고 동화적, 파스텔 색감, 귀여운 일러스트 |
| 성인 평생학습 | 차분하고 세련된, 정보 중심, 여백 활용 |
| 독서동아리 | 따뜻하고 아늑한, 책·커피·소통 이미지 |
| 지역 문화행사 | 창녕 지역 정체성 반영, 자연·역사 모티프 |
| 공모·외부행사 | 공식적이고 신뢰감 있는 톤 |

## 6. 데이터 흐름

```
[행사 에이전트 또는 사서]
  → D-04: 행사 정보 + 요청 산출물 유형 전달

D-04:
  ① 보도자료 → 텍스트 초안 생성 → 사서 전달
  ② 인쇄물 → 이미지 프롬프트 구성 → OpenRouter 호출
              → 이미지 생성 → 텍스트 요소 목록과 함께 사서 전달
  ③ SNS → 1:1 이미지 생성 + 캡션 작성 → 사서 또는 F-01 전달

[사서]
  → 보도자료: 검토·수정 → 배포
  → 인쇄물: 디자인 툴에서 텍스트 삽입 → 검토 → 게시
  → SNS: 캡션 검토·수정 → 인스타그램 직접 게시
```

## 7. MCP 도구 연동

| 도구 | 용도 |
|------|------|
| OpenRouter API | 이미지 생성 모델 호출 (`[모델명 — 확정 시 기재]`) |
| MCP Filesystem | 생성 이미지·보도자료 파일 저장 |
| MCP SQLite | 프롬프트 템플릿 저장·관리, 생성 이력 기록 |

> **OpenRouter 이미지 생성 모델명:** 현재 미확정. PRD 구현 단계 진입 전 사서 확인 필요. 확정 후 이 항목 업데이트.

## 8. Human-in-the-loop 정책

| 단계 | 사서 개입 여부 | 내용 |
|------|--------------|------|
| 홍보물 생성 요청 | 불필요 (에이전트 간 자동 호출) | 사서 직접 요청도 가능 |
| 보도자료 초안 | **필수** | 사서 검토·수정 후 배포 |
| 인쇄물 이미지 초안 | **필수** | 사서가 텍스트 삽입 후 최종 완성 |
| 이미지 재생성 요청 | **필수** | 사서 판단 하에 프롬프트 수정 지시 |
| SNS 이미지+캡션 | **필수** | 사서 검토·수정 후 직접 게시 |
| 프롬프트 템플릿 등록·수정 | **필수** | 사서 승인 후 저장 |

## 9. 제약 및 예외 처리

| 상황 | 처리 방식 |
|------|----------|
| 이미지 생성 API 호출 실패 | 재시도 2회 후 실패 안내 + 프롬프트 텍스트만 사서에게 전달 |
| 행사 정보 불충분 (필수 항목 누락) | 누락 항목 목록화 후 호출 에이전트 또는 사서에게 보완 요청 |
| 행사 성격에 맞는 템플릿 없음 | 기본 템플릿 적용 후 사서에게 템플릿 추가 등록 권고 |
| 이미지 내 텍스트 자동 삽입 요청 | 현재 미지원, 텍스트 요소 목록만 제공 안내 |
| 저작권 우려 이미지 생성 시 | 프롬프트 수정 안내 후 재생성 |

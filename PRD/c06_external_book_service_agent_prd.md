# PRD — C-06 외부도서서비스 에이전트 (External Book Service Agent)

**문서 버전:** 1.0

**소속 도메인:** D2 이용자  
**에이전트 ID:** C-06  
**에이전트 유형:** Leaf Agent  
**참조 아키텍처:** 창녕도서관 사서 AI 에이전트 시스템 v3

---

## 1. 개요

### 1.1 목적

C-06 외부도서서비스 에이전트는 창녕도서관이 운영하는 저빈도 외부 도서 배달 서비스 세 종류 — 책나래(장애인 무료 우편), 책바다(전국 도서관 간 유료 상호대차), 택배대출(개인 주소지 착불 택배) — 의 신청 접수, 처리 현황 관리, 안내문 초안 생성을 담당하는 리프 에이전트다.

세 서비스는 모두 저빈도·개인 신청 기반이며 "신청 접수 → 처리 → 발송 → 완료 기록"의 유사한 처리 흐름을 공유한다. C-05 상호대차(고빈도, 도서관 간 무료)와는 명확히 분리 운영된다.

### 1.2 서비스별 개요

#### 책나래 (장애인 자료 우편 서비스)

| 항목 | 내용 |
|------|------|
| 운영 주체 | 국립중앙도서관 |
| 대상 | 장애인 등록증 소지자 |
| 비용 | 무료 (왕복 우편료 국립중앙도서관 부담) |
| 신청 방법 | 이용자가 국립중앙도서관에 직접 신청 후 창녕도서관 경유 처리 |
| 데이터 입력 방식 | 사서가 엑셀로 신청 내역 직접 입력 (연구용: 외부 API 미연동) |
| 신청 빈도 | 낮음 |

#### 책바다 (전국 도서관 간 유료 상호대차)

| 항목 | 내용 |
|------|------|
| 운영 주체 | 국립중앙도서관 |
| 대상 | 일반 이용자 |
| 비용 | 유료 (왕복 배송비 본인 부담, 금액은 신청 시 안내) |
| 신청 방법 | 책바다 홈페이지(www.nl.go.kr/nill) 또는 도서관 방문 신청 |
| 신청 빈도 | 매우 낮음 |

#### 택배대출 (개인 주소지 착불 택배)

| 항목 | 내용 |
|------|------|
| 대상 | 창녕도서관 회원 |
| 비용 | 유료 (착불, 이용자 본인 부담) |
| 신청 방법 | 도서관 홈페이지 또는 전화 신청 |
| 신청 빈도 | 매우 낮음 |
| 특이사항 | 이용자가 상호대차(무료)와 혼동하여 택배대출(유료)을 무료로 오인하는 사례 빈발 → 유료 확인 절차 필수 |

### 1.3 범위

- **포함:** 신청 접수 기록, 처리 현황 관리, 안내문·확인 문자 초안 생성, 일별 처리 현황 요약
- **제외:** 국립중앙도서관 API 직접 연동, 책바다 홈페이지 자동 신청, 결제 처리, C-05 상호대차 업무

## 3. 기능 요구사항

### F-01 신청 접수 등록

사서가 신청 내역을 텍스트 또는 엑셀 형태로 입력하면 에이전트가 파싱하여 서비스 유형별로 SQLite에 저장한다.

**`external_requests` 테이블 저장 항목:**

| 필드 | 설명 | 예시 |
|------|------|------|
| `request_id` | 자동 부여 ID | `EXT-2026-0511-001` |
| `service_type` | 서비스 유형 | `booknare` / `bookbada` / `delivery_loan` |
| `requester_name` | 신청자명 | |
| `requester_contact` | 연락처 | |
| `delivery_address` | 배송 주소 (택배대출·책나래) | |
| `book_title` | 도서명 | |
| `book_isbn` | ISBN | |
| `request_date` | 신청일 | `2026-05-11` |
| `fee_confirmed` | 유료 안내 확인 여부 | `true` / `false` (택배대출·책바다 필수) |
| `shipped_date` | 발송일 | |
| `tracking_number` | 운송장 번호 (사서 입력) | |
| `status` | 처리 상태 | `pending` / `fee_check` / `processing` / `shipped` / `completed` |

---

### F-02 택배대출 유료 확인 절차 (필수)

택배대출 신청이 접수되면, 에이전트는 발송 처리 전 반드시 아래 확인 절차를 수행한다. 이용자가 상호대차(무료)와 혼동하는 사례가 빈발하므로, 유료임을 명시한 확인 문자 초안을 자동 생성하여 사서에게 제공한다.

**처리 흐름:**

1. 택배대출 신청 접수 → `status: fee_check`로 저장
2. 유료 확인 문자 초안 자동 생성
3. 사서가 초안 확인 후 이용자에게 직접 발송
4. 이용자 유료 동의 확인 → 사서가 `fee_confirmed: true` 입력
5. `status: processing`으로 업데이트 후 발송 처리 진행

**Human-in-the-loop 필수:** 에이전트는 유료 확인 문자를 직접 발송하지 않는다. 사서가 확인 후 발송하며, 이용자 동의 확인도 사서가 직접 수행한다.

**유료 확인 문자 초안 예시:**
```
[창녕도서관 택배대출 안내]
안녕하세요, 홍길동 님.
택배대출 서비스는 착불(이용자 부담) 유료 서비스입니다.
상호대차 서비스(무료)와 다른 서비스이오니 확인 부탁드립니다.

· 신청 도서: 『채식주의자』
· 배송지: 경남 창녕군 창녕읍 ○○로 ○○
· 배송비: 착불 (수령 시 택배기사에게 직접 납부)

진행을 원하시면 회신 부탁드립니다.
창녕도서관 ☎ 055-532-9501
```

### F-03 책나래 신청 관리

책나래는 국립중앙도서관 연동 없이 사서가 직접 엑셀로 신청 내역을 입력하는 방식으로 운영된다. 에이전트는 입력된 데이터를 파싱하여 저장하고, 처리 현황을 추적한다.

**책나래 전용 처리 항목:**
- 장애인 등록 확인 여부 (사서 입력, `disability_verified: true/false`)
- 발송 완료 후 국립중앙도서관 보고용 집계 데이터 출력

**책나래 처리 안내문 초안 예시:**
```
[창녕도서관 책나래 서비스 안내]
안녕하세요, 홍길동 님.
신청하신 도서 『점자로 읽는 세계』가 준비되었습니다.
등록하신 주소로 무료 발송 예정입니다. (발송일: 2026-05-13)
창녕도서관 ☎ 055-532-9501
```

---

### F-04 책바다 신청 관리

책바다는 전국 도서관 간 유료 상호대차 서비스로 신청 빈도가 매우 낮다. 신청 접수 시 에이전트는 유료임을 확인하는 안내 절차를 F-02(택배대출 유료 확인)와 동일한 방식으로 수행한다.

**책바다 전용 처리 항목:**
- 배송비 안내 (금액은 신청 건별로 사서가 직접 확인 후 입력)
- 책바다 홈페이지 신청 링크 안내: `https://www.nl.go.kr/nill/`

---

### F-05 처리 현황 조회 및 요약

사서 요청 시 서비스 유형별 처리 현황을 조회하여 요약 보고한다.

**출력 형식 예시:**
```
[외부도서서비스 현황 — 2026-05-11]

책나래
 · 처리 중: 1건 (홍길동 님, 『점자로 읽는 세계』)
 · 이번 달 완료: 2건

책바다
 · 처리 중: 0건
 · 이번 달 완료: 1건

택배대출
 · 유료 확인 대기: 1건 (김영희 님 — 확인 문자 발송 필요)
 · 처리 중: 0건
 · 이번 달 완료: 0건

연간 누계 (2026년)
 · 책나래: 8건 / 책바다: 3건 / 택배대출: 2건
```

### F-06 서비스 안내 FAQ 응답

이용자 또는 사서가 세 서비스에 대해 질문하면 에이전트가 안내 텍스트를 제공한다. C-01 FAQ 에이전트와 역할이 겹치지 않도록, C-06은 실제 신청 건 처리 맥락에서의 질문에만 응답하고, 일반적인 서비스 안내는 C-01로 위임한다.

**주요 안내 항목:**
- 택배대출과 상호대차의 차이 (유료 vs 무료)
- 책나래 이용 자격 (장애인 등록증 소지자)
- 책바다 신청 방법 및 비용 안내 링크

```

[책바다]

[택배대출]

[수시]
사서 → C-06: 현황 조회 요청
C-06 → 사서: 서비스별 처리 현황 요약 출력
```

## 7. 제약 및 예외 처리

| 상황 | 처리 방식 |
|------|----------|
| 택배대출 유료 미확인 상태에서 발송 요청 | `fee_confirmed: false` 경고 출력, 발송 처리 블로킹 |
| 책나래 장애인 미확인 상태 | `disability_verified: false` 경고, 사서에게 확인 요청 |
| 책바다 배송비 미입력 상태 | 배송비 입력 요청 후 처리 |
| 이용자가 상호대차·택배대출 혼동 문의 | 두 서비스 차이 안내 텍스트 자동 출력 |
| 데이터 파싱 오류 | 실패 항목 목록화 후 사서에게 재입력 요청 |

## 8. C-05 상호대차와의 역할 경계

| 구분 | C-05 상호대차 | C-06 외부도서서비스 |
|------|-------------|-----------------|
| 서비스 | 경남교육청 도서관 간 무료 | 책나래·책바다·택배대출 |
| 빈도 | 매일 (고빈도) | 월 수건 이하 (저빈도) |
| 비용 | 무료 | 무료(책나래) / 유료(책바다·택배대출) |
| 유료 확인 절차 | 없음 | 책바다·택배대출 필수 |
| 연계 기관 | 경남교육청 소속 도서관 | 국립중앙도서관, 전국 도서관, 택배사 |

## 9. 비기능 요구사항

- 택배대출 신청 접수 시 `fee_check` 상태로 자동 설정되어야 하며, 유료 확인 없이 `processing`으로 상태 변경이 불가능하다.
- SQLite 데이터는 연도 단위로 보존하며 삭제하지 않는다.
- 에이전트 응답 언어: 한국어

---

## 10. 향후 확장 고려사항

- 국립중앙도서관 책나래 API 정식 연동 시 사서 수동 입력 방식을 자동 수신으로 전환 검토
- 택배사 운송장 조회 API 연동으로 배송 상태 자동 추적 검토
- 이용자 빈도 증가 시 택배대출을 독립 에이전트로 분리 검토

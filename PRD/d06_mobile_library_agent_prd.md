**문서 버전:** 1.0  
**작성일:** 2026-05-11  
**소속 도메인:** D3 독서문화  
**에이전트 ID:** D-06  
**에이전트 유형:** Leaf Agent  
**참조 아키텍처:** 창녕도서관 사서 AI 에이전트 시스템 v3

## 1. 개요

### 1.1 목적

D-06 순회문고 에이전트는 창녕도서관이 창녕군 소재 기관·단체를 대상으로 운영하는 순회문고 서비스의 전 과정 — 기관 관리, 도서 선정, 배치·회수 일정 관리, 운영일지 초안 생성, 관리대장 갱신 — 을 지원하는 리프 에이전트다.

순회문고는 도서관 자료를 일정 기간 기관에 대출하여 서가를 채워주는 프로그램 운영 성격의 서비스다. 개인 이용자 대상의 D2 이용자 도메인보다 기관 대상 프로그램 운영에 가까워 D3 독서문화 도메인에 배치한다.

### 1.2 서비스 개요 (창녕도서관 기준)

| 항목 | 내용 |
|------|------|
| 대상 기관 | 창녕군 소재 유치원, 학교, 기관 및 단체 |
| 신청 방법 | 홈페이지(cnlib.gne.go.kr) 행사공지 게시판 신청서 작성 후 aeonian@korea.kr 제출 |
| 신청 기간 | 연중 상시 |
| 배치 도서 규모 | 회당 약 130권 |
| 도서 용어 | 배치 도서 (기관에 배치) / 회수 도서 (기관에서 회수) |
| 문의 | 055-532-9501 |

### 1.3 배경

순회문고는 기관별 배치·회수 일정 조율, 도서 선정, 운영일지 작성, 관리대장 갱신이 반복적으로 발생하는 업무다. 특히 도서 선정 단계에서 대출 데이터 분석이 필요하고, 기관별 이용자 특성(어린이·청소년·성인·노인 등)에 따라 선정 기준이 달라진다. 에이전트는 이 반복 과정을 자동화하고 사서의 판단이 필요한 지점에서 초안을 제공한다.

### 1.4 범위

- **포함:** 기관 정보 관리, 대출 데이터 기반 도서 선정 초안, 배치·회수 일정 관리, 운영일지 초안 생성, 엑셀 관리대장 갱신, 홈페이지 게시글 초안 생성
- **제외:** 기관 실사·방문 일정 직접 조율, 도서 물리적 배송 처리, 대출 시스템 직접 연동 (연구용: 사서 수동 입력 방식)

## 3. 기능 요구사항

### FN-01 기관 정보 관리

순회문고 참여 기관의 정보를 SQLite `institutions` 테이블에 등록·관리한다.

**저장 항목:**

| 필드 | 설명 | 예시 |
|------|------|------|
| `institution_id` | 자동 부여 ID | `INST-001` |
| `name` | 기관명 | `창녕군립어린이집` |
| `type` | 기관 유형 | `유치원` / `학교` / `복지관` / `기타기관` |
| `target_age` | 주 이용 연령대 | `어린이` / `청소년` / `성인` / `노인` / `혼합` |
| `contact_name` | 담당자명 | |
| `contact_phone` | 담당자 연락처 | |
| `address` | 기관 주소 | |
| `registered_date` | 등록일 | |
| `status` | 운영 상태 | `active` / `inactive` |
| `memo` | 특이사항 | |

### FN-02 대출 데이터 기반 도서 선정 초안

사서가 대출 내역 엑셀 파일을 입력하면 에이전트가 아래 기준에 따라 배치 도서 후보 목록(약 130권)을 자동 선정하고 초안을 출력한다. 최종 선정은 사서가 확인·수정·승인한다.

**선정 기준 (창녕도서관 확정 기준):**

1. **기본 제외 조건**
   - 대출횟수 8회 미만인 도서 제외
   - 특정 1~2인만 대출한 도서 제외 (개인 편향 도서)
   - 직전 2개 시즌(약 6개월) 내 대출된 도서 제외 (최신 인기 도서 보호)

2. **그룹 비율 선정**
   - 조건 충족 도서를 대출횟수 기준 4개 그룹으로 분류
   - 1그룹(최저빈도) 15% / 2·3그룹(중간빈도) 70% / 4그룹(최고빈도) 15% 비율 적용
   - 총 선정 목표: 130권

3. **기관 유형별 보정 (선택 적용)**
   - 어린이 대상 기관: 아동 KDC(아동문학, 아동과학 등) 비중 우선
   - 노인 대상 기관: 큰 글씨 도서·실용서 우선
   - 혼합 기관: 전체 KDC 균형 반영

**출력 형식:**
```
[순회문고 배치 도서 선정 초안 — ○○기관]

총 선정 수: 130권

1그룹 (19권, 15%)
 · 『채식주의자』 등록번호 123456 — 대출 8회
 · ...

2·3그룹 (91권, 70%)
 · 『82년생 김지영』 등록번호 234567 — 대출 22회
 · ...

4그룹 (19권, 15% — 최고빈도)
 · 『아몬드』 등록번호 345678 — 대출 47회
 · ...

※ 최종 선정은 사서 확인 후 확정됩니다.
```

**Human-in-the-loop 필수:** 선정 초안 출력 후 반드시 사서 확인·수정·승인이 있어야 `배치 확정` 상태로 저장된다.

### FN-03 배치·회수 일정 관리

기관별 배치·회수 일정을 SQLite `schedules` 테이블에 등록하고 관리한다.

**저장 항목:**

| 필드 | 설명 |
|------|------|
| `schedule_id` | 자동 부여 ID |
| `institution_id` | 연결 기관 ID |
| `round` | 회차 (예: `2026-1차`) |
| `deploy_date` | 배치일 |
| `retrieve_date` | 회수 예정일 |
| `book_count` | 배치 도서 수 |
| `status` | `planned` / `deployed` / `retrieved` / `completed` |
| `memo` | 특이사항 |

**일정 알림:** 사서 요청 시 또는 업무 시작 시, 당월 배치·회수 예정 기관 목록을 출력한다.

```
[순회문고 일정 알림 — 2026년 5월]

이번 달 배치 예정
 · 창녕군립어린이집 — 5월 15일 (130권)
 · 남지읍 경로당 — 5월 22일 (130권)

이번 달 회수 예정
 · 창녕초등학교 — 5월 10일 (이번 주 내)
```

### FN-04 운영일지 초안 생성

사서가 기관명, 배치·회수일, 특이사항을 입력하면 에이전트가 운영일지 초안을 생성한다. hwpx 형식으로 출력하며, 결재란은 담당-팀장-과장 3단계로 구성한다.

**운영일지 포함 항목:**

| 항목 | 내용 |
|------|------|
| 사업명 | 순회문고 운영 |
| 기관명 | 해당 기관 |
| 회차 | 2026년 ○차 |
| 배치일 | 실제 배치 날짜 |
| 회수일 | 실제 회수 날짜 |
| 배치 도서 수 | 권수 |
| 회수 도서 수 | 권수 |
| 이용 현황 | 기관 담당자 확인 내용 (사서 입력) |
| 특이사항 | 파손, 분실, 기관 요청사항 등 |
| 결재란 | 담당 / 팀장 / 과장 |

**Human-in-the-loop 필수:** 초안 생성 후 사서 검토·수정·서명 후 사용. 에이전트는 초안만 제공하며 결재 완료 처리를 대행하지 않는다.

---

### FN-05 엑셀 관리대장 갱신

배치·회수가 완료되면 에이전트가 엑셀 관리대장을 갱신한다. 관리대장은 기관별 회차별 이력을 누적 관리한다.

**관리대장 시트 구성:**

| 시트명 | 내용 |
|--------|------|
| 기관목록 | 등록 기관 전체 정보 |
| 배치현황 | 회차별 배치 도서 목록 (기관별) |
| 회수현황 | 회수 완료 기록 |
| 연간집계 | 기관별 연간 배치·회수 건수, 이용 현황 요약 |

**openpyxl 기반으로 구현하며, 기존 구조화된 테이블(Excel Table)을 유지하는 방식으로 열 추가·갱신 처리한다.**

### FN-06 홈페이지 게시글 초안 생성

순회문고 모집 공고 또는 결과 안내 게시글 초안을 생성한다. 사서가 연도·신청 기간·문의처 등을 입력하면 에이전트가 공문서 형식에 맞는 게시글 본문을 출력한다.

**모집 공고 초안 예시:**
```
2026년 창녕도서관 순회문고 안내

창녕도서관에서는 지역 내 기관 및 단체를 대상으로 순회문고 서비스를 운영합니다.
순회문고는 도서관 자료를 일정 기간 기관에 대출해 드리는 서비스입니다.
비어 있는 서가를 도서관 책으로 채워보세요!

■ 신청기간: 2026년 연중 언제든지
■ 참여대상: 창녕군 소재 유치원, 학교, 기관 및 단체
■ 신청방법: 홈페이지(cnlib.gne.go.kr) 행사공지 게시판 신청서 작성 후
            aeonian@korea.kr로 제출
■ 문의: 055-532-9501

많은 관심과 신청 바랍니다.
경상남도교육청 창녕도서관
```

### FN-07 월간 실적 데이터 제공 (DM-03 연계)

매월 초 DM-03 독서문화 도메인 에이전트의 표준 데이터 수집 요청에 응답한다.

**요청 (DM-03 → D-06):**
```json
{ "requester_agent": "DM-03", "request_type": "monthly_result", "target_period": "2026-06" }
```

**응답:**
```json
{
  "agent_id": "D-06",
  "period": "2026-06",
  "deploy_count": 2,
  "retrieve_count": 1,
  "books_deployed": 260,
  "institutions_served": 2,
  "notable_issues": "[파손·분실 등 특이사항 요약, 없으면 생략]"
}
```

사서 개입 없이 자동으로 응답한다.

### FN-08 실시간 서비스 현황 응답 (C-03 연계)

C-03 프로그램안내 에이전트가 이용자 키오스크 질의에 응답하기 위해 조회하면 서비스 개요를 응답한다. 순회문고는 기관 대상 서비스이므로 개인 이용자에게는 간략 안내만 제공한다.

**요청 (C-03 → D-06):**
```json
{ "requester_agent": "C-03", "request_type": "current_program_status" }
```

**응답:**
```json
{
  "agent_id": "D-06",
  "service_summary": "창녕군 소재 기관·단체 대상 도서 순회 대출 서비스 (개인 이용자 신청 불가)",
  "application_method": "홈페이지 행사공지 게시판 신청서 제출"
}
```

사서 개입 없이 자동으로 응답한다.

## 4. 데이터 흐름

```
[신청 접수]
기관 → 이메일 신청 → 사서 → D-06: 기관 정보 등록

[도서 선정]
사서 → D-06: 대출 내역 엑셀 입력
D-06: 선정 기준 적용 → 130권 후보 초안 출력
사서: 확인·수정·승인 → 배치 확정

[배치]
사서 → D-06: 배치일 등록
D-06: schedules 테이블 업데이트 (planned → deployed)
D-06: 운영일지 초안 생성 → 사서 검토·결재

[회수]
사서 → D-06: 회수 완료 입력
D-06: schedules 업데이트 (deployed → retrieved → completed)
D-06: 관리대장 갱신

[수시]
사서 → D-06: 일정 알림 요청
D-06 → 사서: 당월 배치·회수 예정 목록 출력
```

## 7. 제약 및 예외 처리

| 상황 | 처리 방식 |
|------|----------|
| 선정 기준 적용 후 130권 미달 | 부족 수량 및 완화 가능 기준 안내 후 사서 판단 요청 |
| 기관 유형 미입력 상태에서 선정 요청 | 기관 유형 입력 요청 (연령대별 보정 적용 불가) |
| 엑셀 파싱 오류 | 실패 항목 목록화 후 사서 재입력 요청 |
| 배치 도서 파손·분실 보고 | 특이사항 필드에 기록, 운영일지 초안에 자동 반영 |
| 동일 기관 중복 배치 방지 | 직전 회수 완료 확인 후 신규 배치 일정 등록 허용 |

## 8. 비기능 요구사항

- 도서 선정 초안은 입력 파일 처리 후 즉시 출력되어야 한다.
- 관리대장 갱신은 openpyxl 기반으로 처리하며, Excel 구조화 테이블(Table) 형식을 유지해야 한다.
- SQLite 데이터는 연도 단위로 보존하며 삭제하지 않는다.
- 에이전트 응답 언어: 한국어

---

## 9. 데이터 모델 요약

```
institutions     — 순회문고 참여 기관 목록
schedules        — 회차별 배치·회수 일정
book_selections  — 회차별 선정 도서 목록 (배치 확정 후 저장)
```

---

## 10. 향후 확장 고려사항

- 기관별 이용 피드백(이용자 반응, 선호 장르 등) 수집 후 다음 회차 선정에 반영하는 피드백 루프 추가 검토
- 배치 도서 바코드 스캔 기반 자동 입출고 연동 검토
- 기관별 누적 이용 통계를 최상위 오케스트레이터 통계보고서에 연동 검토

# PRD — A-04 성과관리 에이전트 (Performance Management Agent)

**문서 버전:** 1.0  
**작성일:** 2026-05-11  
**소속 도메인:** D0 행정  
**에이전트 ID:** A-04  
**에이전트 유형:** Leaf Agent  
**참조 아키텍처:** 창녕도서관 사서 AI 에이전트 시스템 v3

---

## 1. 개요

### 1.1 목적

A-04 성과관리 에이전트는 도서관이 연초에 설정한 연간 성과 목표(1~2개)의 달성 여부를 정량적으로 추적하고, 사서에게 현황을 보고하는 리프 에이전트다. 사서가 직접 산식과 목표값을 등록하면, 에이전트는 최상위 오케스트레이터로부터 수신한 월간 지표값을 산식에 대입하여 달성률을 자동 계산하고 SQLite에 누적 저장한다.

### 1.2 배경

창녕도서관은 매년 경상남도교육청 성과관리 체계에 따라 1~2개의 정량적 성과 목표를 설정한다. 목표는 주로 전년 대비 증감률 형태이며, 단일 지표 산식 또는 가중치 복합 지표 산식이 사용된다. 기존에는 사서가 수기로 스프레드시트에 작년·올해 수치를 입력하고 달성률을 계산했으나, 이 과정을 에이전트가 자동화한다.

### 1.3 범위

- **포함:** 성과 목표 등록, 산식 저장, 월간 달성률 자동 계산, 달성 현황 보고, 연초 기준값 세팅
- **제외:** 성과 목표 자체의 적절성 판단, 목표 수립 제안, 타 기관 성과 비교, 예산 연계 분석

| 구분 | 역할 |
|------|------|
| 사서 (주 사용자) | 성과 목표 등록, 달성 현황 조회, 보고서 출력 요청 |
| 최상위 오케스트레이터 | 월간 지표값을 A-04에 패싱 |

## 3. 기능 요구사항

### FN-01 성과 목표 등록

사서가 자연어로 성과 목표를 지시하면, 에이전트가 구조화하여 SQLite `goals` 테이블에 저장한다.

**저장 항목:**

| 필드 | 설명 | 예시 |
|------|------|------|
| `goal_id` | 자동 부여 UUID | `g-2026-001` |
| `year` | 목표 연도 | `2026` |
| `goal_name` | 목표명 | `대출권수 10% 향상` |
| `indicators` | 지표 목록 (JSON) | 하단 참조 |
| `target_rate` | 목표 달성률 | `0.10` |
| `baseline_year` | 기준 연도 | `2025` |
| `created_at` | 등록 일시 | |

**`indicators` JSON 구조 (단일 지표 예시):**
```json
[
  {
    "name": "대출권수",
    "weight": 1.0,
    "baseline_value": null,
    "formula": "(current - baseline) / baseline"
  }
]
```

**`indicators` JSON 구조 (가중치 복합 지표 예시):**
```json
[
  {
    "name": "SNS 좋아요 수",
    "weight": 0.30,
    "baseline_value": null,
    "formula": "(current - baseline) / baseline"
  },
  {
    "name": "SNS 댓글 수",
    "weight": 0.70,
    "baseline_value": null,
    "formula": "(current - baseline) / baseline"
  }
]
```

> **제약:** 지표 가중치의 합은 반드시 1.0이어야 한다. 합이 1.0이 아닌 경우 에이전트는 등록을 거부하고 사서에게 수정을 요청한다.

---

### FN-02 기준값(전년도 실적) 세팅

연초(1월)에 사서가 전년도 확정 실적을 에이전트에 입력하면, `indicators[].baseline_value`를 업데이트한다. 최상위 오케스트레이터의 전년도 연간 보고서 데이터를 활용할 수 있으며, 사서가 직접 수동 입력하는 방식도 지원한다.

**Human-in-the-loop 필수:** 기준값 확정 전 에이전트는 반드시 사서에게 값을 제시하고 승인을 요청한다. 사서 승인 없이 기준값을 저장하지 않는다.

---

### FN-03 월간 지표값 수신 및 달성률 자동 계산

최상위 오케스트레이터가 월간 통계 보고서를 생성할 때 해당 월의 누적 지표값을 A-04에 전달한다. A-04는 수신 즉시 아래 절차를 수행한다.

**계산 절차:**

1. 각 지표별 증감률 계산: `(current - baseline) / baseline`
2. 가중치 적용 후 합산: `Σ (증감률 × weight)`
3. 목표값 대비 달성률 산출: `가중합산 증감률 / target_rate × 100`
4. 결과를 SQLite `progress` 테이블에 저장

**`progress` 테이블 저장 항목:**

| 필드 | 설명 |
|------|------|
| `goal_id` | 연결 목표 ID |
| `year_month` | 기준 연월 (예: `2026-04`) |
| `indicator_values` | 지표별 당월 누적값 (JSON) |
| `weighted_rate` | 가중합산 증감률 |
| `achievement_rate` | 달성률 (%) |
| `gap_to_target` | 목표까지 잔여 격차 |
| `recorded_at` | 기록 일시 |

---

### FN-04 달성 현황 보고

사서가 현황 조회를 요청하면, 에이전트는 최신 `progress` 레코드를 기반으로 보고 텍스트를 생성한다.

**보고 형식 (예시):**

```
[2026년 성과 목표 현황 — 2026년 4월 기준]

목표 1. 대출권수 10% 향상
  · 기준값(2025): 42,300권
  · 올해 누적(2026.1~4): 14,820권 → 연환산 추정: 44,460권
  · 현재 달성률: 5.1% / 목표 10% (달성률 51%)
  · 잔여 격차: 4.9%p

목표 2. SNS 종합 실적 향상 (좋아요 30% + 댓글 70%)
  · 좋아요: 기준 1,200 → 현재 320 (증감률 +6.7%)
  · 댓글: 기준 340 → 현재 95 (증감률 +11.8%)
  · 가중합산 증감률: (6.7%×0.3) + (11.8%×0.7) = 10.3%
  · 달성률: 목표 대비 103% ✓ 목표 초과 달성 중
```

> **연환산 추정:** 월별 일평균을 기반으로 연말 예상값을 추정 표시한다. 추정값임을 명시한다.

---

### FN-05 연간 목표 마감 및 결과 저장

12월 말 또는 사서 요청 시 해당 연도 목표의 최종 달성 결과를 확정하고 `goals` 테이블의 `final_achievement` 필드를 업데이트한다. 확정 전 사서 승인 필수.

## 4. 데이터 흐름

```
[연초]
사서 → A-04: 목표 등록 (목표명, 산식, 지표, 가중치, 목표값)
사서 → A-04: 전년도 기준값 입력 (승인 후 저장)

[매월]
최상위 오케스트레이터 → A-04: 월간 누적 지표값 패싱
A-04: 산식 계산 → SQLite 저장
A-04 → 사서: 달성 현황 알림 (선택)

[수시]
사서 → A-04: 현황 조회 요청
A-04 → 사서: 달성률 보고 텍스트 출력

[연말]
A-04: 최종 결과 확정 → 사서 승인 → 저장
```

## 6. Human-in-the-loop 정책

| 단계 | 사서 개입 여부 | 내용 |
|------|--------------|------|
| 목표 등록 | **필수** | 구조화 결과 확인 후 저장 승인 |
| 기준값 세팅 | **필수** | 전년도 실적값 확인 후 저장 승인 |
| 월간 달성률 계산 | 불필요 | 자동 수행 후 결과만 통보 |
| 현황 조회 | 불필요 | 사서 요청 즉시 응답 |
| 연간 결과 확정 | **필수** | 최종값 확인 후 확정 승인 |

---

## 7. 제약 및 예외 처리

| 상황 | 처리 방식 |
|------|----------|
| 가중치 합 ≠ 1.0 | 등록 거부, 사서에게 수정 요청 |
| 기준값 미입력 상태에서 계산 요청 | 계산 불가 안내, 기준값 입력 요청 |
| 지표값 미수신 (오케스트레이터 미패싱) | 해당 월 계산 보류, 사서에게 누락 안내 |
| 목표가 2개 초과 등록 시도 | 경고 후 사서 확인 요청 (시스템 제한은 없으나 운영 정책 준수 권고) |
| 연환산 추정 표시 | 반드시 "추정값" 명시, 확정값과 구분 |

---

## 8. 비기능 요구사항

- 계산 결과는 소수점 둘째 자리까지 표시한다.
- SQLite 데이터는 회계연도 단위로 관리하며, 이전 연도 데이터는 삭제하지 않고 보존한다.
- 에이전트 응답 언어: 한국어

---

## 9. 향후 확장 고려사항

- 목표 수가 3개 이상으로 늘어날 경우, 목표별 우선순위 필드 추가 검토
- 달성률 추이 시각화(차트) 출력 기능 추가 검토
- 경상남도교육청 성과관리 시스템 API 연동 시 자동 보고 기능 추가 검토

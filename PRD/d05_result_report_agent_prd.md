## 1. 개요

### 1.1 목적

D-05 결과보고 에이전트는 D3 독서문화 도메인에 속한 4개 리프 에이전트(D-01 동아리, D-02 행사기획, D-03 강사섭외, D-06 순회문고)의 운영 실적을 매월 취합하여 통합 결과보고서 hwpx 초안을 생성하는 에이전트다. 보고서 확정 후에는 참여율·만족도 등 실적 데이터를 D-02 행사기획 에이전트에 피드백하여 다음 달 기획에 반영되도록 하고, A-02 최상위이관 에이전트의 정기 데이터 수집 요청에도 응답한다.

### 1.2 배경

D4 평생학습 도메인은 E-01→E-05가 시즌 단위로 흐르는 단일 선형 파이프라인이라 E-05가 시즌 종료 시점에 한 번 실적을 취합하면 된다. 반면 D3 독서문화 도메인은 성격이 다른 리프 에이전트들이 서로 다른 주기로 병렬 운영된다.

| 에이전트 | 운영 주기 |
|---------|----------|
| D-01 동아리 | 상시 운영 (회차별 진행) |
| D-02 행사기획 | 매월 6개 행사 기획·운영 |
| D-03 강사섭외 | 수시 (행사 발생 시) |
| D-06 순회문고 | 상시 운영 (기관별 배치·회수) |

이 때문에 실적이 각 에이전트에 흩어져 있고, 사서가 매월 각 에이전트의 산출물을 일일이 모아 보고서를 작성해야 하는 번거로움이 있었다. D-05는 이 취합·통합 과정을 자동화한다.

### 1.3 범위

- **포함:** D-01·D-02·D-03·D-06 월간 실적 데이터 수신 및 검증, A-03 예산 집행 현황 조회, 월간 통합 결과보고서 hwpx 초안 생성, D-02 행사기획 피드백 전달, A-02 표준 데이터 수집 응답, 연간 누계 보고
- **제외:** 각 리프 에이전트의 개별 운영 업무 (D-01·D-02·D-03·D-06 담당), 결과보고서 실제 제출·결재 (사서 직접 처리), 예산 집행 결정 (A-03 담당)

## 4. 기능 요구사항

### FN-01 D3 리프 에이전트 실적 데이터 수신 및 검증

매월 초 D-01·D-02·D-03·D-06에 해당 월 실적 데이터를 요청하고, 응답을 필수 항목 기준으로 검증한다.

**공통 요청 구조 (D-05 → 각 에이전트):**
```json
{
  "requester_agent": "D-05",
  "request_type": "monthly_result",
  "target_period": "2026-06"
}
```

**소스별 필수 응답 항목:**

| 소스 | 필수 항목 |
|------|---------|
| D-01 동아리 | 동아리별 계획 회차·실시 회차, 총 참여자 수, 평균 출석률 (D-01 PRD FN-07 표준 형식 그대로 수신) |
| D-02 행사기획 | 행사별 명칭·유형·대상·정원·실참여 인원·모집충족률 |
| D-03 강사섭외 | 섭외 시도 건수, 성사 건수, 성사율, 강사비 합계 |
| D-06 순회문고 | 당월 배치·회수 건수, 배치 도서 수, 이용 기관 수 |

**검증 실패 시:** 누락·형식 오류 항목을 목록화하여 사서에게 해당 에이전트 재확인 요청. `status: unavailable`(해당 월 활동 없음)은 정상 처리하며 보고서에 "해당 없음"으로 표기한다.

### FN-02 예산 집행 현황 조회 (A-03 호출)

A-03 예산 에이전트에서 해당 월 독서문화 관련 예산(동아리 운영비, 행사 재료비·강사비, 순회문고 운영비 등) 집행 현황을 조회한다.

**조회 항목:**
- 항목별 편성액·집행액·잔액·집행률
- 도메인간 유용 발생 건수 및 금액 (해당 시)

### FN-03 월간 통합 결과보고서 초안 생성 (A-01 호출)

FN-01·FN-02에서 취합한 데이터를 통합하여 결과보고서 hwpx 초안을 생성한다.

**결과보고서 구성:**

| 항목 | 형식 | 내용 |
|------|------|------|
| 1. 운영 개요 | 개조식 | 대상 월, 취합 대상 사업 수, 총 참여자 수 |
| 2. 행사 운영 실적 | 표 | 행사명·유형·대상·정원·참여·모집충족률, 합계 행 포함 |
| 3. 독서동아리 운영 현황 | 표 | 동아리명·계획 회차·실시 회차·참여자 수·평균 출석률 |
| 4. 강사섭외 현황 | 표 | 섭외 시도·성사·성사율·강사비 합계 |
| 5. 순회문고 운영 현황 | 표 | 배치 기관 수·배치 도서 수·회수 건수 |
| 6. 홍보물 배포 현황 | 표 | 매체별(보도자료/인쇄물/SNS) 생성 건수, 대상 행사 |
| 7. 예산 집행 현황 | 표 | 항목별 편성액·집행액·잔액, 합계 행 포함 |
| 8. 성과 및 개선사항 | 개조식 | 잘된 점 (성과), 개선이 필요한 점 (개선사항) |

**행사 운영 실적 표 예시:**

| 행사명 | 유형 | 대상 | 정원 | 참여 | 모집충족률 | 비고 |
|-------|------|------|------|------|----------|------|
| 여름밤 그림책 낭독회 | 어린이 참여형 | 초등 저학년 | 15 | 14 | 93.3% | — |
| 로컬 크리에이터 토크 | 성인 참여형 | 성인 | 20 | 12 | 60.0% | 홍보 기간 촉박 |
| **합계** | | | **35** | **26** | **74.3%** | |

**성과·개선사항 자동 생성 기준:**

| 항목 | 자동 생성 조건 | 예시 문구 |
|------|-------------|---------|
| 성과 | 모집충족률 90% 이상 | "○○ 행사 모집충족률 ○%로 이용자 호응 우수" |
| 성과 | 강사섭외 성사율 80% 이상 | "이달 강사섭외 성사율 ○%로 원활한 진행" |
| 개선사항 | 모집충족률 60% 미만 | "○○ 행사 모집충족률 저조(○%) — 홍보 시점·대상 재검토 필요" |
| 개선사항 | 강사섭외 성사율 50% 미만 | "강사 후보군 확대 또는 섭외 시점 조정 필요" |
| 개선사항 | 동아리 평균 출석률 70% 미만 | "○○ 동아리 참여 저조(○%) — 운영 방식 재검토 필요" |

> 자동 생성 문구는 초안이며 사서가 반드시 검토·수정 후 사용한다.

**Human-in-the-loop 필수:** 결과보고서 초안 생성 후 사서 검토·수정·결재 후 사용.

### FN-04 D-02 행사기획 피드백

결과보고서 사서 확정 후 행사별 실적 데이터를 D-02 행사기획 에이전트에 전달하여 다음 달 기획 시 참고하도록 한다.

**전달 항목:**
```json
{
  "requester_agent": "D-05",
  "period": "2026-06",
  "events": [
    {
      "event_name": "로컬 크리에이터 토크",
      "event_type": "성인 참여형",
      "target_audience": "성인",
      "capacity": 20,
      "participants": 12,
      "recruitment_rate": 60.0,
      "notable_issue": "홍보 기간 촉박"
    }
  ]
}
```

**전달 시점:** 결과보고서 사서 확정 직후 자동 전달. D-02는 수신 데이터를 참고용으로만 활용하며(동일 유형 행사 반복 기획 시 모집충족률 저조 이력 회피 등), 데이터 저장·활용 방식은 D-02 자체 판단에 맡긴다.

### FN-06 연간 누계 보고 (연말 요청 시)

| 항목 | 내용 |
|------|------|

| 연간 예산 집행 요약 | 항목별 연간 편성·집행·잔액 |
| 차기 연도 기획 제언 | 데이터 기반 운영 방향 제언 (3~5개 개조식) |

## 5. 데이터 흐름

```
[매월 초]
D-05 → D-01·D-02·D-03·D-06: 전월 실적 데이터 요청
각 에이전트 → D-05: 표준 응답 (또는 unavailable)
D-05: 필수 항목 검증
  → 검증 실패: 사서에게 해당 에이전트 재확인 요청

D-05 → A-03: 전월 예산 집행 현황 조회
A-03 → D-05: 집행 현황 데이터 반환

D-05 → A-01: 통합 결과보고서 hwpx 초안 생성 요청
A-01 → D-05: hwpx 파일 경로 반환
D-05 → 사서: 초안 전달

사서: 결과보고서 검토·수정·결재 확정

[확정 후]
D-05 → D-02: 행사별 실적 데이터 피드백

[월간·연간 통계 수집 시]
A-02 → D-05: 데이터 수집 요청
D-05 → A-02: 표준 실적 데이터 응답

[연말]
자동 트리거 또는 사서 요청 → D-05: 연간 누계 보고 생성
```

- 에이전트 응답 언어: 한국어

## 11. D3 독서문화 실적 취합 구조

D-05는 D4 평생학습처럼 단일 선형 파이프라인의 종착점이 아니라, 서로 다른 주기로 병렬 운영되는 4개 리프 에이전트의 실적을 매월 한 곳으로 모으는 **취합 허브**다.

```
[상시]     [월간]      [수시]      [상시]
D-01   D-02       D-03       D-06
동아리  행사기획    강사섭외    순회문고
  └──────┴──────┬─────┴──────┘
                ↓
              D-05 (매월 취합)
                ↓
        통합 결과보고서 + D-02 피드백
```

D-02의 월간 행사 기획 주기에 맞춰 D-05도 월 단위로 취합을 실행하며, 행사 실적 피드백을 통해 D-02의 다음 달 기획 판단을 보조하는 약한 루프를 형성한다 (E-01↔E-05처럼 자동 데이터 반영 루프는 아니며, 참고 자료 제공 수준).

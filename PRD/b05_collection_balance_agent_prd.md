# PRD — B-05 균형 에이전트 (Collection Balance Agent)

**문서 버전:** 1.0
**작성일:** 2026-07-07
**소속 도메인:** D1 장서
**에이전트 ID:** B-05
**에이전트 유형:** Leaf Agent (공통 도구 에이전트)

---

> **표기 안내:** 이 문서의 `FN-01`, `FN-02`... 는 B-05 에이전트 내부 기능(Function) 번호다. 본문에 등장하는 `B-01`은 이 에이전트의 주 호출자인 실제 에이전트 참조다.

---

## 1. 개요

### 1.1 목적

B-05 균형 에이전트는 도서관 장서 전체의 KDC(한국십진분류법) 분류 균형을 분석하고, 결핍·과잉 분야를 근거로 수서 방향을 제언하는 공통 도구 에이전트다. B-01 수서 에이전트가 신간 후보를 점수화할 때 결핍 지수를 실시간 조회하는 데 사용하며, 사서가 정기적으로 장서 구성 전체 현황을 점검할 때도 직접 호출한다.

### 1.2 배경

`b01_acquisition_agent_prd.md`(FN-02·FN-03)는 KDC 균형 분석을 B-01이 자체 수행하는 것으로 설계되어 있었다. 그러나 B-03(복본 판정)을 별도 공통 도구 에이전트로 분리했던 것과 같은 이유로, 장서 균형 분석도 여러 도메인(B-01 신간 수서, 향후 B-02 희망도서 검토 등)에서 반복적으로 필요할 수 있는 독립 기능이다. B-05는 이 로직을 단일 에이전트로 일원화하여 판단 기준의 일관성을 확보한다.

> **B-05 vs C-02 추천 역할 구분**
> C-02는 이용자 개인의 즉석 도서 추천에 응답하는 에이전트이고, B-05는 장서 전체 단위의 KDC 분포를 분석하는 에이전트다(`PRD/c02_recommendation_agent_prd.md` 1.3·2절 참조). 개인 대상 여부로 구분한다.

### 1.3 범위

- **포함:** 장서 KDC 분류별 보유 통계 관리, 권장(목표) 비율 대비 결핍·과잉 분야 산출, B-01 요청 시 실시간 결핍 지수 응답, 사서 요청 시 정기 균형 분석 리포트 생성
- **제외:** 도서 선정·구입 결정 자체(B-01 담당), 복본 판정(B-03 담당), 개별 이용자 도서 추천(C-02 담당), 특정 행사·동아리용 도서 큐레이션(D-02·D-01 담당)

## 2. 업무 흐름 (Workflow)

```
[정기 통계 갱신]
사서 → B-05: 장서 KDC 통계 엑셀 업로드 (또는 SQLite 누적치 사용)
B-05: xlsx.js 파싱 → collection_kdc_stats 갱신 (FN-01)

[B-01 신간 후보 점수화 시점]
B-01 → B-05: 결핍 지수 조회 요청 (KDC 대분류 목록)
B-05 → B-01: 분야별 결핍 지수 응답 (FN-03, 자동)

[사서 정기 점검]
사서 → B-05: "장서 균형 분석 리포트 만들어줘"
B-05: 목표 비율 대비 현재 비율 비교 → 결핍/과잉 분야 정리 (FN-02)
B-05 → 사서: 균형 분석 리포트 + 수서 방향 제언 (FN-04)
```

## 3. 기능 요구사항

### FN-01 장서 KDC 통계 수집·갱신

사서가 업로드한 장서 KDC 통계 엑셀 파일을 파싱하여 `collection_kdc_stats` 테이블을 갱신한다.

**엑셀 업로드 항목(예상):** KDC 대분류(000~900), 소장 권수, 최근 1년 대출 횟수(선택), 갱신 기준일

처리는 `xlsx.js`(CDN 동적 로드, `CLAUDE.md` 기술스택 참조)로 수행하며, 실 LMS 연동 시 자동 수집으로 대체 가능하도록 설계한다. 파싱 실패 행은 목록화하여 사서에게 재업로드를 요청한다.

**(2026-07-09 신규) 실물 서식 확보:** 자료개발 도메인 실물 장서현황 문서(A-01 `ATT-008`)에서 실제 업로드 서식을 확인했다 — KDC 류별(000~900 행) × 자료실별(종합자료실/참고실/향토자료/다문화자료실/어린이자료실 열) 매트릭스이며, 각 셀은 보유수/증감/계 3개 하위 컬럼을 가진다. 위 "엑셀 업로드 항목(예상)"보다 훨씬 세분화되어 있으므로, FN-01 파싱 로직을 이 실물 매트릭스 구조에 맞춰 재설계할 필요가 있다(자료실별 분포까지 추적할지, 전체 합산치만 사용할지는 사서 확인 필요 — 8장 미결 사항 참조).

---

### FN-02 목표 비율 대비 결핍·과잉 분야 산출

**결핍 지수 계산:** `결핍지수 = 목표비율(%) - 현재비율(%)`. 값이 클수록(양수) 결핍, 음수면 과잉으로 판단한다.

**목표 비율 출처(Config로 주입, 기관별 상이):**
- 기관 자체 기준(예: 도서관 운영위원회 승인 비율)
- 공공도서관 통계 벤치마크(참고용, 기관이 직접 값을 확정)

목표 비율이 설정되지 않은 경우, 결핍 지수를 계산하지 않고 사서에게 목표 비율 등록을 우선 요청한다(임의 기본값 가정 금지).

**(2026-07-09 신규) 목표 비율 후보 산식 발견:** 자료개발 실물 「자료 확충 계획」 문서(A-01 `ATT-006`)에서 다음 산식을 확인했다 — `2026년 류별 확충 비율(D) = [(전년 대출비율 A) + (전년 확충비율 B) + (전체장서비율 C)] / 3`, `확충권수(E) = 예상권수 × D / 100`. 이는 "목표 비율"이 아니라 "연간 확충 배분 비율" 산식이라는 점에 유의 — B-05의 `kdc_target_ratios`(장기 목표)와는 다른 개념일 수 있으며, 채택 여부는 사서 협의 필요(아래 미결 사항 4번).

---

### FN-03 B-01 결핍 지수 실시간 응답

B-01이 신간 후보 점수화(`b01_acquisition_agent_prd.md` FN-03 ③ 장서 균형 항목) 시 아래 형식으로 요청하면 즉시 응답한다.

**요청:**
```json
{ "requester_agent": "B-01", "kdc_majors": ["000", "300", "800", "..."] }
```

**응답:**
```json
{
  "agent_id": "B-05",
  "as_of": "[기준일]",
  "results": [
    { "kdc_major": "300", "current_pct": 12.0, "target_pct": 18.0, "deficiency_index": 6.0 },
    { "kdc_major": "800", "current_pct": 22.0, "target_pct": 15.0, "deficiency_index": -7.0 }
  ]
}
```

사서 개입 없이 자동으로 응답한다.

### FN-04 정기 균형 분석 리포트

사서 요청 시 전체 KDC 대분류에 대한 현황·목표·결핍지수 표와 우선 확충 분야(결핍지수 상위 N개)를 정리해 제시한다.

**출력 형식:**
```
[장서 균형 분석 — 기준일: YYYY-MM-DD]

| KDC 대분류 | 현재 비율 | 목표 비율 | 결핍지수 | 상태 |
|-----------|---------|---------|---------|------|
| 300 사회과학 | 12.0% | 18.0% | +6.0 | 결핍 |
| 800 문학    | 22.0% | 15.0% | -7.0 | 과잉 |
...

우선 확충 제언 (결핍지수 상위 3개): 300, ...
```

이 리포트는 공문서(기안문)가 아니라 내부 참고 자료이므로 A-01 호출 없이 텍스트/표 형식으로 직접 제시한다. 별도 공문 형태가 필요하면 사서 요청 시에만 A-01을 호출한다.

## 4. 비기능 요구사항

| 항목 | 기준 |
|------|------|
| 자동 처리 범위 | FN-03(B-01 결핍 지수 응답)은 사서 개입 없이 자동 처리 |
| Human-in-the-loop | 목표 비율 최초 등록·변경은 사서 확정 필수. 수서 방향 최종 결정은 B-01/사서가 함(B-05는 제언만) |
| 데이터 정확성 | 목표 비율 미설정 시 임의 기본값을 가정하지 않고 등록을 요청 |
| 갱신 주기 | 사서가 임의 시점에 재업로드 가능. 강제 주기는 없음(연 1~2회 권장, Config 안내용) |

## 6. 도구 및 MCP 연동

| 도구 / 에이전트 | 사용 시점 |
|----------------|---------|
| MCP Filesystem | 장서 KDC 통계 엑셀 파일 로드 |

외부 API 연동 없음. 실 LMS 연동 전까지는 사서 엑셀 업로드(연구용) 방식으로 운영한다.

## 7. 수용 기준 (Acceptance Criteria)

- **AC1**: 목표 비율이 등록된 상태에서 B-01의 결핍 지수 요청에 사서 개입 없이 즉시 응답한다.
- **AC2**: 목표 비율이 미등록된 KDC 대분류는 결핍 지수 계산 없이 등록 필요 안내를 반환한다.
- **AC3**: 엑셀 업로드 파싱 실패 행은 목록화되어 사서에게 재업로드가 요청된다.
- **AC4**: 정기 균형 분석 리포트는 결핍지수 기준 우선 확충 분야를 명시적으로 제시한다.
- **AC5**: B-05는 스스로 수서를 결정하거나 실행하지 않는다(항상 B-01/사서의 참고 자료로만 기능).

## 8. 미결 사항 (Open Questions)

1. **목표 비율 확정 방식**: 기관 자체 기준을 사서가 직접 입력할지, 공공도서관 통계 벤치마크 수치를 기본 초안으로 제공하고 사서가 조정하게 할지 결정 필요 (`b01_acquisition_agent_prd.md` 9절의 동일 미결 사항과 연동).
2. **B-01 FN-02와의 통합**: 현재 `b01_acquisition_agent_prd.md` FN-02·FN-03에는 "KDC 균형 분석(B-01 자체 수행)"으로 기술되어 있다. B-05 도입 후에는 이를 "B-05 호출"로 갱신해야 하며, 본 PRD와 함께 반영한다(아래 참고).
3. **실LMS 연동 시점**: 소장 통계를 실시간 자동 수집으로 전환할 API/DB 연동 방식 확정 필요.
4. **(2026-07-09 신규) 확충 비율 산식(D=[A+B+C]/3) 채택 여부**: 자료개발 실물 문서에서 발견한 산식을 FN-02의 "목표 비율"과 별개로 "연간 확충 배분" 계산에 채택할지, 채택 시 FN-02와 어떻게 통합할지 결정 필요.
5. **(2026-07-09 신규) 자료실별 세분화 반영 여부**: FN-01 실물 서식(`ATT-008`)이 자료실별(종합자료실/참고실/향토자료/다문화자료실/어린이자료실) 매트릭스인데, 현재 `collection_kdc_stats`는 KDC 대분류 단일 축만 가정한다 — 자료실별 결핍 지수까지 B-01에 제공할지, 전체 합산치만 유지할지 결정 필요.
6. **(2026-07-31 신규) 이용대상 축 ↔ KDC 주제 축 매핑 규칙**: B-01의 수서 계획 산정 기준(2026-07-31 확정)에 이용대상별 분야 배분(일반성인 50 / 청소년 10 / 어린이 25 / 유아 15)이 신설됐다. `kdc_target_ratios`는 KDC **주제** 분류이고 이 배분은 **이용대상** 분류라 축이 다르므로, 두 기준을 같은 표에 혼합 제시하지 않는다. 매핑 후보는 `public.books.room` + ISBN 부가기호 독자대상기호(`7`=어린이, `4`=청소년, `6`/`5`=학습참고서 제외) 조합이나, **어린이와 유아를 구분할 신호가 현재 데이터에 없다**. 사서가 "이용대상별 결핍 지수"를 요청하면 규칙 확정을 먼저 요청하고 추정값을 만들지 않는다 (`b01_acquisition_agent_prd.md` 9절 10번과 연동).

# PRD — A-03 예산 에이전트 (Budget Management Agent)

**문서 버전:** 1.0  
**작성일:** 2026-05-23  
**소속 도메인:** D0 행정  
**에이전트 ID:** A-03  
**에이전트 유형:** Leaf Agent (공통 도구 에이전트)  
**참조 아키텍처:** 창녕도서관 사서 AI 에이전트 시스템 v3

---

## 1. 개요

### 1.1 목적

A-03 예산 에이전트는 창녕도서관의 도메인별 예산 편성·집행·잔액을 관리하는 공통 도구 에이전트다. 각 도메인 에이전트가 예산 잔액 조회 또는 집행 기록을 요청할 때 A-03을 호출하며, A-03은 단일 창구로서 전체 예산 현황을 일원화하여 관리한다. 최상위 오케스트레이터에는 월간 예산 현황 데이터를 정기 보고한다.

### 1.2 배경

창녕도서관은 K-EduFine(경상남도교육청 예산회계시스템) 기반으로 예산을 편성·집행하나, 실시간 잔액 조회나 도메인별 집행 현황 파악은 수기 엑셀로 관리하는 실정이다. A-03은 K-EduFine과 동일한 구조의 Excel 파일을 기반으로, 에이전트 생태계 내에서 예산 현황을 실시간으로 관리하고 도메인 에이전트에 잔액 정보를 제공한다.

### 1.3 예산 구조

**연간 예산 규모 (참고, 실운영 시 확정값으로 대체):**

| 도메인 | 주요 예산 항목 |
|--------|--------------|
| D0 행정 | 사무용품비, 시설유지비 |
| D1 장서 | 도서구입비, 제본비 |
| D2 이용자 | 순회문고 운영비 |
| D3 독서문화 | 행사비, 강사비, 홍보물 제작비 |
| D4 평생학습 | 강사비 1,500만원, 운영물품비 300만원 |
| D5 홍보협력 | SNS 운영비, 소식지 제작비 |

### 1.4 범위

- **포함:** Excel 기반 예산 편성·집행·잔액 관리, 도메인 에이전트 잔액 조회 서비스, 집행 기록, 도메인간 예산 유용 보고문 초안 생성, 월간 현황 보고, 이상 집행 경고
- **제외:** K-EduFine 직접 연동, 실제 지출 결제·송금, 예산 편성 권한 (사서·최고관리자 담당), 세입 관리, 연간 결산 (최고관리자 담당)

B-01    D-02    E-01    기타 에이전트

## 4. Excel 예산 파일 구조 (K-EduFine 동일 구조)

사서가 K-EduFine 구조와 동일하게 구성된 xlsx 파일을 매년 1월 초 지정 경로에 업로드한다.

**필수 시트 구성:**

| 시트명 | 내용 |
|--------|------|
| 편성예산 | 도메인별·항목별 연간 편성액 |
| 집행내역 | 날짜·도메인·항목·금액·적요·집행 에이전트·유용 여부 |
| 잔액현황 | 편성액 - 집행액 = 잔액 (자동 계산) |

**집행내역 시트 컬럼:**

| 컬럼명 | 필수 여부 | 설명 |
|--------|----------|------|
| 집행일 | 필수 | YYYY-MM-DD |
| 도메인 | 필수 | D0~D5 |
| 예산항목 | 필수 | 도서구입비·강사비·재료비 등 |
| 집행금액 | 필수 | 원 단위 정수 |
| 적요 | 필수 | 지출 내용 요약 |
| 집행 에이전트 | 선택 | 요청 에이전트 ID (예: B-01) |
| 도메인간유용 | 선택 | Y/N, Y이면 차용 도메인·승인일 기재 |
| 승인번호 | 선택 | 최고관리자 승인 시 부여 |

## 5. 기능 요구사항

### FN-01 잔액 조회 서비스 (타 에이전트 호출 시)

도메인 에이전트가 집행 전 잔액을 조회하면 즉시 응답한다.

**처리 흐름:**
```
1. 호출 에이전트 → A-03: 도메인 코드 + 예산 항목 + 필요 금액 전달
2. A-03: Excel 잔액현황 시트 조회
3. 응답:
   · 필요 금액 ≤ 잔액: "집행 가능" + 잔액 금액
   · 필요 금액 > 잔액: "예산 부족" + 잔액 금액. 사업 기획 목적 조회이면 FN-07(사업항목 간 예산 유용, Bottom-Up) 절차를 우선 안내하고, 같은 단위과제카드 내에서 해결되지 않을 때만 FN-04 도메인간유용 절차를 안내
```

---

### FN-02 집행 기록 (타 에이전트 호출 시)

도메인 에이전트가 집행 내역을 전달하면 Excel에 기록하고 잔액을 갱신한다.

**처리 흐름:**
```
1. 호출 에이전트 → A-03: 도메인·항목·금액·적요·집행일 전달
2. A-03: 자기 도메인 예산 여부 확인
   · 자기 도메인: 집행내역 시트 즉시 기록 → 잔액 갱신
   · 타 도메인 요청: FN-04 도메인간유용 절차 진행
3. 집행 완료 응답 반환
```

---

### FN-03 이상 집행 탐지 및 경고

Excel 잔액 현황을 주기적으로 점검하여 이상 집행을 탐지하고 사서에게 경고한다.

**경고 기준:**

| 상황 | 기준 | 처리 |
|------|------|------|
| 잔액 임박 | 잔액 < 편성액의 10% | 해당 도메인 에이전트 및 사서에게 경고 |
| 조기 소진 위험 | 6월 말 이전 집행률 70% 초과 | 사서에게 경고 + 집행 속도 조정 권고 |
| 불용 예상 | 10월 기준 연말 잔액 추정 > 편성액 15% | 최고관리자에게 불용 예상 보고 |
| 유용 반복 | 동일 도메인 월 2회 이상 유용 | 사서에게 예산 재편성 검토 권고 |

**경고 출력 예시:**
```
[A-03 예산 경고 — 2026년 6월]

⚠️ 조기 소진 위험
 · D4 평생학습 — 강사비: 집행률 73% (6월 기준)
   편성 15,000,000원 / 집행 10,950,000원 / 잔액 4,050,000원

📋 불용 예상 (10월 기준 연말 추정)
 · D2 이용자 — 순회문고 운영비: 연말 잔액 추정 22%
   → 집행 계획 재검토 권고
```

### FN-04 도메인간 예산 유용 처리

도메인 에이전트가 자기 도메인 예산 부족으로 타 도메인 예산 사용을 요청하는 경우 처리한다.

**유용 허용 조건 (모두 충족 시):**
1. 자기 도메인 예산 잔액 부족 또는 복수 도메인 협업 비용 분담
2. 인간 최고관리자 사전 승인
3. 집행 내역에 유용 플래그 및 사유 명기

**처리 흐름:**
```
1. 유용 요청 접수
2. 보고문 초안 자동 생성 (hwpx, A-01 호출)
   · 포함: 요청 에이전트·도메인, 차용 도메인·항목, 금액·용도, 자기 도메인 잔액, 요청일
3. 사서를 통해 최고관리자 보고
4. 승인 수신:
   · 승인: 집행 기록 반영 + 승인번호 기재
   · 반려: 요청 에이전트에 반려 사유 전달
```

**Human-in-the-loop 필수:** 도메인간 유용은 반드시 최고관리자 승인 후 집행 기록된다. A-03은 승인 없이 유용 집행을 기록하지 않는다.

---

### FN-05 월간 예산 현황 보고 (최상위 오케스트레이터 연계)

매월 초 A-02 최상위이관 에이전트의 데이터 수집 요청에 응답하여 전월 예산 현황을 전달한다.

**보고 항목:**
- 도메인별 편성액·집행액·잔액·집행률
- 도메인간 유용 발생 건수 및 금액
- 이상 집행 탐지 건수

**월간 예산 현황 요약 예시:**
```
[예산 현황 월간 보고 — 2026년 4월]

도메인별 집행 현황
 · D0 행정:   편성 2,000,000 / 집행 450,000 / 잔액 1,550,000 (22.5%)
 · D1 장서:   편성 30,000,000 / 집행 8,250,000 / 잔액 21,750,000 (27.5%)
 · D3 독서문화: 편성 8,000,000 / 집행 3,200,000 / 잔액 4,800,000 (40.0%)
 · D4 평생학습: 편성 18,000,000 / 집행 7,300,000 / 잔액 10,700,000 (40.6%)

도메인간 유용: 1건
 · D3 → D4 강사비 유용 200,000원 (승인번호: 2026-04-001)

이상 탐지: 없음
```

### FN-06 공문서 초안 생성 (예산 관련)

예산 전용·이체·집행 계획 공문서가 필요할 때 A-01을 호출하여 초안을 생성한다.

**해당 공문 유형:**
- 도메인간 예산 유용 승인 요청 보고문
- 예산 전용(轉用)·이체 기안문
- 연말 불용 예산 처리 기안문

---

### FN-07 사업항목 간 예산 유용 절차 (Bottom-Up)

> 실제 운영 스펙(`.claude/agents/a-03-budget-management.md`)에서는 이 기능이 **FN-08**로 번호가 부여되어 있다(스펙에는 실제 Excel 원장 연동 기능인 FN-07 자동 매칭이 이미 존재하기 때문). 이 문서에서는 PRD 자체의 기존 FN 번호 순서를 유지하기 위해 FN-07로 표기한다.

사업(행사·프로그램 등)을 **기획하는 단계**에서 FN-01 잔액 조회 결과 특정 예산 항목의 잔액이 부족하다고 판정되면, 최고관리자 승인이 필요한 FN-04(도메인간 유용)로 바로 넘어가지 않고 먼저 **같은 상위 사업(단위과제카드) 안에서** 대체 재원을 찾는다. 사서의 채팅 확인만으로 진행되며 최고관리자 승인은 필요 없다.

**처리 흐름:**
```
1. 예산 부족 통지 + 대체 탐색 동의 요청
   "예산이 부족합니다. 다른 항목의 예산을 사용하시겠습니까?"
   → 부정 회신: 즉시 중단(대체 탐색 없이 계획서 작성 중단)

2. Bottom-Up 탐색 (동의 시)
   부족 항목의 예산 계층에서 가장 가까운(하위) 단계부터 순서대로 넓혀가며
   같은 상위 항목에 속한 다른 세부 항목을 탐색한다.
   유효 후보(잔액 ≥ 필요 금액)가 있는 첫 단계에서 탐색을 멈춘다.
   ※ 상위 사업(단위과제카드) 자체를 넘는 탐색은 하지 않음 — 그 경우는 FN-04로만 처리.

3. 후보 제시 및 사용 확인
   찾은 단계의 후보(항목명 + 현재 잔액)를 제시하고 "이 예산을 사용하시겠습니까?" 질문

4. 결과 처리
   긍정(항목 지정): 해당 항목을 대체 재원으로 확정, 이후 집행 기록도 그 항목에 반영
   부정: 해당 계획서 작성을 즉시 중단, 자동으로 다음 단계를 재탐색하지 않음
   모든 단계에서 후보 없음: FN-04 진행 또는 계획 축소·중단 여부를 사서에게 확인
```

**예시 (실제 예산 계층 기준):**
```
부족 항목: 종합자료실운영 > 1.공공도서관자료실운영 > 가.창녕도서관 > 2)자료실운영 > 라)업무용소프트웨어구입

"예산이 부족합니다. 다른 항목의 예산을 사용하시겠습니까?" → (긍정)

같은 "2)자료실운영" 내 다른 항목입니다. 이 예산을 사용하시겠습니까?
 · 가)도서정리용품구입 — 현재 잔액 3,830,700원
 · 나)전산용품구입 — 현재 잔액 1,358,540원
→ (긍정, 항목 선택) → 해당 항목으로 진행 / (부정) → 계획서 작성 중단
```

**분할 집행 미지원:** 한 대체 항목의 잔액만으로 필요 금액 전액을 감당하지 못하면 그 항목은 후보에서 제외한다(여러 항목에 나눠 충당하는 분할 집행은 지원하지 않음).

## 9. 제약 및 예외 처리

| 상황 | 처리 방식 |
|------|----------|
| Excel 파일 형식 오류 | 오류 셀 위치 특정 후 사서에게 수정 요청 |
| 최고관리자 승인 지연 | 보류 상태 유지, 사서에게 촉구 알림 |
| 동일 항목 중복 집행 기록 | 중복 의심 플래그 후 사서 확인 요청 |
| 편성예산 시트 미업데이트 | 전년도 파일 감지 시 경고 후 신규 파일 요청 |
| K-EduFine 실적과 불일치 | 에이전트 범위 외, 사서가 수동 대사(對査) 수행 |
| FN-07 모든 단계에서 대체 항목 후보 없음 | 같은 단위과제카드 내 대체 재원 없음을 안내, FN-04 진행 또는 계획 축소·중단 여부 확인 |
| FN-07 진행 중 사서가 부정 회신 | 해당 계획서 작성 즉시 중단, 명시적 재요청 전까지 재개하지 않음 |

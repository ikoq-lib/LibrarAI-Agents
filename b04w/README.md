# B-04-W 자료조직 프로그램

입고 목록(xlsx/csv) 한 건씩을 KDC 분류 + KORMARC 레코드로 만든다. 규칙의 출처는
`.claude/agents/b-04-w-cataloging-worker.md`이고, 이 프로그램은 그 규칙 중 **결정론적인
부분을 코드로 옮긴 것**이다. 워커(LLM)에게는 판단이 필요한 것만 남긴다.

| 코드가 계산한다 | LLM이 판단한다 |
|---|---|
| 저자기호 숫자(리재철 제5표), LDR·008 자릿수, 필드 지시기호, ISBD 구두점, 청구기호 조립, 제어번호 채번, 저자기호 충돌 ±1 조정 | KDC 분류번호, 주제명표목·키워드, 책임표시 정리, 번역 여부·원표제, 문학형식 |

배치 단위로 같은 실수가 301번 반복되는 것을 막으려면 자릿수·구두점 같은 것은 매번
다시 판단하게 두면 안 된다. 실제로 2026-09-02 배치에서 008이 38자로 나간 사고가
4건 있었다.

## 실행

```bash
cd b04w
python prep_4th_general.py ../.artifacts/b04w_4th_general_prep.csv   # 구입 목록 → 입고 목록
python run_batch.py --input ../.artifacts/b04w_4th_general_prep.csv \
    --out ../outputs/20260904_b04w_4th_general --workers 16
python to_xlsx.py ../outputs/20260904_b04w_4th_general/처리현황.csv
```

옵션: `--limit N`(앞 N건만), `--skip-web`(웹 보강 생략), `--model`(기본 `qwen/qwen3.7-plus`).

## 6단계

| 단계 | 하는 일 | 병렬 | 캐시 |
|---|---|---|---|
| 1 SEOJI | 표제·책임표시·면수·판형·부가기호·정가 | 직렬(0.25초 간격) | `cache/seoji/` |
| 2 웹검색 | 목차·책소개·번역 정보 (도서 단위) | O | `cache/web/` |
| 3 발행지 | 260 `$a`·008/15-17 (출판사 단위) | O | `data/publisher_places.json` |
| 4 장서 DB | 제어번호 재사용·복본 판정·같은 저자 분류 선례·세목 분포 | O | — |
| 5 분류 | KDC·주제명·책임표시 (LLM) | O | `cache/classify/` |
| 6 조립·QA | 저자기호·레코드 조립·점검 | 직렬 | — |

**캐시가 이 프로그램의 재실행 안전장치다.** 외부 API 호출이 배치당 수백 건이라
재실행 비용이 그대로 돈이다. 중간에 끊겨도 같은 명령으로 이어서 돌리면 조회한 건은
다시 부르지 않는다. 다만 **실패는 캐시하지 않는다** — 다음 실행에서 다시 시도해야 한다.

## 서지 출처가 이렇게 된 이유

**SEOJI(국립중앙도서관)가 유일한 서지 API다.** 알라딘은 2026-07-09 차단, 네이버 책
검색은 2026-09-01 종료, data.go.kr `BookInformationService`는 폐기됐다(2026-09-04
`NO_OPENAPI_SERVICE_ERROR` 확인). 그런데 SEOJI로 메울 수 없는 구멍이 둘 있다.

- **발행지가 아예 없다.** SEOJI 응답 37개 필드 어디에도 없고 자관 `public.books`에도
  열이 없다. 그래서 출판사 단위로 웹에서 확인해 `data/publisher_places.json`에 쌓는다.
  도서(301)가 아니라 출판사(222) 단위인 이유는 그만큼 호출이 줄기 때문이다.
- **목차·책소개가 거의 비어 있다.** 표본 20건 중 2건만 채워져 있었다(2026-09-04 실측).
  분류를 추정으로 하지 않으려면 이 둘이 필요해서 도서 단위로 웹 보강을 한다.

웹 보강은 Gemini `google_search` 그라운딩을 먼저 쓰려 했으나 키 쿼터가 소진돼
(HTTP 429) OpenRouter web 플러그인으로 갔다. 어느 쪽이든 **검색 결과에 근거가 없으면
빈 값을 돌려받아 `[발행지불명]` + `needs_info`로 넘긴다.** 추정 기재는 하지 않는다.

## 분류를 자관 관행에 맞추는 두 가지 근거

KDC6 표만 보고 분류하면 자관이 채택하지 않은 별법으로 가서 서가 배열이 깨진다.
그래서 프롬프트에 자관 실측 두 가지를 함께 넣는다.

1. **같은 저자의 자관 기존 소장** — 이 저자의 앞 책을 우리 관이 어디에 두었는가.
   표보다 강한 근거다. 실제로 『분투 없이 열리는 길은 없다』(권태선)에서 구입 목록의
   주제란은 사회과학이었지만, 같은 저자의 『진실에 복무하다: 리영희 평전』이 070.99에
   있는 것을 보고 073.91(한국 방송)로 잡았다.
2. **후보 강목의 세목 분포** — `public.books` 73,390행에서 그 강목 아래 세목별 건수.
   압도적 다수가 쓰는 세목을 따른다.

## 알려진 한계

- 세목 분포 교차검증은 **이미 고른 강목 안에서만** 작동한다. 강목 자체가 어긋나면
  잡지 못한다 — 저자 선례가 이 구멍을 일부 메우지만 전부는 아니다.
- 발행지가 확인되지 않은 출판사는 `[발행지불명]`으로 남는다. 사서가
  `data/publisher_places.json`의 `places`에 값을 채우면 다음 배치부터 자동 적용된다.
- 쪽 번호가 인쇄되지 않은 자료(주로 그림책)의 `300 $a` 대괄호 판정은 `unpaged`
  입력에 의존한다. 성인 자료 배치에서는 거의 쓰이지 않는다.
- **모든 출력은 사서 검토 전 초안이다.** `status`가 `ok`여도 분류의 타당성과 요약의
  사실성은 기계가 판정하지 않는다.

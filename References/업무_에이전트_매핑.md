# 연간 업무 내역 ↔ 담당 에이전트 매핑

> **목적:** `References/연간 업무 내역.xlsx`(업무일정 시트, 88행)는 사용자가 직접 관리하는 원본 업무 흐름표이며 "에이전트" 컬럼은 비워둔 채로 유지한다(원본 파일 비수정). 이 문서는 그 원본을 대체하지 않고, chief-coordinator가 월간/주간 계획서를 생성할 때 "이번 기간에 예정된 업무를 어느 DM에 물어야 하는가"를 판단하기 위해 참조하는 별도 매핑 표다.
>
> 원본 xlsx의 "업무종류" 컬럼(자료개발/독서진흥/기획담당/평생학습)은 부서 관점 분류이며, 실제 업무 내용 기준으로는 담당 DM이 다르게 매핑되는 경우가 있다(예: "기획담당"으로 분류된 "인문학"은 실제로는 평생학습 강좌 운영 방식과 동일해 DM-04가 적합). 아래 표의 "담당"은 부서 분류가 아니라 **실제 에이전트 라우팅 기준**이다.
>
> 업데이트 시점: 2026-07-18. 원본 xlsx의 업무명이 추가/변경되면 이 표도 함께 갱신한다.

## 사용 방법 (chief-coordinator)

1. 월간/주간 계획서 생성 시 `References/연간 업무 내역.xlsx`의 "업무 일정" 컬럼을 대상 기간과 대조해 해당하는 행을 추출한다.
2. 추출된 각 행의 "업무명"을 이 표에서 찾아 담당(들)을 확인한다.
3. 담당이 DM인 경우 해당 DM에 `plan_request`(해당 업무명을 명시)를 보낸다.
4. 담당이 "chief-coordinator 직접"인 경우 DM에 위임하지 않고 chief-coordinator가 직접 처리한다(필요 시 A-01/A-02/A-04 호출).
5. 복수 담당이 걸친 업무(도서관 홍보, 도서관의날 등)는 관련 DM 모두에 조회 후 chief-coordinator가 하나의 섹션으로 편집·통합한다(FN-02/FN-04와 동일한 "DM이 서술, 최상위는 편집" 원칙).
6. 이 표에 없는 신규 업무명이 xlsx에 추가되면, FN-01의 키워드 기반 라우팅 규칙으로 우선 처리하고 이 표를 갱신한다.

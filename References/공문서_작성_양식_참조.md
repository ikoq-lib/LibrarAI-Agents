## 2. 도서관 공문서 종류별 본문 패턴

### 2-1. 행사 운영 계획

```
수신  내부결재
제목  [연월] [행사명] 운영 계획

1. 관련: [기관명]-[번호]([날짜], "[관련 계획명]")
2. 지역민의 도서관 이용 활성화를 적극적으로 유도하기 위해 "[행사명]"을 다음과 같이 수립하여 운영하고자 합니다.

  가. 운영기간: [날짜] ~ [날짜]
  나. 운영장소: [도서관명]
  다. 운영대상: 어린이, 청소년, 성인 등 [지역명]
  라. 운영내용: [대표행사명] 등 [N]개 행사
  마. 소요금액: 금[숫자]원(금[한글금액]원)
  바. 예산과목: [예산과목명]

붙임  [연월] [행사명] 운영 계획 1부.  끝.
```

### 2-2. 행사 운영 결과

```
수신  내부결재
제목  [연월] [행사명] 운영 결과

1. 관련: [기관명]-[번호]([날짜], "[운영 계획 문서명]")
2. 지역민의 도서관 이용 활성화를 위해 실시한 "[행사명] 운영 결과"를 다음과 같이 보고합니다.

  가. 운영기간: [날짜] ~ [날짜]
  나. 운영장소: [도서관명]
  다. 운영대상: 어린이, 청소년, 성인 등 [지역명]
  라. 운영내용: [대표행사명] 등 [N]개 행사 운영 [참가자수]명 참가
  마. 지출금액: 금[숫자]원(금[한글금액]원)
  바. 지출과목: [예산과목명]

붙임  [연월] [행사명] 운영 결과 1부.  끝.
```

### 2-3. 이용 실적 보고

```
수신  내부결재
제목  [연도] [월] 도서관 이용 실적 보고

우리 도서관의 [연도] [월] 이용 실적을 다음과 같이 보고합니다.

1. 기간: [날짜] ~ [날짜]
2. [월] 이용 실적

  [표: 대출실적(대출권수, 대출자수) / 행사실적(행사개수·회, 행사참여자수)]

붙임  [연도] [월] 및 누적 이용실적 1부.  끝.
```

## 3. 작성 규칙 (2025 개정 공문서 작성법 핵심)

### 항목 기호 체계

| 순서 | 항목 기호 | 대체 특수부호 |
|------|-----------|--------------|
| 첫째 | 1., 2., 3. | □ |
| 둘째 | 가., 나., 다. | ○ |
| 셋째 | 1), 2), 3) | - |
| 넷째 | 가), 나), 다) | • |
| 다섯째 | ⑴, ⑵, ⑶ | |
| 여섯째 | ㈎, ㈏, ㈐ | |
| 일곱째 | ①, ②, ③ | |
| 여덟째 | ㉮, ㉯, ㉰ | |

- 하위 항목은 앞 항목으로부터 2타(한글 1자) 들여쓰기
- 항목 기호와 내용 사이: 1타 띄움

### 날짜 표기

- **올바름**: `2025. 1. 6.` / `2025. 2. 20.～2. 24.`
- **틀림**: `2025.1.6` / `'25. 1. 6.` / `2025. 2. 20(24).`
- 요일: `2025. 1. 6.(월)`
- 기간: 물결표(～) 또는 붙임표(-) 사용

### 시간 표기

- **올바름**: `09:00` / `13:20` / `09:30～12:20`
- **틀림**: `오전 9시` / `9시` / `13 : 20`
- 24시각제, 쌍점(:) 양쪽 붙여씀

### 금액 표기

- **비계약 금액**: `금221,750원(금이십이만일천칠백오십원)`
- **계약 금액**: `일금221,750원정(일금이십이만일천칠백오십원정)`
- 금액에 차이 시 → 글자로 적은 금액 우선

### "끝." 표기

- 본문이 끝난 후 1자(2타) 띄우고 `끝.`
- 첨부물이 있는 경우: `붙임  첨부물명 1부.  끝.`
- 오른쪽 한계선에서 끝난 경우: 다음 줄 왼쪽에서 1자 띄우고 `끝.`

### 붙임 표기

- `붙임  예산 내역서 1부.  끝.`
- 복수: `붙임  1. 서식 승인 목록 1부.` / `2. 직원 연찬회 계획 1부.  끝.`
- 한꺼번에 묶지 않음: `이력서, 자기소개서 각1부.` → ❌

### 수신란

- 내부결재: `수신  내부결재`
- 외부발신: `수신  [기관장 직위]([담당과장 직위])`

### 관련 근거 표기

- 단수: `1. 관련: [처리과명]-[번호]([날짜], 「[문서명]」)`
- 반드시 문서명(「」) 포함

### 낱표(낫표) 사용

- 겹낫표(『 』): 책 제목, 신문 이름
- 홑낫표(「 」): 법률명, 규정명, 소제목, 노래 제목

### 글자 표기

- 외국어는 괄호 안에: `연구 개발(R&D)` / `세계20개국금융정상회의(G20)`
- 기관명 붙여쓰기: `경상남도교육청창녕도서관` (단, 공문서 수신란은 띄어씀)

### 용어 구별

| 구분 | 의미 |
|------|------|
| 참고 | 살펴서 생각함 (1개 제시) |
| 참조 | 비교하고 대조함 (2개 이상 제시) |
| 주최 | 기획에 초점 |
| 주관 | 시행에 초점 |
| 소계 | 동일 과목 합 |
| 합계 | 동일 과목 합 |
| 총계 | 과목별 합계를 더함 |
| 기획 | 무엇을 할 것인가 |
| 계획 | 구체적으로 어떻게 할 것인가 |
| 이외 | 대상 포함하여 밖 |
| 외 | 대상 포함하지 않고 밖 |

## 4. 실제 적용 예시 (창녕도서관 샘플 기반)

**시행문 번호**: `[기관명]-[연도별일련번호]`  
**결재선(도서관)**: 주무관 → 사서팀장 → 도서관장  
**공개구분**: `부분공개(7)` 또는 `부분공개`  
**주소 푸터**: `우 [우편번호] [도로명주소] / [누리집] / 전화 [번호] / 전송 [번호] / [이메일] / 공개구분`
